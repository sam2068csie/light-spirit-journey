# R3 天秤市集：關卡設計（草案，2026/11/15）

對應講義重點三（次序不等式，第 10～11 頁，共 3 題）。單元規劃見 `docs/num_plan.md`。這份是**每一題、每一步**的設計，確認之後才開始寫程式。

- 2 章：第一章 6 題（5 題推導＋1 題速算），第二章 4 題（3 題推導＋1 題速算）。講義只有 3 題，第一章把第 10 頁的五選題拆開來，一種運算練一題，最後再回到原題。
- 每一題有 2 組數字，每次玩隨機抽一組。數字都和講義不同，全部用程式驗算過（`tools/num/verify_r3.py`）。
- 照 design_rules **1.7**（每一步都必要）和 **1.8**（看圖作答、少讀字）設計：**範圍都用拖的**，沒有「選一個範圍」的選項題。
- 「答對／答錯」欄是畫面上的世界反應（design_rules 1.2）。

## 場景與新元件

舞台沿用原野（`num_field.gd`）的數線柵欄。市集的攤位沿著柵欄排開，**每一個範圍是柵欄上亮起的一段燈**（燈條）。

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **燈條**（新） | 每一題 | 數線上方疊好幾條燈條，每條標一個式子（x、y、−y、x − y…）。題目給的範圍一開始就亮著，學生拉出來的答對之後才留下。 |
| **拉範圍** `lrange`（新的作答方式） | 第 1、2、4、7、8、9 題 | 數線上有一條空的燈條，兩端各有一個把手。拖兩個把手到端點（吸附到整數或半格），按「確定」。 |
| **方框** | 第 3、5、9 題 | 坐標方格上畫出 x、y 的範圍圍成的長方形，四個角是格子點。點角落用現有的 `grid`（點到別的角，那個角會顯示它的值）。 |

**拉範圍答錯時**：只有錯的那一端的把手閃紅，提示說「右端太大」或「左端太小」，不畫出正確的位置。常見的錯（例如端點直接相減、平方忘了 0）有自己的提示。答對時燈條亮起；從哪兩個端點合出來的，會從原本的燈條連一條細線過來。

照 design_rules 第 6 節：要學生拉出來、點出來的東西，答對之後才出現。

## 每一步為什麼必要（1.7）

- 第 1 題：x、y 是題目問的兩個範圍。y 多一步「除以 2」，因為 \|2y − 3\| 不是直接的距離，拿掉這步就拉不出中心。
- 第 2 題：x + y、x − y 是題目問的。−y 是 x − y 的關鍵，常見的錯（端點直接相減）就是少了這一步。
- 第 3 題：四個角就是題目問的兩個範圍的四個端點，點完範圍就出來了，所以不再拉一次。
- 第 4 題：x^{2} 是 x^{2} + y^{2} 要用的，也是這一題的重點（跨過 0）。y^{2} 不跨過 0，直接在第 2 步一起算。
- 第 5 題：每張審判卡是講義五選題的一個選項。只有 ✕ 的那張接反例。
- 第 7 題：x^{2}、y^{2} 各自的範圍是相減要用的，y 跨過 0 是陷阱。
- 第 8 題：配方之後兩個平方才能各自看範圍，m、M 是題目問的。
- 第 9 題：拆成兩個括號，才能用兩個範圍相乘。最後加回常數是題目問的。

## 錯的答案怎麼確保「絕對錯」

- 拉範圍不是選項，學生拉出來的範圍只要和答案不一樣就是錯的。常見錯誤的提示（端點直接相減、平方忘了 0、y 跨過 0）都用程式確認和答案不一樣。
- 第 3 題：每一組的最大、最小只在一個角，沒有兩個角一樣大（程式驗過）。
- 第 5 題的反例：方框裡的格子點只有一個讓 x^{2} + y^{2} < 5（程式驗過）。○ 的卡用很密的格子掃過整個方框。

## 判分

- 拉範圍：兩端都要對（吸附到整數，第 1 題第 1 組 y、第 2 組 y 的中心是半格，吸附到半格）。
- 第 1 題 ② 的 \frac{3}{2}、\frac{5}{2}：寫 1.5、2.5 也算對。
- 第 8 題 ④ 的 m、M 分開兩格，不會有順序問題。

## 觀念卡（4 張）

1. 距離寫成範圍：\|x − a\| ≤ b ⇔ [a − b] ≤ x ≤ [a + b]，a 是 [中心]。（干擾：端點、b − a）
2. 相減：x − y = x + ([−y])，−y 的範圍要 [左右對調]。（干擾：端點相減）
3. 相乘、相除：xy、\frac{x}{y} 的最大、最小在方框的 [四個角]。（干擾：中間）
4. 平方：範圍跨過 0 時，x^{2} 的最小值是 [0]。（干擾：端點的平方）

## 速算

- 第 6 題：給 a ≤ x ≤ b、c ≤ y ≤ d（整數），問 x − y 或 xy 的範圍，按鈕三個：答案、端點直接相減（或 xy 只看兩個端點相乘）、左右顛倒。錯的按鈕產生時檢查和答案不一樣。
- 第 10 題：給 a ≤ x ≤ b，問 x^{2} 的範圍，按鈕：答案、端點平方（跨過 0 時就是錯的）、另一個。沒跨過 0 的題目，錯的按鈕換成「左右沒對調」。

## 寫完要檢查（design_rules 第 8 節）

- 每一步都是回答這一題必要的（1.7）。範圍都在圖上拉，提示只說要做什麼（1.8，`reading`）。
- 燈條、方框上不寫中文，只有數字、式子。
- 要學生拉的範圍、點的角，答對之後才出現。
