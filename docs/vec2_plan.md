# 高二「平面向量」（箭羽高原）單元規劃（2026/11/20 草案 v3.1）

依據：高偉數學「高二上三段加強輔導班練習試題」兩份講義＋ `docs/design_rules.md`。
- **上冊**（48 頁）：3-1 平面向量的表示法（重點一～四）、3-2 平面向量的內積（重點一～七），84 題，題號 **A1～A84**（照講義出現的順序）。
- **下冊**（28 頁）：3-3 平面向量的應用（重點一～四），61 題，題號 **B1～B61**。

這一版排「關卡和章節」，每一題的數字、步驟之後在各關的設計稿（`docs/vec2_v1_design.md`…）重新設計並驗算。

**使用者的決定（2026/11/20）**
- **八關**，每關 **2 章**，一章最多 **12 題**（含速算）。
- **3-2 重點七「平面上的比例」（A80～A84）做成地圖彩蛋**，不放進關卡（第 3 節）。
- 其他沿用數與式、指數與常用對數的原則：同題型的講義題合成一題的變化；不用完全照講義（可以加新題、新玩法，先猜再算、計算交給畫面、判斷留給學生）；核心技巧保留，計算太重的減量或放終焉之塔；份量不用刻意一樣。

**v3 怎麼排**：講義的 15 個重點照順序併成 8 關，**大部分的章剛好是講義的一個重點**。只有一個地方換了順序：3-2 重點六「向量的投影」挪到內積那一關的第二章（投影就是內積的幾何意義，和垂直、平行的分解放在一起）。

（v1 自己重新分組成 10 關；v2 一個重點一關、15 關。）

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題一步一步帶。「下列哪些正確」的五選題拆成一張一張審判卡（○／✕），✕ 的卡再追問正確的是什麼。
- **學生自己列式**（1.4）：x\vec{AB} + y\vec{AC}、內積展開、參數式都用填空模板挖空。
- **答案在圖上、少讀字**（1.8）：向量一律畫在方格（或斜方格）上，題目的箭頭、點都看得到；學生答完一步，圖上補畫那一步的結果（和向量、分點、垂足、投影）。
- **看得到的後果**（1.2）：拖箭頭打中了，箭射進靶心、風箏飛起來；錯了，箭偏掉、風箏掉下來。
- **錯的選項絕對錯**（2）：審判卡、比大小用程式掃過。
- **共用元件**（V1 先做好，各關共用）：
  - **箭頭畫布**（`arrows`）：方格上畫向量、拖箭頭的終點、首尾相接自動畫出和向量（三角形法）或平行四邊形法。
  - **斜方格**（`skew`）：以兩個不平行的向量為兩個方向的斜格子；x\vec{a} + y\vec{b} 就是在斜格子上走 x 格、y 格。
  - 直線與圓已經有的格子點、滑桿、區域塗色、光點軌跡（`trail`）、燈（`lamps`）直接沿用。

## 2. 各關規劃

講義裡**同一個題型的題目合成遊戲裡的一題**，各自變成那一題的一種變化。每一題後面括號是合進來的講義題號；標「新」的是講義沒有、為了好玩和好懂加的題目。

### V1 風向台（3-1 重點一、二：向量的意義、線性組合、分點公式）

**場景**：高原入口的風向台。一支箭頭就是一陣風：方向是風往哪吹、長度是風多大。兩陣風一起吹，風箏往合起來的方向飄。風向台旁邊兩座崖之間有一條繩橋，繩上掛著箭羽，繩上的位置就是分點。

**新玩法**
- **拖箭頭**：拖箭頭的終點，兩陣風首尾接起來，風箏沿著和向量飄過去。
- **首尾接龍**：一串箭頭一支接一支，看最後指到哪裡。
- **繩上珠子**：沿用高一 R2「繩上珠子」的拖珠子（m : n），兩段繩子的長度比和 \vec{AP} = \frac{n}{m + n}\vec{AB} + \frac{m}{m + n}\vec{AC} 的係數跟著變（係數交叉：靠近 B 那一段越短，\vec{AB} 的係數越大）。

- **第一章 向量的意義與線性組合**（3-1 重點一，9 題）
  1. 什麼是向量（新）：兩支箭頭長度、方向一樣就是同一個向量，拖過去疊在一起。
  2. 相等向量（A1）：平行四邊形的頂點兩兩連成向量，一樣的箭頭疊在一起，數有幾種。
  3. 加法和減法（新）：三角形法、平行四邊形法，\vec{AB} − \vec{AC} = \vec{CB}（減法是「從後面指到前面」）。
  4. 正六邊形的箭頭（A3、A4）：變化 A 用 \vec{a}、\vec{b} 表示（A3）；變化 B 用對角線 \vec{u}、\vec{v} 表示（A4）。審判卡，每張畫出首尾接龍。
  5. 判定平行四邊形（A7）：審判卡。
  6. 係數積與平行（新）：拖 k，箭頭伸長、縮短、k < 0 時掉頭；\vec{a} ∥ \vec{b} ⇔ \vec{a} = k\vec{b}。
  7. 用兩個方向拼出向量（A2）：平行四邊形裡 \vec{EF} = x\vec{AB} + y\vec{AD}，沿著斜方格走。
  8. 不共線時係數唯一（A5、A6）：x\vec{AB} + y\vec{AC} = \vec{0} ⇒ x = y = 0。變化 B 先把 \vec{CB} 換成 \vec{AB} − \vec{AC}。
  9. 速算。
- **第二章 分點公式**（3-1 重點二，8 題）
  1. 拖珠子看係數（新）：係數交叉、加起來是 1。
  2. 中點和分點相減（A12）：P 是中點、Q 是 3 : 1 分點，求 \vec{PQ}。
  3. 梯形裡的分點（A11）。
  4. 角平分線分對邊（新）：AB : AC = BD : DC，再用分點（V2、V5 會用到）。
  5. 內切圓的切點（A8）：先用切線長求 BD : DC，再用分點。
  6. 高的垂足（A9）：先求 BD，再用分點。
  7. 由面積比找線段比（A10）。
  8. 速算。

### V2 斜紋麥田（3-1 重點三、四：共線、係數的範圍、座標表示法）

**場景**：高原上的田沿著兩個方向排成平行四邊形（地圖上已經畫了）。以 \vec{AB}、\vec{AC} 為兩個方向的斜方格，P = x\vec{AB} + y\vec{AC} 就是從 A 出發走 x 格、y 格。田埂上的烽台排成正方形的方格，每座烽台都有座標。

**新玩法**
- **斜方格**：學生在斜方格上點出 P，旁邊顯示 (x, y)。
- **係數和 = 1 的線**：拖 P 沿著直線 BC 走，旁邊顯示 x + y 一直是 1。
- **區域長出稻子**：給 x、y 的範圍，點出 P 能到的田，對的稻子長出來、錯的枯掉（design_rules 1.2）。
- **加權的天秤**：\vec{PA} + 2\vec{PB} + \vec{PC} = \vec{0} 的 P 是加權平均，三個點掛不同重量，P 是平衡點。

- **第一章 共線與係數的範圍**（3-1 重點三，10 題）
  1. 共線判斷（A13）：審判卡，每張在斜方格上看三點是不是在一條線上。
  2. 拖點看 x + y（新）：P 在直線 BC 上、BC 外側、BC 和 A 之間，x + y 分別是多少。
  3. 兩線交點（A14、A16、A18）：變化 A 中線和 DE（A14）、B 兩條線交於 P（A16）、C 斜座標法（A18）。先寫「P 在第一條線上」、再寫「P 在第二條線上」，比較係數。
  4. 交點分線段的比（A15、A19）。
  5. 孟氏定理（A17）：審判卡。
  6. 三角形內部（A20）：x > 0、y > 0、x + y < 1。
  7. 菱形內部（A21）。
  8. 七個區域（A22）：點出 P 在哪一塊。
  9. 區域的面積（A23）：先拖範圍滑桿看稻田的形狀，再算面積。
  10. 速算。
- **第二章 座標表示法**（3-1 重點四，11 題）
  1. 用 \vec{a}、\vec{b} 拼出 \vec{p}（A24）：先在斜方格上看大概幾格，再列聯立。
  2. 由三角形裡的已知向量求另一個（A25）。
  3. 平行又給長度，求點（A26）：單位向量 × 長度。
  4. 加權的零向量（A27）：天秤。
  5. 什麼時候拼不出來（A28、A29）：變化 A 三點共線時斜方格塌成一條線（A28）；變化 B 三個動點，拖時間看什麼時候排成一直線（A29）。
  6. 由中點三角形求頂點、重心（A30）。
  7. 長度的最小值（A31）：|2\vec{PA} + \vec{PB}| 化成 3 倍「P 到一個點的距離」。
  8. 長度和單位向量（A32）。
  9. 角平分向量（A33）：兩支單位向量相加 = 菱形的對角線。
  10. 座標的分點（A34）。
  11. 速算。

### V3 日晷影場（3-2 重點一、六：內積、垂直與平行、正射影）

**場景**：高原上的大日晷。太陽光垂直照下來，一支箭頭落在地面直線上的影子，就是它的**正射影**（呼應「光」的世界觀）。內積 = 影子長 × 另一支箭頭的長（同向是正、反向是負）。

**新玩法**
- **影子**：拖箭頭的方向，地上的影子跟著變長變短，夾角超過 90° 影子跑到反方向（內積變負）。
- **影子＋竿子**：一支向量 = 影子（平行分量）＋竿子（垂直分量）。

- **第一章 內積的意義與計算**（3-2 重點一，9 題）
  1. 拖箭頭看影子（新）：內積什麼時候最大、是 0、是負的。
  2. 觀念審判卡（A35、A36）。
  3. 內積和共線（A37）。
  4. 多邊形裡的內積比大小（A38、A39）：\vec{AB} 和各條對角線的內積 = 各條在 AB 方向的影子長比大小。
  5. 已知三邊求內積（A40）。
  6. 圖形中的內積（A43、A44、A45、A46）：變化 A 平行四邊形、B 正三角形的等分點、C 外作正方形、D 平行四邊形的對角線和等腰梯形。全部化成兩支基底向量再展開。
  7. 垂足和內積（A41）。
  8. 動點的內積（A42）：\vec{PA} · \vec{PB} = −3 是一個圓，再求到直線距離的最大值。
  9. 速算。
- **第二章 垂直、平行與正射影**（3-2 重點一後半＋重點六，10 題）
  1. 座標的內積（新）：(a_{1}, a_{2}) · (b_{1}, b_{2}) = a_{1}b_{1} + a_{2}b_{2}，和影子算出來一樣。
  2. 垂直求 t（A47）。
  3. 平行求 t（A48）。
  4. 垂直加平行求向量（A49）。
  5. 拆成平行和垂直兩個分量（A50）：影子＋竿子。
  6. 正射影的公式（新）：影子 = \frac{\vec{a} · \vec{b}}{|\vec{b}|^{2}}\vec{b}，填空列式。
  7. 正射影的計算（A78）：審判卡，正射影和正射影長分開問。
  8. 正射影的觀念（A77）：審判卡，兩支向量在同一個方向上的影子一樣長代表什麼。
  9. 竿子垂直影子（A79）：\vec{a} − \vec{c} ⊥ \vec{b}，內積直接是 0。
  10. 速算。

### V4 長弓靶場（3-2 重點二、三：求長度、求夾角）

**場景**：射箭場。兩支箭夾一個角射出去，合起來的長度、夾角都看得到。崖邊有一座巨大的量角器。

**新玩法**
- **拖 t 看長度**：|\vec{a} + t\vec{b}| 隨 t 變，畫面上箭頭伸縮，旁邊畫出長度平方對 t 的拋物線，最低點就是最小值。
- **先猜再算**：先拖量角器猜夾角（不扣能量），算完再看差多少。

- **第一章 求長度**（3-2 重點二，7 題）
  1. 長度的平方 = 自己和自己的內積（新）：|\vec{a} + \vec{b}|^{2} 展開，對照圖上的平行四邊形。
  2. 已知內積求長度（A51）。
  3. 已知長度求內積（A52）。
  4. 長度的範圍（A53）：兩支箭同向最長、反向最短。
  5. |\vec{a} + t\vec{b}| 的最小值（A55）：拖 t；最短的時候 \vec{a} + t\vec{b} ⊥ \vec{b}。
  6. 外心的向量和、角平分線長（A54、A56）。
  7. 速算。
- **第二章 求夾角**（3-2 重點三，7 題）
  1. 內積的正負和夾角（新）：審判卡，銳角、直角、鈍角。
  2. 座標求角（A57）。
  3. 已知夾角求未知數（A58）。
  4. 外作正方形（A59）。
  5. 已知長度求夾角（A60、A62、A63）：變化 A |\vec{a} − 2\vec{b}|、B |\vec{a}| = |\vec{b}| = |\vec{a} − \vec{b}|（畫出來是正三角形）、C |\vec{u}| = 2|\vec{v}| = |2\vec{u} + 3\vec{v}|。每一題先拖量角器猜。
  6. 垂直的兩支向量組合出的夾角（A61）。
  7. 速算。

### V5 四心營火（3-2 重點四、五：三角形的四心、面積比）

**場景**：營地裡四座營火分別點在三角形的重心、內心、外心、垂心。營地旁邊是三角形的花圃（面積比）。

**新玩法**
- **三人拉繩**：三個頂點各拉一條繩到 G，三條力的箭頭加起來剛好是 \vec{0}（重心）。
- **找營火**：拖一個點，看它到三邊、三頂點的距離，找出內心、外心。
- **三分花圃**：從 P 拉三條線到頂點，把花圃分成三塊。拖 P，三塊的面積比和係數一起變。

- **第一章 三角形的四心**（3-2 重點四，10 題）
  1. 重心的觀念（A64）：審判卡。
  2. 重心和內積（A65）。
  3. 三支向量和為零的變化題（A66）。
  4. 小三角形的重心（A67）。
  5. 過重心的直線和面積（A68）。
  6. 內心（A69）：審判卡，角平分線分對邊的比。
  7. 找營火（新）：拖點找外心（到三頂點一樣遠）、內心（到三邊一樣遠）。
  8. 四心的觀念（A70、A71）：審判卡。
  9. 外心、垂心的計算（A72、A73、A74）：變化 A 外心和垂心（A72，外心用「到兩邊的投影是邊長的一半」列兩條式子）、B 角平分線和中垂線（A73）、C 座標上的四心（A74，審判卡）。
  10. 速算。
- **第二章 面積比**（3-2 重點五，8 題）
  講義只有 2 題，其他是新題：
  1. 三分花圃（新）：拖 P，看三塊的面積比。
  2. 等高的三角形面積比 = 底的比（新）：國中的觀念，在斜方格上複習。
  3. 已知關係式求面積比（A75）。
  4. \vec{PA} + 2\vec{PB} + 3\vec{PC} = \vec{0} 型（新）：係數比就是對面那一塊的面積比。
  5. 已知面積比求點（A76）。
  6. 面積比反推係數（新）：三塊是 1 : 2 : 3，\vec{AP} = x\vec{AB} + y\vec{AC} 的 x、y 是多少。
  7. 四心的面積比（新）：重心 1 : 1 : 1、內心是三邊的比（接第一章）。
  8. 速算。

### V6 風箏航道（3-3 重點一：直線的參數式）

**場景**：風箏沿著風的方向飛。t 是時間，風箏從 A 出發、照方向向量走，走過的地方留下光點。航道盡頭是像鏡子的岩壁，光打到岩壁會反射。

**新玩法**
- **t 滑桿**：拖 t，點沿著直線走，走過的地方留下光點（`trail`）；t 的範圍決定是線段、射線還是整條直線。
- **法向量**：直線上插一支和它垂直的箭頭，ax + by = c 的 (a, b) 就是這支箭頭。
- **反射光**：拖鏡子（直線）的角度，入射光、反射光跟著畫。

- **第一章 參數式與法向量**（3-3 重點一前半，12 題）
  1. 參數式是時間（新）：拖 t，風箏什麼時候飛到哪裡。
  2. 線段、射線的參數式（B1、B2）：審判卡，每張拖 t 看光點走過哪一段。
  3. 線段參數式的審判卡（B7）。
  4. 線段上的格子點（B3）。
  5. 用法向量寫直線（B4）。
  6. 方向向量、法向量和直線（B5、B6、B8）：變化 A 方向向量和直線上的點（B5）、B 和直線平行的向量（B6）、C 直線換成參數式（B8）。
  7. 兩直線的交點（B9、B10）：變化 A 一般式和參數式（B9）、B 沿著向量前進碰到直線（B10）。
  8. 點到直線的距離（B11）。
  9. 沿直線走固定距離（B15）。
  10. 菱形、正方形的頂點（B16、B17）：轉 90° 的向量。
  11. 平行、垂直、夾角綜合（B18）。
  12. 速算。
- **第二章 極值、投影、反射與夾角**（3-3 重點一後半，10 題）
  1. 參數式求極值（B12、B13、B14）：變化 A 線段上一次式的最大值（端點最大，B12）、B 平方和的最小值（t 的二次函數，B13）、C 內積的最小值（B14）。
  2. 垂足和 PA + PB 的最小值（B19）：對稱點。
  3. 反射求鏡子的斜率（B20）：鏡子平分入射光和反射光的夾角。
  4. 向量在直線上的正射影（B21）。
  5. 投影點（B22）。
  6. 兩直線的銳角交角（B23）。
  7. 參數式的交點和夾角（B24）。
  8. 已知斜率求交角（B25）。
  9. 已知夾角求直線（B26）。
  10. 速算。

### V7 弓帆工坊（3-3 重點二、三：柯西不等式、面積公式）

**場景**：做弓和船帆的工坊。弓弦：兩支箭（向量）方向對齊的時候，弦拉得最緊。船帆：兩支向量張開，三角形、平行四邊形的帆，面積用向量算。

**新玩法**
- **轉箭頭**：|\vec{a}|、|\vec{b}| 固定，轉 \vec{b}，看 \vec{a} · \vec{b} 跟著變：同向最大、反向最小。這就是 |\vec{a} · \vec{b}| ≤ |\vec{a}||\vec{b}|。
- **張開的帆**：拖兩支箭頭，張出的三角形帆塗色，面積跟著變。

- **第一章 柯西不等式與三角不等式**（3-3 重點二，10 題）
  1. 轉箭頭（新）：看出柯西不等式和等號成立的時候。
  2. 已知一次式求平方和的最小值（B27）。
  3. 先配方再用柯西（B28）。
  4. 內積的形式（B29、B30）：變化 A 一個向量在圓上（B29）、B 已知兩個長度（B30）。
  5. 垂直條件下的最小值（B31）。
  6. 倒數型（B32）。
  7. 不等式審判卡（B33）。
  8. 三角形內的距離（B34）：面積寫成一次式，再用柯西。
  9. 半圓湖游泳（B35）：時間寫成 sin、cos 的一次式。
  10. 速算。
- **第二章 面積公式**（3-3 重點三，8 題）
  1. 從 \frac{1}{2}ab sin θ 推出向量的面積公式（新）：填空列式。
  2. 向量式求面積（B36）。
  3. 座標的面積公式（新）：\frac{1}{2}|a_{1}b_{2} − a_{2}b_{1}|。
  4. 面積的綜合審判卡（B37、B38）。
  5. 外作正方形求面積（B39）。
  6. 線性組合的區域面積（B40、B41）：沿用 V2 的稻田，算面積。
  7. 面積和夾角（新）：已知面積和兩邊，求夾角（兩個答案）。
  8. 速算。

### V8 雙線織坊（3-3 重點四：二階行列式與克拉瑪法則）

**場景**：織布工坊，兩支向量張開成一塊平行四邊形的布。行列式 = 布的面積（帶方向：翻過來是負的）。兩條直線交在哪裡，就是聯立方程式的解。

**新玩法**
- **張開的布**：拖兩支箭頭，張出的平行四邊形塗色，面積 = 行列式的絕對值；兩支箭頭的順序換過來，布翻面變色（負號）。
- **兩條直線**：兩條直線畫在方格上，交點就是解；Δ = 0 時兩條平行（無解）或疊在一起（無限多解）。

- **第一章 二階行列式**（3-3 重點四前半，9 題）
  1. 行列式 = 布的面積（新）：拖箭頭看正負。
  2. 行列式的值（B44、B45）：變化 A 大數字（先化簡再算）、B 根號。
  3. 行列式的整數解（B46）。
  4. 行列式的性質（B42、B43）：一張布的邊伸長、加上另一邊的倍數，面積怎麼變。
  5. 性質審判卡（B48、B49）。
  6. 已知面積求點（B47）。
  7. 張成的平行四邊形面積（B60、B61）。
  8. 行列式的綜合審判卡（B51）。
  9. 速算。
- **第二章 克拉瑪法則**（3-3 重點四後半，9 題）
  1. 克拉瑪法則求解（B52）。
  2. 已知三個行列式求解（B53）。
  3. 已知解，求新方程組的解（B55、B56）。
  4. 克拉瑪的綜合審判卡（B54）。
  5. x\vec{a} + y\vec{b} = \vec{c} 有幾組解（B50）：兩支箭頭平不平行。
  6. 討論解的個數（B57）：拖 a，看兩條直線交於一點、平行、重合。
  7. 無解（B58）。
  8. 無限多解（B59）。
  9. 速算。
