# 高二「平面向量」（箭羽高原）單元規劃（2026/11/20 草案 v2）

依據：高偉數學「高二上三段加強輔導班練習試題」兩份講義＋ `docs/design_rules.md`。
- **上冊**（48 頁）：3-1 平面向量的表示法（重點一～四）、3-2 平面向量的內積（重點一～七），84 題，題號 **A1～A84**（照講義出現的順序）。
- **下冊**（28 頁）：3-3 平面向量的應用（重點一～四），61 題，題號 **B1～B61**。

這一版排「關卡和章節」，每一題的數字、步驟之後在各關的設計稿（`docs/vec2_v1_design.md`…）重新設計並驗算。

**v2 的改動（2026/11/20）**：v1 自己重新分組成 10 關，沒照之前的規劃原則。v2 改回和數與式、指數與常用對數一樣的做法：

- **一關對應講義的一個重點，順序和講義一樣**：兩本講義共 15 個重點，做 15 關。
- **每關 2 章，一章最多 12 題**（含速算）。
- **份量不用刻意一樣**：題目少的重點（面積比 2 題、投影 3 題）也是一關，不夠的用新題、新玩法補；題目多的重點（直線的參數式 26 題）靠同題型合併塞進兩章。
- **同題型的講義題合成一題**的變化；**不用完全照講義**，核心技巧保留，太重的計算減量或放終焉之塔。

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題一步一步帶。「下列哪些正確」的五選題拆成一張一張審判卡（○／✕），✕ 的卡再追問正確的是什麼。
- **學生自己列式**（1.4）：x\vec{AB} + y\vec{AC}、內積展開、參數式都用填空模板挖空。
- **答案在圖上、少讀字**（1.8）：向量一律畫在方格（或斜方格）上，題目的箭頭、點都看得到；學生答完一步，圖上補畫那一步的結果（和向量、分點、垂足、投影）。
- **看得到的後果**（1.2）：拖箭頭打中了，箭射進靶心、風箏飛起來；錯了，箭偏掉、風箏掉下來。
- **錯的選項絕對錯**（2）：審判卡、比大小用程式掃過。
- **共用元件**（V1 先做好，各關共用）：
  - **箭頭畫布**（`arrows`）：方格上畫向量、拖箭頭的終點、首尾相接自動畫出和向量（三角形法）或平行四邊形法。
  - **斜方格**（`skew`）：以兩個不平行的向量為兩個方向的斜格子；x\vec{a} + y\vec{b} 就是在斜格子上走 x 格、y 格。
  - 直線與圓已經有的格子點、滑桿、區域塗色、光點軌跡（`trail`）、燈（`lamps`）直接沿用。

## 2. 各關規劃

講義裡**同一個題型的題目合成遊戲裡的一題**，各自變成那一題的一種變化。每一題後面括號是合進來的講義題號；標「新」的是講義沒有、為了好玩和好懂加的題目。

### V1 風向台（3-1 重點一：向量基本概念）

**場景**：高原入口的風向台。一支箭頭就是一陣風：方向是風往哪吹、長度是風多大。兩陣風一起吹，風箏往合起來的方向飄。

**新玩法**
- **拖箭頭**：拖箭頭的終點，兩陣風首尾接起來，風箏沿著和向量飄過去。
- **首尾接龍**：一串箭頭一支接一支，看最後指到哪裡。

- **第一章 向量的意義與加減**（約 6 題）
  1. 什麼是向量（新）：兩支箭頭長度、方向一樣就是同一個向量，拖過去疊在一起。
  2. 相等向量（A1）：平行四邊形的頂點兩兩連成向量，一樣的箭頭疊在一起，數有幾種。
  3. 加法和減法（新）：三角形法、平行四邊形法，\vec{AB} − \vec{AC} = \vec{CB}（減法是「從後面指到前面」）。
  4. 正六邊形的箭頭（A3、A4）：變化 A 用 \vec{a}、\vec{b} 表示（A3）；變化 B 用對角線 \vec{u}、\vec{v} 表示（A4）。審判卡，每張畫出首尾接龍。
  5. 判定平行四邊形（A7）：審判卡。
  6. 速算。
- **第二章 線性組合**（約 5 題）
  1. 係數積（新）：拖 k，箭頭伸長、縮短、k < 0 時掉頭。
  2. 用兩個方向拼出向量（A2）：平行四邊形裡 \vec{EF} = x\vec{AB} + y\vec{AD}，沿著斜方格走。
  3. 不共線時係數唯一（A5、A6）：x\vec{AB} + y\vec{AC} = \vec{0} ⇒ x = y = 0。變化 B 先把 \vec{CB} 換成 \vec{AB} − \vec{AC}。
  4. 平行的向量（新）：\vec{a} ∥ \vec{b} ⇔ \vec{a} = k\vec{b}。
  5. 速算。

### V2 分羽繩橋（3-1 重點二：分點公式）

**場景**：兩座崖之間的繩橋，繩上掛著箭羽。繩上的位置就是分點。

**新玩法**
- **繩上珠子**：沿用高一 R2「繩上珠子」的拖珠子（m : n），兩段繩子的長度比和 \vec{AP} = \frac{n}{m + n}\vec{AB} + \frac{m}{m + n}\vec{AC} 的係數跟著變（係數交叉：靠近 B 那一段越短，\vec{AB} 的係數越大）。

- **第一章 分點公式**（約 5 題）
  1. 拖珠子看係數（新）：係數交叉、加起來是 1。
  2. 中點和分點相減（A12）：P 是中點、Q 是 3 : 1 分點，求 \vec{PQ}。
  3. 梯形裡的分點（A11）。
  4. 外分點（新）：珠子拖到繩子外面，係數出現負數。
  5. 速算。
- **第二章 圖形裡的分點**（約 5 題）
  1. 內切圓的切點（A8）：先用切線長求 BD : DC，再用分點。
  2. 高的垂足（A9）：先求 BD，再用分點。
  3. 由面積比找線段比（A10）。
  4. 角平分線分對邊（新）：AB : AC = BD : DC，再用分點（V4、V8 會用到）。
  5. 速算。

### V3 斜紋麥田（3-1 重點三：共線問題）

**場景**：高原上的田沿著兩個方向排成平行四邊形（地圖上已經畫了）。以 \vec{AB}、\vec{AC} 為兩個方向的斜方格，P = x\vec{AB} + y\vec{AC} 就是從 A 出發走 x 格、y 格。

**新玩法**
- **斜方格**：學生在斜方格上點出 P，旁邊顯示 (x, y)。
- **係數和 = 1 的線**：拖 P 沿著直線 BC 走，旁邊顯示 x + y 一直是 1。
- **區域長出稻子**：給 x、y 的範圍，點出 P 能到的田，對的稻子長出來、錯的枯掉（design_rules 1.2）。

- **第一章 三點共線與交點**（約 7 題）
  1. 共線判斷（A13）：審判卡，每張在斜方格上看三點是不是在一條線上。
  2. 兩線交點（A14、A16、A18）：變化 A 中線和 DE（A14）、B 兩條線交於 P（A16）、C 斜座標法（A18）。先寫「P 在第一條線上」、再寫「P 在第二條線上」，比較係數。
  3. 交點分線段的比（A15、A19）。
  4. 孟氏定理（A17）：審判卡。
  5. 拖點看 x + y（新）：P 在直線 BC 上、BC 外側、BC 和 A 之間，x + y 分別是多少。
  6. 速算。
- **第二章 係數的範圍**（約 6 題）
  1. 三角形內部（A20）：x > 0、y > 0、x + y < 1。
  2. 菱形內部（A21）。
  3. 七個區域（A22）：點出 P 在哪一塊。
  4. 區域的面積（A23）。
  5. 拖範圍看區域（新）：拖 x、y 的範圍滑桿，看稻田的形狀跟著變。
  6. 速算。

### V4 方格烽台（3-1 重點四：向量的座標表示法）

**場景**：高原上的烽台排成方格，每座烽台都有座標。向量 = 從一座烽台指到另一座的箭頭，(x, y) 就是往右、往上各走幾格。

**新玩法**
- **拖箭頭讀座標**：拖箭頭終點，旁邊即時顯示 (x, y)；加減、係數積都在方格上畫出來。
- **加權的天秤**：\vec{PA} + 2\vec{PB} + \vec{PC} = \vec{0} 的 P 是加權平均，三個點掛不同重量，P 是平衡點。

- **第一章 座標運算**（約 7 題）
  1. 用 \vec{a}、\vec{b} 拼出 \vec{p}（A24）：先在斜方格上看大概幾格，再列聯立。
  2. 由三角形裡的已知向量求另一個（A25）。
  3. 平行又給長度，求點（A26）：單位向量 × 長度。
  4. 加權的零向量（A27）：天秤。
  5. 由中點三角形求頂點、重心（A30）。
  6. 什麼時候拼不出來（A28、A29）：變化 A 三點共線時斜方格塌成一條線（A28）；變化 B 三個動點，拖時間看什麼時候排成一直線（A29）。
  7. 速算。
- **第二章 長度、單位向量與分點**（約 6 題）
  1. 長度和單位向量（A32）。
  2. 長度的最小值（A31）：|2\vec{PA} + \vec{PB}| 化成 3 倍「P 到一個點的距離」。
  3. 角平分向量（A33）：兩支單位向量相加 = 菱形的對角線。
  4. 座標的分點（A34）。
  5. 單位向量拼出的方向（新）：拖角度看 (cos θ, sin θ)，接三角函數。
  6. 速算。

### V5 拉車坡道（3-2 重點一：內積的定義）

**場景**：坡道上拉貨車。力的箭頭和前進方向夾一個角，只有沿著前進方向的那一段在出力。內積 = 出力的那一段 × 走的距離。

**新玩法**
- **拉貨車**：拖力的方向，「有用的力」那一段跟著變長變短，夾角超過 90° 變成往後拉（內積變負）。

- **第一章 內積的意義與計算**（約 9 題）
  1. 拉貨車（新）：拖角度，看內積什麼時候最大、是 0、是負的。
  2. 觀念審判卡（A35、A36）。
  3. 內積和共線（A37）。
  4. 多邊形裡的內積比大小（A38、A39）：\vec{AB} 和各條對角線的內積，看各條在 AB 方向「出力」多少。
  5. 已知三邊求內積（A40）。
  6. 圖形中的內積（A43、A44、A45、A46）：變化 A 平行四邊形、B 正三角形的等分點、C 外作正方形、D 平行四邊形的對角線和等腰梯形。全部化成兩支基底向量再展開。
  7. 垂足和內積（A41）。
  8. 動點的內積（A42）：\vec{PA} · \vec{PB} = −3 是一個圓，再求到直線距離的最大值。
  9. 速算。
- **第二章 垂直、平行與分解**（約 6 題）
  1. 垂直求 t（A47）。
  2. 平行求 t（A48）。
  3. 垂直加平行求向量（A49）。
  4. 拆成平行和垂直兩個分量（A50）。
  5. 座標的內積（新）：(a_{1}, a_{2}) · (b_{1}, b_{2}) = a_{1}b_{1} + a_{2}b_{2}，和定義算出來一樣。
  6. 速算。

### V6 長弓靶場（3-2 重點二：求長度）

**場景**：射箭場。兩支箭合起來的長度，用內積算。

**新玩法**
- **拖 t 看長度**：|\vec{a} + t\vec{b}| 隨 t 變，畫面上箭頭伸縮，旁邊畫出長度平方對 t 的拋物線，最低點就是最小值。

- **第一章 長度的計算**（約 5 題）
  1. 長度的平方 = 自己和自己的內積（新）：|\vec{a} + \vec{b}|^{2} 展開，對照圖上的平行四邊形。
  2. 已知內積求長度（A51）。
  3. 已知長度求內積（A52）。
  4. 外心的向量和（A54）。
  5. 速算。
- **第二章 長度的最大最小**（約 5 題）
  1. 長度的範圍（A53）：兩支箭同向最長、反向最短。
  2. |\vec{a} + t\vec{b}| 的最小值（A55）：拖 t。
  3. 角平分線長（A56）。
  4. 最短的時候垂直（新）：|\vec{a} + t\vec{b}| 最小時，\vec{a} + t\vec{b} ⊥ \vec{b}。
  5. 速算。

### V7 量角崖（3-2 重點三：求夾角）

**場景**：崖邊的巨大量角器。兩支箭的夾角用量角器讀，cos 值在旁邊。

**新玩法**
- **先猜再算**：先拖量角器猜夾角（不扣能量），算完再看差多少。

- **第一章 座標與圖形的夾角**（約 5 題）
  1. 座標求角（A57）。
  2. 已知夾角求未知數（A58）。
  3. 外作正方形（A59）。
  4. 內積的正負和夾角（新）：審判卡，銳角、直角、鈍角。
  5. 速算。
- **第二章 已知長度求夾角**（約 5 題）
  1. 已知長度求夾角（A60、A62、A63）：變化 A |\vec{a} − 2\vec{b}|、B |\vec{a}| = |\vec{b}| = |\vec{a} − \vec{b}|（畫出來是正三角形）、C |\vec{u}| = 2|\vec{v}| = |2\vec{u} + 3\vec{v}|。
  2. 垂直的兩支向量組合出的夾角（A61）。
  3. 先猜再算（新）：給一個形狀，先拖量角器猜，再算 cos 確認。
  4. 夾角的範圍（新）：兩支向量的夾角在 0° 到 180° 之間，cos 一個值只對應一個角。
  5. 速算。

### V8 四心營火（3-2 重點四：三角形的四心）

**場景**：營地裡四座營火分別點在三角形的重心、內心、外心、垂心。

**新玩法**
- **三人拉繩**：三個頂點各拉一條繩到 G，三條力的箭頭加起來剛好是 \vec{0}（重心）。
- **找營火**：拖一個點，看它到三邊、三頂點的距離，找出內心、外心。

- **第一章 重心與內心**（約 7 題）
  1. 重心的觀念（A64）：審判卡。
  2. 重心和內積（A65）。
  3. 三支向量和為零的變化題（A66）。
  4. 小三角形的重心（A67）。
  5. 過重心的直線和面積（A68）。
  6. 內心（A69）：審判卡，角平分線分對邊的比。
  7. 速算。
- **第二章 外心與垂心**（約 6 題）
  1. 四心的觀念（A70、A71）：審判卡。
  2. 外心和垂心的計算（A72）：外心用「到兩邊的投影是邊長的一半」列兩條式子。
  3. 角平分線和中垂線（A73）。
  4. 座標上的四心（A74）：審判卡。
  5. 找營火（新）：拖點找外心（到三頂點一樣遠）、內心（到三邊一樣遠）。
  6. 速算。

### V9 三分花圃（3-2 重點五：面積比）

**場景**：一塊三角形的花圃，從裡面一點 P 拉三條線到頂點，分成三塊種三種花。三塊的面積比就是 P 的「權重」。

**新玩法**
- **拖點看三塊花**：拖 P，三塊花圃的面積比和 \vec{AP} = x\vec{AB} + y\vec{AC} 的係數一起變。

講義只有 2 題，大部分是新題：
- **第一章 由關係式求面積比**（約 5 題）
  1. 拖點看三塊花（新）：P 往 C 靠近，哪一塊變小。
  2. 等高的三角形面積比 = 底的比（新）：國中的觀念，在斜方格上複習。
  3. 已知關係式求面積比（A75）。
  4. \vec{PA} + 2\vec{PB} + 3\vec{PC} = \vec{0} 型（新）：係數比就是對面那一塊的面積比。
  5. 速算。
- **第二章 由面積比求點**（約 4 題）
  1. 已知面積比求點（A76）。
  2. 面積比反推係數（新）：三塊是 1 : 2 : 3，P 的係數是多少。
  3. 四心的面積比（新）：重心 1 : 1 : 1、內心 = 三邊的比（接 V8）。
  4. 速算。

### V10 日晷影場（3-2 重點六：向量的投影）

**場景**：高原上的大日晷。太陽光垂直照下來，一支箭頭落在地面直線上的影子，就是它的**正射影**（呼應「光」的世界觀）。

**新玩法**
- **影子**：拖箭頭的方向，地上的影子跟著變長變短，夾角超過 90° 影子跑到反方向。
- **影子＋竿子**：一支向量 = 影子（平行分量）＋竿子（垂直分量）。

講義只有 3 題，大部分是新題：
- **第一章 正射影**（約 5 題）
  1. 拖箭頭看影子（新）：影子長 = |\vec{a}| cos θ。
  2. 正射影的公式（新）：影子 = \frac{\vec{a} · \vec{b}}{|\vec{b}|^{2}}\vec{b}，填空列式。
  3. 正射影的計算（A78）：審判卡，正射影和正射影長分開問。
  4. 投影點（新）：B 點在直線 AC 上的投影點。
  5. 速算。
- **第二章 正射影的性質**（約 4 題）
  1. 正射影的觀念（A77）：審判卡，兩支向量在同一個方向上的影子一樣長代表什麼。
  2. 竿子垂直影子（A79）：\vec{a} − \vec{c} ⊥ \vec{b}，內積直接是 0。
  3. 內積 = 影子長 × 長度（新）：V5 的內積用影子再看一次。
  4. 速算。

### V11 風箏攤（3-2 重點七：平面上的比例）

**場景**：高原上的風箏攤。A 系列的風箏每對折一次長寬比不變，黃金比例的風箏最好看。

- **第一章 黃金比例**（約 4 題）
  1. 黃金矩形（A80）：五種長寬比，挑最接近黃金比例的。
  2. 切掉正方形還是一樣的形狀（新）：黃金矩形切掉一個正方形，剩下的還是黃金矩形。
  3. 正五邊形的對角線（A81）：長度乘積。
  4. 速算。
- **第二章 紙張、圓角與透視**（約 4 題）
  1. A 系列紙張（A82）：A5 對折成 A6，求尺寸。
  2. 圓角三角形（A83）：審判卡。
  3. 單點透視（A84）：消失點和長方體。
  4. 速算。

### V12 風箏航道（3-3 重點一：直線的參數式）

**場景**：風箏沿著風的方向飛。t 是時間，風箏從 A 出發、照方向向量走，走過的地方留下光點。航道盡頭是像鏡子的岩壁，光打到岩壁會反射。

**新玩法**
- **t 滑桿**：拖 t，點沿著直線走，走過的地方留下光點（`trail`）；t 的範圍決定是線段、射線還是整條直線。
- **法向量**：直線上插一支和它垂直的箭頭，ax + by = c 的 (a, b) 就是這支箭頭。
- **反射光**：拖鏡子（直線）的角度，入射光、反射光跟著畫。

講義有 26 題，同題型合併後分成兩章：
- **第一章 參數式與法向量**（約 12 題）
  1. 線段、射線的參數式（B1、B2）：審判卡，每張拖 t 看光點走過哪一段。
  2. 線段上的格子點（B3）。
  3. 用法向量寫直線（B4）。
  4. 方向向量、法向量和直線（B5、B6、B8）：變化 A 方向向量和直線上的點（B5）、B 和直線平行的向量（B6）、C 直線換成參數式（B8）。
  5. 線段參數式的審判卡（B7）。
  6. 兩直線的交點（B9、B10）：變化 A 一般式和參數式（B9）、B 沿著向量前進碰到直線（B10）。
  7. 點到直線的距離（B11）。
  8. 沿直線走固定距離（B15）。
  9. 菱形、正方形的頂點（B16、B17）：轉 90° 的向量。
  10. 平行、垂直、夾角綜合（B18）。
  11. 參數式是時間（新）：拖 t，風箏什麼時候飛到哪裡。
  12. 速算。
- **第二章 極值、投影、反射與夾角**（約 10 題）
  1. 參數式求極值（B12、B13、B14）：變化 A 線段上一次式的最大值（端點最大，B12）、B 平方和的最小值（t 的二次函數，B13）、C 內積的最小值（B14）。
  2. 垂足和 PA + PB 的最小值（B19）：對稱點。
  3. 反射求鏡子的斜率（B20）：鏡子平分入射光和反射光的夾角。
  4. 向量在直線上的正射影（B21）。
  5. 投影點（B22）。
  6. 兩直線的銳角交角（B23）。
  7. 參數式的交點和夾角（B24）。
  8. 已知斜率求交角（B25）。
  9. 已知夾角求直線（B26）。
  10. 速算。

### V13 拉弦試煉（3-3 重點二：柯西不等式與三角不等式）

**場景**：長弓的弓弦。兩支箭（向量）方向對齊的時候，弦拉得最緊。

**新玩法**
- **轉箭頭**：|\vec{a}|、|\vec{b}| 固定，轉 \vec{b}，看 \vec{a} · \vec{b} 跟著變：同向最大、反向最小。這就是 |\vec{a} · \vec{b}| ≤ |\vec{a}||\vec{b}|。

- **第一章 柯西不等式**（約 6 題）
  1. 轉箭頭（新）：看出柯西不等式和等號成立的時候。
  2. 已知一次式求平方和的最小值（B27）。
  3. 先配方再用柯西（B28）。
  4. 內積的形式（B29、B30）：變化 A 一個向量在圓上（B29）、B 已知兩個長度（B30）。
  5. 倒數型（B32）。
  6. 速算。
- **第二章 三角不等式與應用**（約 5 題）
  1. 垂直條件下的最小值（B31）。
  2. 不等式審判卡（B33）。
  3. 三角形內的距離（B34）：面積寫成一次式，再用柯西。
  4. 半圓湖游泳（B35）：時間寫成 sin、cos 的一次式。
  5. 速算。

### V14 張帆工坊（3-3 重點三：面積公式）

**場景**：做船帆的工坊。兩支向量張開，三角形的帆、平行四邊形的帆，面積用向量算。

**新玩法**
- **張開的帆**：拖兩支箭頭，張出的三角形帆塗色，面積 = \frac{1}{2}\sqrt{|\vec{a}|^{2}|\vec{b}|^{2} − (\vec{a} · \vec{b})^{2}}，座標寫法 \frac{1}{2}|a_{1}b_{2} − a_{2}b_{1}|。

- **第一章 面積公式**（約 5 題）
  1. 從 \frac{1}{2}ab sin θ 推出向量的面積公式（新）：填空列式。
  2. 向量式求面積（B36）。
  3. 座標的面積公式（新）：\frac{1}{2}|a_{1}b_{2} − a_{2}b_{1}|。
  4. 外作正方形求面積（B39）。
  5. 速算。
- **第二章 面積的綜合**（約 5 題）
  1. 面積的綜合審判卡（B37、B38）。
  2. 線性組合的區域面積（B40、B41）：沿用 V3 的稻田，算面積。
  3. 平行四邊形 = 兩個三角形（新）。
  4. 面積和夾角（新）：已知面積和兩邊，求夾角（兩個答案）。
  5. 速算。

### V15 雙線織坊（3-3 重點四：二階行列式與克拉瑪法則）

**場景**：織布工坊，兩支向量張開成一塊平行四邊形的布。行列式 = 布的面積（帶方向：翻過來是負的）。兩條直線交在哪裡，就是聯立方程式的解。

**新玩法**
- **張開的布**：拖兩支箭頭，張出的平行四邊形塗色，面積 = 行列式的絕對值；兩支箭頭的順序換過來，布翻面變色（負號）。
- **兩條直線**：兩條直線畫在方格上，交點就是解；Δ = 0 時兩條平行（無解）或疊在一起（無限多解）。

- **第一章 二階行列式**（約 9 題）
  1. 行列式 = 布的面積（新）：拖箭頭看正負。
  2. 行列式的值（B44、B45）：變化 A 大數字（先化簡再算）、B 根號。
  3. 行列式的整數解（B46）。
  4. 行列式的性質（B42、B43）：一張布的邊伸長、加上另一邊的倍數，面積怎麼變。
  5. 性質審判卡（B48、B49）。
  6. 已知面積求點（B47）。
  7. 張成的平行四邊形面積（B60、B61）。
  8. 行列式的綜合審判卡（B51）。
  9. 速算。
- **第二章 克拉瑪法則**（約 9 題）
  1. 克拉瑪法則求解（B52）。
  2. 已知三個行列式求解（B53）。
  3. 已知解，求新方程組的解（B55、B56）。
  4. 克拉瑪的綜合審判卡（B54）。
  5. x\vec{a} + y\vec{b} = \vec{c} 有幾組解（B50）：兩支箭頭平不平行。
  6. 討論解的個數（B57）：拖 a，看兩條直線交於一點、平行、重合。
  7. 無解（B58）。
  8. 無限多解（B59）。
  9. 速算。

## 3. 觀念卡、速算、終焉之塔

- **觀念卡**（`concepts_vec2.gd`）：每關 3～5 張。例如「\vec{AP} = x\vec{AB} + y\vec{AC}，P 在直線 BC 上 ⇔ x + y = [ ]」、「\vec{a} · \vec{b} < 0 ⇔ 夾角是 [ ] 角」、「行列式 = 0 ⇔ 兩支向量 [ ]」。每張至少一塊干擾積木。
