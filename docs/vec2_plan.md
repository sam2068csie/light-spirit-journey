## 0. 總覽

### 要請使用者決定的事

1. **關數**：草案是 10 關（3-1 三關、3-2 三關、3-3 四關）。題目很多（145 題），所以比三角函數（7 關）、指數與對數（8 關）多。要壓到 8 關的話，可以把 V2 併進 V3、V9 併進 V8。
2. **重點七「平面上的比例」（A80～A84：黃金比例、A 系列紙張、圓角三角形、單點透視）**：和向量的計算關係比較小。草案是做成箭羽高原上的**地圖彩蛋**（風箏的長寬比），不放進關卡。也可以不收。
3. **二階行列式與克拉瑪法則（B42～B61，20 題）**：講義放在 3-3，草案照講義放在最後一關 V10。
4. **沿用指數與對數的做法**：每關 2 章、一章最多 12 題（含速算）；講義裡同一個題型的題目合成遊戲裡的一題（每次隨機抽一種變化）；不用完全照講義，可以加新玩法。
5. **關卡名稱**：都是暫定的，圍繞箭羽高原的箭、風、風箏、田。

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題一步一步帶。「下列哪些正確」的五選題拆成一張一張審判卡（○／✕），✕ 的卡再追問正確的是什麼。
- **學生自己列式**（1.4）：x\vec{AB} + y\vec{AC}、內積展開、參數式都用填空模板挖空。
- **答案在圖上、少讀字**（1.8）：向量一律畫在方格（或斜方格）上，題目的箭頭、點都看得到；學生答完一步，圖上補畫那一步的結果（和向量、分點、垂足、投影）。
- **看得到的後果**（1.2）：拖箭頭打中了，箭射進靶心、風箏飛起來；錯了，箭偏掉、風箏掉下來。
- **錯的選項絕對錯**（2）：審判卡、比大小用程式掃過。
- **共用元件**（之後 V1 先做好，各關共用）：
  - **箭頭畫布**（`arrows`）：方格上畫向量、拖箭頭的終點、首尾相接自動畫出和向量（三角形法）或平行四邊形法。
  - **斜方格**（`skew`）：以兩個不平行的向量為兩個方向的斜格子；x\vec{a} + y\vec{b} 就是在斜格子上走 x 格、y 格。
  - 直線與圓已經有的格子點、滑桿、區域塗色、光點軌跡（`trail`）、燈（`lamps`）直接沿用。

## 2. 各關規劃

講義裡**同一個題型的題目合成遊戲裡的一題**，各自變成那一題的一種變化。每一題後面括號是合進來的講義題號。

### V1 風向台（向量與座標）

**場景**：高原入口的風向台，風從各個方向吹。一支箭頭就是一陣風：方向是風往哪吹、長度是風多大。兩陣風一起吹，風箏往合起來的方向飄。

**新玩法**
- **拖箭頭**：方格上拖箭頭的終點，旁邊即時顯示 (x, y)。兩陣風首尾接起來，風箏沿著和向量飄過去。
- **首尾接龍**：一串箭頭一支接一支，看最後指到哪裡（正六邊形、平行四邊形的判定）。

- **第一章 向量的加減與線性組合**（5 題）
  1. 相等向量（A1）：平行四邊形的頂點兩兩連成向量，一樣的箭頭疊在一起，數有幾種。
  2. 正六邊形的箭頭（A3、A4）：變化 A 用 \vec{a}、\vec{b} 表示（A3）；變化 B 用對角線 \vec{u}、\vec{v} 表示（A4）。審判卡，每張畫出首尾接龍。
  3. 判定平行四邊形（A7）：審判卡。
  4. 不共線時係數唯一（A5、A6）：x\vec{AB} + y\vec{AC} = \vec{0} ⇒ x = y = 0。變化 B 先把 \vec{CB} 換成 \vec{AB} − \vec{AC}。
  5. 速算。
- **第二章 座標表示**（8 題）
  1. 用 \vec{a}、\vec{b} 拼出 \vec{p}（A24）：先在斜方格上數出大概幾格，再列聯立。
  2. 由三角形裡的已知向量求另一個（A25）。
  3. 平行又給長度，求點（A26）：單位向量 × 長度。
  4. 加權的零向量（A27）：\vec{PA} + 2\vec{PB} + \vec{PC} = \vec{0}，P 是加權平均。
  5. 單位向量（A32）。
  6. 由中點三角形求頂點、重心（A30）。
  7. 長度的最小值（A31）：|2\vec{PA} + \vec{PB}| 化成 3 倍「P 到一個點的距離」。
  8. 速算：座標加減、係數積。

### V2 分羽繩橋（分點公式）

**場景**：兩座崖之間的繩橋，繩上掛著箭羽。繩上的位置就是分點。

**新玩法**
- **繩上珠子**：沿用高一 R2「繩上珠子」的拖珠子（m : n），兩段繩子的長度比和 \vec{AP} = \frac{n}{m + n}\vec{AB} + \frac{m}{m + n}\vec{AC} 的係數跟著變（係數交叉：靠近 B 那一段越短，\vec{AB} 的係數越大）。
- **角平分**：兩支單位箭頭相加 = 菱形的對角線，剛好平分夾角。

- **第一章 分點公式**（5 題）
  1. 座標的分點（A34）。
  2. 平行四邊形裡的分點（A2）。
  3. 中點和 3 : 1 分點相減（A12）。
  4. 梯形（A11）。
  5. 速算。
- **第二章 圖形裡的分點**（5 題）
  1. 角平分向量（A33）：單位向量相加。
  2. 內切圓的切點（A8）：先用切線長求 BD : DC，再用分點。
  3. 高的垂足（A9）：先求 BD，再用分點。
  4. 由面積比找線段比（A10）。
  5. 速算。

### V3 斜紋麥田（共線與區域）

**場景**：高原上的田沿著兩個方向排成平行四邊形（地圖上已經畫了）。以 \vec{AB}、\vec{AC} 為兩個方向的斜方格，P = x\vec{AB} + y\vec{AC} 就是從 A 出發走 x 格、y 格。

**新玩法**
- **斜方格**：學生在斜方格上點出 P，旁邊顯示 (x, y)。
- **係數和 = 1 的線**：拖 P 沿著直線 BC 走，旁邊顯示 x + y 一直是 1。
- **區域長出稻子**：給 x、y 的範圍，點出 P 能到的田，對的稻子長出來、錯的枯掉（design_rules 1.2）。

- **第一章 三點共線與交點**（7 題）
  1. 共線判斷（A13）：審判卡，每張在斜方格上看三點是不是在一條線上。
  2. 什麼時候無法表示成線性組合（A28）：A、B、C 共線時斜方格塌成一條線。
  3. 動點何時共線（A29）：拖時間滑桿，看三點什麼時候排成一直線。
  4. 兩線交點（A14、A16、A18）：變化 A 中線和 DE（A14）、B 兩條線交於 P（A16）、C 斜座標法（A18）。每一題先寫「P 在第一條線上」的式子、再寫「P 在第二條線上」的式子，比較係數。
  5. 交點分線段的比（A15、A19）。
  6. 孟氏定理（A17）：審判卡。
  7. 速算。
- **第二章 係數的範圍與區域**（6 題）
  1. 三角形內部（A20）：x > 0、y > 0、x + y < 1。
  2. 七個區域（A22）：點出 P 在哪一塊。
  3. 菱形內部（A21）。
  4. 區域的面積（A23、B40、B41 第 5 小題）：變化 A 平行四邊形、B 梯形、C 用座標算。
  5. 範圍改一下，區域怎麼變（新）：拖 x、y 的範圍滑桿，看稻田的形狀跟著變。
  6. 速算。

### V4 日晷影場（內積與正射影）

**場景**：高原上的大日晷。太陽光垂直照下來，一支箭頭落在地面直線上的影子，就是它的**正射影**（呼應「光」的世界觀）。內積 = 影子長 × 另一支箭頭的長（同向是正、反向是負）。

**新玩法**
- **影子**：拖箭頭的方向，地上的影子跟著變長變短，夾角超過 90° 影子跑到反方向（內積變負）。
- **拉貨車**：力的箭頭和前進方向夾一個角，只有影子那一段在「出力」。

- **第一章 內積的意義與計算**（8 題）
  1. 觀念審判卡（A35、A36）。
  2. 內積和共線（A37）。
  3. 多邊形裡的內積比大小（A38、A39）：\vec{AB} 和各條對角線的內積 = 各條在 AB 方向的影子長比大小。
  4. 已知三邊求內積（A40）。
  5. 圖形中的內積（A43、A44、A45、A46）：變化 A 平行四邊形、B 正三角形的等分點、C 外作正方形、D 平行四邊形的對角線和等腰梯形。全部化成兩支基底向量再展開。
  6. 垂足和內積（A41）。
  7. 動點的內積（A42）：\vec{PA} · \vec{PB} = −3 是一個圓，再求到直線距離的最大值。
  8. 速算。
- **第二章 垂直、平行與正射影**（7 題）
  1. 垂直求 t（A47）。
  2. 平行求 t（A48）。
  3. 垂直加平行求向量（A49）。
  4. 拆成平行和垂直兩個分量（A50）：影子（平行分量）＋竿子（垂直分量）。
  5. 正射影的觀念（A77）：審判卡。
  6. 正射影的計算（A78、A79）。
  7. 速算。

### V5 長弓靶場（長度與夾角）

**場景**：射箭場。兩支箭夾一個角射出去，靶上的落點、箭的長度都看得到。

**新玩法**
- **拖 t 看長度**：|\vec{a} + t\vec{b}| 隨 t 變，畫面上箭頭伸縮，旁邊畫出長度平方對 t 的拋物線，最低點就是最小值。
- **量角器**：夾角用量角器讀，cos 值在旁邊。

- **第一章 求長度**（7 題）
  1. 已知內積求長度（A51）：|\vec{PQ}|^{2} 展開。
  2. 已知長度求內積（A52）。
  3. 長度的最大最小（A53）。
  4. |\vec{a} + t\vec{b}| 的最小值（A55）：拖 t。
  5. 外心的向量和（A54）。
  6. 角平分線長（A56）。
  7. 速算。
- **第二章 求夾角**（7 題）
  1. 座標求角（A57）。
  2. 已知夾角求未知數（A58）。
  3. 外作正方形（A59）。
  4. 已知長度求夾角（A60、A62、A63）：變化 A |\vec{a} − 2\vec{b}|、B |\vec{a}| = |\vec{b}| = |\vec{a} − \vec{b}|（畫出來是正三角形）、C |\vec{u}| = 2|\vec{v}| = |2\vec{u} + 3\vec{v}|。
  5. 垂直的兩支向量組合出的夾角（A61）。
  6. 看圖先猜夾角（新）：先拖量角器猜，再算 cos 確認。
  7. 速算。

### V6 四心營火（四心與面積比）

**場景**：營地裡四座營火分別點在三角形的重心、內心、外心、垂心。

**新玩法**
- **三人拉繩**：三個頂點各拉一條繩到 G，三條力的箭頭加起來剛好是 \vec{0}（重心）。
- **面積秤**：P 把三角形分成三塊，三塊的面積比 = 權重，用塗色的比例看出來。

- **第一章 重心與內心**（7 題）
  1. 重心的觀念（A64）：審判卡。
  2. 重心和內積（A65）。
  3. 三支向量和為零的變化題（A66）。
  4. 小三角形的重心（A67）。
  5. 過重心的直線和面積（A68）。
  6. 內心（A69）：審判卡，角平分線分對邊的比。
  7. 速算。
- **第二章 外心、垂心與面積比**（8 題）
  1. 四心的觀念（A70、A71）：審判卡。
  2. 外心和垂心的計算（A72）：外心用「到兩邊的投影是邊長的一半」列兩條式子。
  3. 角平分線和中垂線（A73）。
  4. 座標上的四心（A74）：審判卡。
  5. 已知關係式求面積比（A75）。
  6. 已知面積比求點（A76）。
  7. 拖點看面積比（新）：拖 P 在三角形裡走，三塊面積的比和係數一起變。
  8. 速算。

### V7 風箏航道（直線的參數式與法向量）

**場景**：風箏沿著風的方向飛。t 是時間，風箏從 A 出發、照方向向量走，走過的地方留下光點。

**新玩法**
- **t 滑桿**：拖 t，點沿著直線走，走過的地方留下光點（`trail`）；t 的範圍決定是線段、射線還是整條直線。
- **法向量**：直線上插一支和它垂直的箭頭，ax + by = c 的 (a, b) 就是這支箭頭。

- **第一章 直線的參數式**（6 題）
  1. 線段的參數式（B1）：審判卡，每張拖 t 看光點走過哪一段。
  2. 射線是不是同一個圖形（B2）。
  3. 線段上的格子點（B3）。
  4. 兩直線的交點（B9）。
  5. 沿著向量前進碰到直線（B10）。
  6. 速算。
- **第二章 法向量與方向向量**（11 題）
  1. 用法向量寫直線（B4）。
  2. 方向向量和直線上的點（B5）。
  3. 和直線平行的向量（B6）。
  4. 線段參數式的審判卡（B7）。
  5. 直線換成參數式（B8）。
  6. 點到直線的距離（B11）。
  7. 沿直線走固定距離（B15）。
  8. 菱形的頂點（B16）。
  9. 正方形的頂點（B17）：旋轉 90° 的向量。
  10. 平行、垂直、夾角綜合（B18）。
  11. 速算。

### V8 鏡光峽谷（投影、反射與夾角）

**場景**：峽谷兩側的岩壁像鏡子。光打到岩壁反射，入射角 = 反射角（呼應「光」的世界觀）。

**新玩法**
- **反射光**：拖鏡子（直線）的角度，入射光、反射光跟著畫；對齊出口就過關。
- **對稱點**：把 B 翻到鏡子另一邊，A 到 B' 的直線最短。

- **第一章 參數式求極值與投影**（7 題）
  1. 線段上一次式的最大值（B12）：代參數式變成 t 的一次函數，端點最大。
  2. 平方和的最小值（B13）：變成 t 的二次函數。
  3. 內積的最小值（B14）。
  4. 垂足和 PA + PB 的最小值（B19）：對稱點。
  5. 向量在直線上的正射影（B21）。
  6. 投影點（B22）。
  7. 速算。
- **第二章 反射與直線的夾角**（6 題）
  1. 反射求鏡子的斜率（B20）：鏡子平分入射光和反射光的夾角。
  2. 兩直線的銳角交角（B23）。
  3. 參數式的交點和夾角（B24）。
  4. 已知斜率求交角（B25）。
  5. 已知夾角求直線（B26）。
  6. 速算。

### V9 拉弦試煉（柯西不等式）

**場景**：長弓的弓弦。兩支箭（向量）方向對齊的時候，弦拉得最緊。

**新玩法**
- **轉箭頭**：|\vec{a}|、|\vec{b}| 固定，轉 \vec{b}，看 \vec{a} · \vec{b} 跟著變：同向最大、反向最小。這就是 |\vec{a} · \vec{b}| ≤ |\vec{a}||\vec{b}|。

- **第一章 柯西不等式**（6 題）
  1. 已知一次式求平方和的最小值（B27）。
  2. 先配方再用柯西（B28）。
  3. 內積的形式（B29）。
  4. 已知長度求內積的範圍（B30）：轉箭頭。
  5. 倒數型（B32）。
  6. 速算。
- **第二章 三角不等式與應用**（5 題）
  1. 垂直條件下的最小值（B31）。
  2. 不等式審判卡（B33）。
  3. 三角形內的距離（B34）：面積寫成一次式，再用柯西。
  4. 半圓湖游泳（B35）：時間寫成 sin、cos 的一次式。
  5. 速算。

### V10 雙線織坊（面積、行列式與克拉瑪）

**場景**：織布工坊，兩支向量張開成一塊平行四邊形的布。行列式 = 布的面積（帶方向：翻過來是負的）。兩條直線（兩條線頭）交在哪裡，就是聯立方程式的解。

**新玩法**
- **張開的布**：拖兩支箭頭，張出的平行四邊形塗色，面積 = 行列式的絕對值；兩支箭頭的順序換過來，布翻面變色（負號）。
- **兩條直線**：兩條直線畫在方格上，交點就是解；Δ = 0 時兩條平行（無解）或疊在一起（無限多解）。

- **第一章 面積公式與二階行列式**（10 題）
  1. 向量式求面積（B36）。
  2. 面積的綜合審判卡（B37、B38）。
  3. 外作正方形求面積（B39）。
  4. 行列式的值（B44、B45）：變化 A 大數字（先化簡再算）、B 根號。
  5. 行列式的整數解（B46）。
  6. 行列式的性質（B42、B43、B48）：一張布的邊伸長、加上另一邊的倍數，面積怎麼變。
  7. 已知面積求點（B47）。
  8. 張成的平行四邊形面積（B60、B61）。
  9. 行列式和三角形面積（B49 的 D、E 選項拆出來）。
  10. 速算。
- **第二章 克拉瑪法則**（9 題）
  1. 克拉瑪法則求解（B52）。
  2. 已知三個行列式求解（B53）。
  3. 已知解，求新方程組的解（B55、B56）。
  4. 行列式綜合審判卡（B49、B51、B54）。
  5. x\vec{a} + y\vec{b} = \vec{c} 有幾組解（B50）：兩支箭頭平不平行。
  6. 討論解的個數（B57）：拖 a，看兩條直線交於一點、平行、重合。
  7. 無解（B58）。
  8. 無限多解（B59）。
  9. 速算。

### 彩蛋：風箏的比例（A80～A84）

高原上的風箏攤：A 系列的風箏每對折一次長寬比不變（√2）、黃金比例的風箏最好看。做成 2～3 個地圖彩蛋（像高一的骰子攤車），獎勵星塵：
- A 系列紙張（A82）：A5 對折成 A6，求尺寸。
- 黃金矩形（A80）：五種長寬比，挑最接近黃金比例的。
- 正五邊形的對角線（A81）：長度乘積。
- 圓角三角形（A83）、單點透視（A84）：圖比較複雜，草案先不收。

## 3. 觀念卡、速算、終焉之塔

- **觀念卡**（`concepts_vec2.gd`）：每關 3～5 張。例如「\vec{AP} = x\vec{AB} + y\vec{AC}，P 在直線 BC 上 ⇔ x + y = [ ]」、「\vec{a} · \vec{b} < 0 ⇔ 夾角是 [ ] 角」、「行列式 = 0 ⇔ 兩支向量 [ ]」。每張至少一塊干擾積木。
- **速算**：每章一題（上面各章最後一題）。
- **終焉之塔**：十關做完之後再規劃。講義裡大雜燴的綜合題（例如 B41 的六個小題）可以搬到塔裡。

## 4. 製作順序（建議）

1. **共用元件**：箭頭畫布、斜方格（V1、V3、V10 都要用），先在 V1 做好。
2. V1 → V2 → V3（3-1 先開放一部分也可以玩）。
3. V4 → V5 → V6（3-2）。
4. V7 → V8 → V9 → V10（3-3）。
5. 彩蛋、觀念卡、終焉之塔。

每一關開工前先寫設計稿（`docs/vec2_vN_design.md`：每一題、每一步、數字驗算），給使用者確認再做。
