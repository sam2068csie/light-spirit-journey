# 數與式：延後到終焉之塔的題型

講義（高偉數學・數與式）有、但主線關卡沒有放的題型。做塔的時候從這裡挑。每做完一關就更新。
單元規劃見 `docs/num_plan.md` 第 3 節。

**不收**：三項的算幾不等式（a^{2}b 型），主線和塔都不放（使用者 2026/11/13）。

## R1 風車小數（重點一）

- 1 ≤ n ≤ 10，\frac{1}{n} 化成循環小數時，循環節最多幾位（講義「循環小數綜合題」選項 E）
- 循環小數夾範圍的變化型：兩個未知數字、範圍的端點也是循環小數
- 分點比大小的根號版（√5、√7 之間的加權平均排順序）：R2 第二章會做，塔可以出更複雜的版本

## 之後的關卡

- a、b 無理，a + b、ab 有理 ⇒ a^{3} + b^{3} 有理（R5 移過來，使用者 2026/11/13）
- 反證法進階版：證明 ∛2 + √5 是無理數（要展開 (P − √5)^{3}）
- 三層以上的雙重根號、√(a + 2√(b + √c)) 這種要剝三次的
- 雙重根號相加後再代入高次式：a = √(7 + √33) + √(7 − √33) 這一型
- a^{5} + b^{5}（用 a^{2} + b^{2} 和 a^{3} + b^{3} 組出來）
- (a − b)^{3} + (b − c)^{3} + (c − a)^{3} 的分解
- 等號成立反推 (x, y)：4x + y + \frac{9}{x} + \frac{4}{y} = 16 這一型
- 有理數的圖形問題（半圓裡哪些線段長是有理數）
- 根號化簡後的絕對值：√(25x^{2} − 10x + 1) = |5x − 1| 要看 x 的範圍
- 整數分散性：7|a − 3| + 3|b + 5| + \frac{1}{3}|c − 7| = 2
- 三角不等式的根號版：√(4x^{2} − 12x + 9) + … ≤ …
- 反證法進階、||x + 1| − |x − 2|| ≤ x 這種套兩層的分段
- 分段討論畫圖：三個以上絕對值加一次式的函數圖形
- 次序不等式的複合式：xy − 3x − 2y 的範圍
