# 平面向量：延後到終焉之塔的題型

做關卡的時候，太長、條件太多、適合當綜合題的講義題目記在這裡，八關做完之後規劃終焉之塔再用。

## B18 平行、垂直、夾角綜合（V6，2026/11/22 使用者決定移到塔）

講義：O 是原點，\vec{OA} 平行 L1：2x + 6y = 7 且 |\vec{OA}| = √10，B 在 L2：x − 2y + 10 = 0 上且 \vec{OB} ⊥ L2，\vec{OA} 和 \vec{OB} 夾銳角，\vec{OC} = \vec{AB}，求過 C 且和 \vec{OC} 垂直的直線（x + 3y = 10）。

V6 設計時準備好的步驟（數字已驗算，`tools/vec2/verify_v6.py` 第 11 段）：
① B = O 到 L2 的垂足 ② A（兩個可能裡，和 \vec{OB} 內積是正的那個）③ \vec{OC} = \vec{AB} ④ 直線 \vec{OC} · (x, y) = |\vec{OC}|^{2}

| | 第 1 組 | 第 2 組 |
|---|---|---|
| 題目 | L1：3x + y = 5、\|\vec{OA}\| = √10，L2：x + 2y − 10 = 0 | L1：2x − y = 7、\|\vec{OA}\| = √5，L2：3x − y + 10 = 0 |
| ① B | (2, 4) | (−3, 1) |
| ② A | (−1, 3)（(1, −3) 的內積是 −10） | (−1, −2) |
| ③ \vec{OC} | (3, 1) | (−2, 3) |
| ④ 直線 | 3x + y = 10 | 2x − 3y + 13 = 0 |

看得到的後果：兩個可能的 A 都畫出來（淡淡的），答對那一個亮、和 \vec{OB} 之間標銳角；\vec{AB} 平移到 O 變成 \vec{OC}；直線畫出來，\vec{OC} 是它的法向量。

## B41 平行四邊形的綜合計算（V7，2026/11/22 設計時移到塔）

講義：A(3, 2)、B(5, 1)、C(4, 3)，六個小題：(1) 平行四邊形 ABCD 的 D (2) \vec{AB} · \vec{AC} (3) \vec{AC} 在 \vec{AB} 上的正射影 (4) △ABC 的面積 (5) \vec{AP} = r\vec{AB} + s\vec{AC}、−1 ≤ r ≤ 2、1 ≤ s ≤ 3 的區域面積 (6) \vec{QA} + \vec{QB} + \vec{QC} = \vec{0} 時 △QBC 的面積。

每一小題前面幾關都練過了（V2 平行四邊形、V3 內積和正射影、V5 重心的面積、V7 面積公式）。V7 第 16 題第 2 組只收第 (5) 小題。整題六小題連在一起，適合當塔的綜合題。
