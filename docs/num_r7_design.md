## 場景與新元件

舞台是方格麥田，田埂把麥田切成一塊一塊。

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **天秤**（新：`scale`） | 第 1 題 | 天秤左右兩盤放等號兩邊的式子，下面一排數字卡（a, b) = (1, 1)、(2, 1)、(1, −1)、(2, −1)、(0, 1)。點一張數字卡，兩盤上出現代進去的值，不一樣重天秤就歪掉。數字卡隨便點、不扣分，點完再判 ○ ✕。 |
| **項的卡片**（新：`ctap`） | 第 2 題 | 兩個括號的每一項是一張卡片。點出「在兩個括號裡正負號相反的那幾項」，點對的卡片被一個框框在一起，變成一整塊 A。 |
| **補成正方形**（新：`sqtap`） | 第 3 題 | 兩塊大麥田：(x^{2} + y^{2})^{2} 和 (x^{2} − y^{2})^{2}。旁邊畫出要拿掉的部分：一塊是 9 個 x^{2}y^{2} 小方格，剛好排成 3 × 3 的正方形；另一塊是 5 個小方格，排不成正方形。點出「拿掉的剛好是正方形」那一塊。 |

| **梯子**（新：`gtap`） | 第 11、12、14 題 | 梯子的每一階寫一個式子（t + \frac{1}{t}、t^{2} + \frac{1}{t^{2}}、t^{3} + \frac{1}{t^{3}}…），算出來的值寫在階上。爬新的一階之前，先點出要踩的是哪一階（第 14 題的 a^{5} + b^{5} 要踩兩階）。答對光靈往上爬一格。 |
| **水槽**（現有的 `slide`） | 第 16 題 | 四個水槽，水位是 (a − 1)^{2}、(b − 2)^{2}…，四個滑桿調 a、b、c、d。全部放空，水位加起來才會 ≤ 0。 |
| 審判卡、填空、選擇 | 其他步驟 | 現有的 |

## 每一步為什麼必要（1.7）

- 第 1 題：判 ✕ 的卡要改對，才知道錯在哪裡。
- 第 2 題：① 是這題的方法（看成一整塊），② ③ 是展開。
- 第 3 題：① 是關鍵（加還是減 2x^{2}y^{2}），② ③ 是平方差。
- 第 4 題：① 配對就是方法，② 是答案。
- 第 5 題：① ② 各分解一個括號，③ 合起來（係數要提出來）。
- 第 6 題：① 立方差的有理化是新的，② ③ 各化簡一項，④ 合起來。
- 第 7 題：① ② 是 R6 的複習（很快），③ 是新的（根號裡沒有 2√ 要先乘 2）。
- 第 8 題：① 是用這個公式的條件。
- 第 10 題：① ② 求 a、b，③ 先分解（不分解就要硬算三次方），④ 是答案。
- 第 11、12、14 題：每一階都是題目問的值，點要踩的階就是方法。
- 第 13 題：① 是關鍵（a 本身很難算，a^{2} 很漂亮），② 讓式子只剩 a^{2}。
- 第 15 題：① 是這題的關鍵（絕對值拿掉要看正負），② ③ 是答案。
- 第 16、17 題：① 配方，② 平方和是 0 ⇒ 每一個都是 0，③ 是答案。

## 錯的答案怎麼確保「絕對錯」

- 等式審判的錯卡：程式確認數字卡裡至少有一張讓兩邊不相等。
- 第 3 題：拿掉的部分 5x^{2}y^{2}、17x^{2}y^{2}，5、17 不是平方數，分解不下去。
- 第 6 題的錯選項：(∛6 + 1)(∛{36} + ∛6 + 1)、(∛{36} − 1)(∛{36} + ∛6 + 1) 乘開都還有立方根。
- 第 12 題 ⑤：t 和 \frac{1}{t} 對調也滿足 t + \frac{1}{t} = √6，t − \frac{1}{t} 變號。
- 籃子：配對只有一種（相乘才會消掉中間項），正負號在整個範圍裡都不變（程式在範圍裡隨機代 100 個數確認）。

## 判分

- 第 2 題 ② 的 3y − 2 也可以寫成 2 − 3y（平方一樣），兩種都算對。
- 第 7、11 題的根號照題目的順序填。
- 第 17 題 ③ 的 x = −\frac{3}{2} 可以填 −3/2 或 −1.5。

## 觀念卡（4 張）

1. 立方和、立方差：a^{3} + b^{3} = (a + b)(a^{2} [−] ab + b^{2})、a^{3} − b^{3} = (a − b)(a^{2} [+] ab + b^{2})。（干擾：同號）
2. 看成一整塊、湊平方差：(x + A)(x − A) = x^{2} − [A^{2}]；x^{4} + kx^{2}y^{2} + y^{4} 補成 (x^{2} ± y^{2})^{2}，拿掉的要是 [平方]。（干擾：2A、相加）
3. 倒數的梯子：x^{2} + \frac{1}{x^{2}} = (x + \frac{1}{x})^{2} − [2]、x^{3} + \frac{1}{x^{3}} = (x + \frac{1}{x})^{3} − [3](x + \frac{1}{x})。（干擾：+ 2、1）
4. 平方和是 0：實數的平方 [≥ 0]，加起來 ≤ 0 ⇒ 每一個都是 [0]；p^{2} + q^{2} + r^{2} − pq − qr − rp = \frac{1}{2}[(p − q)^{2} + …]。（干擾：> 0）

## 速算

- 第 9 題：(px ± q)^{2}、(px ± q)^{3} 的某一項係數，或 a^{3} ± k^{3} 分解出來的中間項。按鈕三個：答案、正負號相反、忘了乘 2（或 3）。
- 第 18 題：x + \frac{1}{x} = k（整數或 √n）求 x^{2} + \frac{1}{x^{2}}，按鈕：k^{2} − 2、k^{2} + 2、k^{2}；a + b、ab 求 a^{2} + b^{2}，按鈕：s^{2} − 2p、s^{2} + 2p、s^{2} − p。
