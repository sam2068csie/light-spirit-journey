# 高一「直線與圓」：暫不收錄、之後放進終焉之塔的題型

講義（高偉數學 高一上二段加強輔導班）裡有，但**沒有放進 C1～C8 主線關卡**的題型都記在這裡。
直線與圓的終焉之塔在 `line_tower_bank.gd`（已做好 30 層，見下一節）；之後加題從這份清單挑。
每做完一關就更新這份文件：新增延後的題型，或把已經收錄的劃掉（寫上收錄在哪裡）。

數字和情境照慣例要重新設計，不照抄講義。

## 來自 C1「坐標燈標」（3-1 重點一：平面坐標）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 外角平分線分點 | ∠A 的外角平分線交直線 BC 於 D（外分點） | C1 只做內分；外分要先懂「外分點」，適合和分點公式一起當綜合題 |
| 菱形求第四頂點 | 已知三頂點、對角線互相垂直平分 | 和平行四邊形第四點重複度高，塔裡當變化題 |
| 等距點應用題 | 飛機等速、飛彈同速擊中（到兩點等距 ⇒ 中垂線上） | 文字情境長，適合塔裡的應用題 |
| 已知垂直求面積最大值 | \ol{PR} ⊥ \ol{QR}，P 在 x 軸、Q 在 y 軸，求 △OPQ 面積最大 | 要配方或算幾，跨單元 |
| 垂心在原點求面積 | 已知垂心是原點，反求頂點坐標再算面積 | 三心＋垂直的綜合 |
| 從圖形比斜率（正多邊形） | 正五邊形中心在原點，各邊斜率誰最小 | 需要較複雜的圖，塔裡當看圖題 |
| 鳶形的斜率關係 | 鳶形四邊的斜率關係、乘積 | 綜合題 |

## 來自 C2「直線棧橋」（3-1 重點二：直線方程式）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 平行四邊形 I | 已知兩邊所在直線和一個頂點：判斷象限、內部格子點、y = mx 的範圍 | 跨平行線、交點、區域，步驟長 |
| 平行四邊形 II | 已知直線 AB 和 ∠B 的平分線，求 \ol{BC} 的斜率 | 要用角平分線的對稱（C3 之後才學） |
| 截距式：過定點、面積最小 | 過定點的直線和兩正半軸圍成的三角形面積最小 | 要用算幾不等式（跨多項式單元） |
| 截距式：周長 | 截距式的直線和兩軸圍成三角形的周長 | 綜合題 |
| 角平分線分點＋面積平分線 | 先用角平分線分點，再找把面積平分的直線 | C1＋C2 的綜合 |
| 直線與正方形恰交兩點 | 過定點的直線和正方形恰有兩個交點，求斜率範圍 | 斜率範圍的進階版 |
| 三直線圖形判斷聯立解數 | 看三條 y = m_{i}x + k_{i} 的圖，判斷兩兩聯立的解的個數 | C2 只做了比 m、k，塔裡接續 |

## 來自 C3「鏡面渡口」（3-1 重點三：極值、3-2 距離）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| AP + PQ + QB 最小 | P 在 x 軸、Q 在 y 軸，A、B 在第一象限 | 和 C3 撞球（兩次對稱）同一個觀念，塔裡當綜合題（使用者 2026/11/06 同意） |
| 根號式差的絕對值最大 | \|√((x − a)^{2} + b^{2}) − √((x − c)^{2} + d^{2})\| 的最大值 | C3 只做根號式的和；差的版本當塔裡的進階題 |
| 正三角形外心到一邊的距離 → 面積 | 點到直線距離的應用 | 綜合題 |
| 已知距離比反求參數 | 直線交 \ol{AB}，已知分割比求直線的係數 | C3 只做「由直線求比」，反過來的放塔裡 |
| 已知截距差求平行線距離 | 兩平行線的截距相差多少，求距離 | 變化題 |
| 一般三角形的內心、旁心 | 三邊都是斜線的三角形，用角平分線方程式求內心 | 計算量大，C3 只做直角三角形 |

## 來自 C4「分光稻田」（3-2 重點三：二元一次不等式）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 三線圍成三角形的內角平分線 | 先判斷哪一條是內角平分線（看第三個頂點在哪一側） | C3＋C4 的綜合（從 C3 移過來，C4 學完同側異側才能做） |
| 最大內切圓的應用題（非直角三角形區域） | 區域是一般三角形，求能放進去的最大圓 | C4 只做直角三角形的區域 |
| 直線 y = m(x + 5) − 2 通過區域求 m 的最大值 | 和 C4「照進田裡的光」同觀念，但只問一邊 | 變化題 |
| 由圖反求含參數的聯立不等式 | 兩條以上的邊界都有參數 | C4 只做一條邊界 |

**不收錄：線性規劃**（在區域裡求 ax + by 的最大、最小值）。使用者 2026/11/06 決定，主線和塔都不放。

## 來自 C5「圓規工坊」（3-3 重點一：圓方程式）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 和兩平行線相切、圓心在直線上 | 半徑 = 兩平行線距離的一半，圓心在中間那條線和指定直線的交點 | 跨 C3（平行線距離）＋C5 |
| 過兩點且和直線相切 | 圓心在中垂線上，再用 r = d(K, L)，要解二次方程式 | 計算量大 |
| 過四點求圓（四點共圓） | 先用三點求圓，再驗證第四點 | 綜合題 |
| 從切線反求圓 | 過一點、和直線切於某點 | 圓心在切點的垂直線上＋中垂線，綜合題 |
| 圖形判斷 | 直線和圓的係數連動，判斷哪幾個圖可能 | 看圖題，跨 C2＋C5 |
| 動點 (a + 2)^{2} + (b − 1)^{2} 的最小值 | (a, b) 在圓上，求到定點距離平方的最小值 | 點與圓的應用 |
| 圓和兩軸的交點在不同象限，求範圍 | 令 x = 0、y = 0，看兩根的正負 | 跨多項式（根與係數） |

**C5 已收錄**（不用再放塔）：恰可決定一圓（使用者 2026/11/06 決定放 C5）、和兩軸相切過一點（兩個圓都畫）。

## 來自 C6「割弦漣漪」（3-3 重點四：圓與直線的相交情況）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 圓上到直線距離為 k 的點，參數在圓或直線裡 | 例如半徑是 r、直線含 k，問恰有 3 個點時的條件 | C6 只做固定的圓和直線（k 是距離）；參數混在一起的放塔裡 |
| 圓上到直線距離為整數的點 | 數出距離是 1、2、3… 的點各有幾個再加起來 | 是 C6「離光線兩步遠的燈」的延伸，計數題 |
| 弦長＋分割比 | 直線被圓截出的弦，再問直線把某線段分成的比（C3 距離比） | C3＋C6 的綜合 |
| 過定點、弦長固定，圓心不在原點 | 設斜率後的距離方程式係數比較大 | C6 只做圓心在原點的版本（計算量） |
| 圓上的點和定線段圍成的四邊形面積最大 | 拆成兩個三角形，各自用最遠距離 | C6 只做三角形 |
| 半圓與直線：參數在常數項 | 例如 √(4 − x^{2}) = x + k（平行移動的直線） | C6 做的是繞定點轉（斜率）；平移的版本當變化題 |

**C6 已收錄**：半圓與直線的交點個數（使用者 2026/11/07 決定放 C6）。不用判別式（使用者 2026/11/07 決定），主線和塔都一律用 d 和 r 比。

**留給 C7「切線燈環」**（需要切線，不放塔）：光的反射與切線、影長、彩虹的光線、切點弦（極線）。已收錄在 C7（見下一節）。

## 來自 C7「切線燈環」（3-3 重點五：切線問題）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 參數藏在一般式裡的切線 | 點在圓上，先代入求出參數，再求切線 | C7 的圓都是給好的，先求參數的放塔裡 |
| 過圓外一點的切線，圓心不在原點、數字大 | 設斜率後的二次方程式係數大 | 計算量大，C7 只做好算的數字 |
| △ABC 外接圓、△KBC 面積 | 兩條切線＋切點弦圍成的圖形，求面積或外接圓 | 綜合題（C5 求圓＋C7 切線） |
| 反射問題：鏡面是斜線 | 光經過一條斜的直線反射後和圓相切 | C7 只做鏡面是 x 軸；斜的鏡面要先求對稱點（C3＋C7） |
| 兩圓的內公切線 | 內公切線的交點是兩圓心的內分點 | C8 只做外公切線，內公切線放塔裡 |

**C7 已收錄**：從切線反求圓（C5 留下來的，放在 C7「照訂單做燈環」）、切點弦（兩條切線的交點）、反射、影長、圓內反射。

**不收錄：圓冪**（切線段長² = 割線段的乘積、最近 × 最遠）。使用者 2026/11/07：課綱刪掉了，主線和塔都不放。切線段長只用畢氏定理。

## 來自 C8「軌跡星環」（3-3 重點二：圓系、重點三：軌跡）

| 題型 | 講義的方向 | 為什麼延後 |
|---|---|---|
| 阿波羅尼斯圓求式子的最大值 | P 在阿波羅尼斯圓上，求 ax + by 或 \ol{PQ} 的最大值 | C8 只做到「圓上的點到定點最遠」，其他式子的最大值放塔裡 |
| 軌跡綜合選擇題（多選） | 五個敘述各判斷是不是圓 | C8 拆成四個單選，多選的版本放塔裡 |
| 圓系：圓心在指定直線上、過圓與直線的交點 | C + kL = 0 的圓心代進直線求 k | C8 只做「過一點」和「圓心在 y 軸上」，其他條件當變化題 |
| 動點在直線上的軌跡 | 例如 P 在直線上走，\ol{OP} 的中點軌跡（還是直線） | 不是圓，放塔裡當對照題 |

**C8 已收錄**：圓系（使用者 2026/11/07 決定放 C8）、公切線（外公切線，放 C8）、兩圓的公共弦。

## 其他關之間的約定（不是塔的題目，但做後面的關要記得）

- C3「距離比 = 分割比」只用**看圖**判斷 A、B 在直線的同側或兩側，**還沒有提到代入的正負**。
  C4（二元一次不等式）正式教「代入 ax + by + c 看正負 ⇒ 同側、異側」，第一題最後一步回頭引用了 C3 這一題（已完成）。
- C3 的內心題只做直角三角形（兩邊在坐標軸上）。一般三角形的內心（三條邊都要用距離公式）放塔裡。

## 玩法的原則（使用者 2026/11/06 試玩後決定）

完整的出題、玩法、寫法、版面規則和交付前檢查清單在 `docs/design_rules.md`。

- **不要用「直接挑戰」**（一開始只問最後答案、卡住才展開步驟）：學生會覺得「我沒辦法一步算出來，我好笨」。
- **看得到的後果**是好的：答對了世界有反應（稻子長出來、光照到渡船），答錯了看到錯的結果（田枯掉、光打歪了），不只是紅字。
- 「先動手、再解釋」（例如 C3 先瞄準光線，打中了再問為什麼）保留試作。

## 收錄規則（做塔的時候注意）

- 一題可以跨好幾關的觀念，這正是塔的用途。
- 計算太複雜的以觀念為主、計算為輔（和主線一樣）。
- 圖不放中文標籤；選項一行放得下；錯的選項要絕對錯。
