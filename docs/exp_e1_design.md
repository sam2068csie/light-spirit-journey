## 場景與新元件

舞台是峽谷的岩壁：岩層一層一層往下，**每往下一層落差加倍**。指數就是「第幾層」：乘法 = 再往下走、除法 = 往上爬，負指數在岩壁上方，分數指數停在兩層之間。岩壁底下是回音岩洞、溫泉的菌絲、會發光的礦石。

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **光柱積木**（新：`pillar`） | 第 3、4、5、7、8 題 | 岩壁上每個質數一根光柱（2、3、5、7）。題目的每一張數字卡，學生拖到它的質數柱上（6、12 這種要拆的卡，拖到柱子上會自己裂成兩塊，各飛去一根）。放對了，柱子自己長高（負的往下長）；放錯了卡片彈回來，寫出原因（「243 = 3^{5}」）。標著 ? 的「關鍵卡」要先填指數才會長。最後讀柱子的高度就是答案。**學生做判斷，加總交給畫面。** |

| **賽跑**（新：`race`） | 第 19 題 | 四條光條（甲、乙、丙、丁用顏色和符號區分，不寫中文），各自照「每 n 天變 n 倍」一起長。滑桿是天數，光條每到自己的結算日跳一次。 |

**答對時**：光柱的那一層岩壁亮起來；回音往上傳；菌絲長滿溫泉；礦石共鳴。
**答錯時**：卡片彈回、寶石不亮、光柱縮回原來的高度。

## 每一步為什麼必要（1.7）

## 錯的答案怎麼確保「絕對錯」

- 第 1 題：0^{0}、0 的負次方、負數的無理數次方沒有定義（課本的定義）。**負數的分數次方（例如 (−8)^{\frac{1}{3}}）不出題**，課本沒有定義分數次方的負底數，避免爭議。
- 第 2 題的錯誤原因：4^{\frac{1}{2}} 只有 2（不是 ±2）、(−2)^{2} = 4，都是真的錯。
- 第 7 題 B、第 8 題 C、第 17 題的錯誤選項：程式代數字確認不相等（`verify_e1.py`）。
- 第 10 題 B 的錯卡：a^{2x} + a^{−2x} = 14，不是 16。
- 第 16 題錯卡：90 年後 a = 2^{−7}、b = 2^{−6}，不一樣亮。
- 第 19 題錯卡：乙的速率 3^{\frac{1}{3}} 比甲的 2^{\frac{1}{2}} 大，第 3 天之後乙一直領先甲。

## 判分

- 第 4 題答案可以填分數或小數（小數鍵盤用 `dot`）。
- 第 7 題 A ③ \frac{27}{√7} 和 \frac{27√7}{7} 都算對（引擎會比根號）。
- 第 8 題 C ① 4 和 3 可以對調（`groups`）。
- 第 12 題 A ② 填 2√3 或 √12 都對（± 格子比絕對值）。
- 第 18 題 B ② 填 0.36 或 \frac{9}{25} 都對。

## 觀念卡（5 張）

1. 指數律：a^{r} · a^{s} = a^{[r + s]}、(a^{r})^{s} = a^{[rs]}，底數要 [大於 0]。（干擾：rs、r + s、不等於 0）
2. 有意義：0^{0} 和 0 的 [負數] 次方沒有意義，負數的 [無理數] 次方沒有意義。（干擾：正數、整數）
3. 回音階梯：(a^{\frac{1}{2}} + a^{−\frac{1}{2}})^{2} = a + a^{−1} + [2]；設 t = a^{\frac{1}{2}} + a^{−\frac{1}{2}}，a^{\frac{3}{2}} + a^{−\frac{3}{2}} = t^{3} − [3t]。（干擾：1、3t^{2}）
4. 倍增與減半：每 n 天變 k 倍，t 天後變 k^{[\frac{t}{n}]} 倍；半衰期 T，t 年後剩 (\frac{1}{2})^{[\frac{t}{T}]}。（干擾：\frac{n}{t}、kt）
5. 指數比大小：同底數（底數 > 1）比 [指數]；同指數比 [底數]，比不了就化成同一個次方。（干擾：係數）

## 速算

- 第 9 題：2^{\frac{1}{3}} × 2^{\frac{1}{6}}（按鈕：√2、2^{\frac{1}{18}}、∛2）、∛{x^{2}} = x^{?}（\frac{2}{3}、\frac{3}{2}、6）、4^{x} = 3 ⇒ 8^{x}（3√3、\frac{9}{2}、27）。產生時確認三個不一樣。
- 第 20 題：每 n 天變 k 倍，t 天後（按鈕：k^{\frac{t}{n}}、k^{\frac{n}{t}}、\frac{kt}{n}）；a + a^{−1} = m ⇒ a^{2} + a^{−2}（m^{2} − 2、m^{2} + 2、m^{2}）。
