## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題都一步一步帶。講義的「下列哪些正確」五選題，拆成一張一張審判卡（○／✕），✕ 的卡再追問「舉一個反例」。
- **學生自己列式**（1.4）：算式用填空模板挖空，例如 √(9 + 2√14) = √[ ] + √[ ]（兩格可互換，用 `groups`）。
- **看得到的後果**（1.2）：每關有自己的「世界反應」，寫在各關的「玩法」。圖上不寫中文（4）。
- **錯的選項絕對錯**（2）：每一個選項都想「有沒有哪個情況它會對」。比大小、不等式性質這種題目，用程式掃一大堆數字確認錯的選項真的會錯。
- **判分寬鬆**（2.5）：分數、小數、沒化簡的根號都算對，√80 = 4√5 引擎已經會比。兩根、因式的順序用 `groups`，比例式用 `prop`。
- **證明題**：反證法改成「把證明的句子排順序」（引擎已有 `order`），再選「矛盾出在哪一句」。
- **計算太重的放塔**（2）：三層以上的根號、五次方放終焉之塔（第 3 節）。
- **是非題位置固定**：「有理數／無理數」的二選一要加進 `choice_order.gd` 的 PAIRS，有理數固定在左。
- **題數**：每章 12 題以內。下面每章後面的（約 N 題）是預估，做的時候再依份量調整。

## 2. 各關規劃

### R1 風車小數（重點一：數線）

**玩法**：原野上的風車，每片扇葉寫一個數字，循環節就是扇葉。答對時風車轉起來，數字一圈一圈接成小數。數線柵欄上，點對位置會亮起一根燈柱。比大小時，兩個數落在數線上，大的在右邊亮起來。

- **第一章 循環小數與有限小數**（約 11 題）
  - 有理數的稠密性：兩個數之間「有無窮多個有理數」的判斷卡。
  - 循環小數化分數：把「乘 10 的幾次方、相減」的式子挖空讓學生列。
    範例：1.2\ol{36} → 1000x − 10x = 1236.\ol{36} − 12.\ol{36} → x = \frac{1224}{990} = \frac{68}{55}（已驗算）。
  - 循環小數夾範圍：一個帶未知數字 a 的循環小數夾在兩個分數之間，求 a（數字之後用程式找唯一解）。
  - 分數化循環小數：用長除法，餘數重複的那一刻風車開始轉。
  - 有限還是循環：先約分，再看分母的質因數。畫面上分母拆成質因數積木，和分子約掉的那幾塊消失，只剩 2、5 時燈亮（有限），剩其他質數時風車一直轉（循環）。
    範例：\frac{21}{56} = \frac{3}{8}（有限），\frac{9}{42} = \frac{3}{14}（循環）。重點是「看起來有 7，約分後就沒了」。
  - 有限小數進階：分子有未知數字 a，讓約分後只剩 2、5（之後用程式掃 a = 1～9 確認答案唯一）。
  - 第 n 位數字：先找循環節長度，再算餘數。範例：\frac{1}{7} 的第 100 位：100 = 6 × 16 + 4，第 4 個數字是 8（已驗算）。
  - 循環小數綜合判斷卡：0.\ol{9} = 1、循環節最多幾位……
- **第二章 尺規作圖與比大小**（約 12 題）
  - 尺規作圖（比例）：平行線把線段截成等比例，求數線上點的坐標。
  - 尺規作圖（根號）：拖動直徑上的點 C，半圓上的垂線 \ol{CD} = √ab。順便看到 \ol{CD} 永遠不超過半徑 \frac{a + b}{2}（R4 算幾不等式會再用）。
  - 分數比大小：通分子、或比 1 − 分數。
  - 根號相加：平方比較。範例：√11 + √3 和 2 + √10，平方後 14 + 2√33 和 14 + 2√40，後者大（已驗算）。
  - 根號相減：有理化成 \frac{2}{√15 + √13} 和 \frac{2}{√11 + √9}，分母大的小（已驗算）。
  - 四捨五入反推：分子分母和固定、四捨五入後是某個數，求這個分數。
  - 不等式性質審判卡＋反例：「a > b、c > d ⇒ ac > bd」✕（反例用負數），「a > b ⇒ \frac{1}{a} < \frac{1}{b}」✕（a、b 異號）。
  - 由 abc < 0、a + b + c < 0 等條件判斷正負（一步一步：先判斷有幾個負的）。

### R2 繩上珠子（重點二：分點公式）

**玩法**：兩根柵欄柱之間拉一條繩子，拖動上面的珠子 P，讀數顯示 \ol{PA} : \ol{PB}。答對時珠子定住、發光。外分點在繩子延長出去的地方，繩子會跟著拉長。

- **第一章 內分與外分**（約 8 題）
  - A(−2)、B(8)，\ol{AC} : \ol{BC} = 3 : 2：內分 C = 4，外分 C = 28（已驗算）。兩個都要找到（題目說「所有」）。
  - 2|x − a| = 3|x − b| 的判斷卡：P 在哪裡、比例是多少。
  - 應用：地圖縮小比例（三個地點按比例畫到數線上，新的情境）、追趕問題（兩人同向、速度比固定，追上的位置就是外分點）。
- **第二章 分點比大小**（約 6 題）
  - 已知 a < b < c 和距離的比，比較 \frac{4a + 5c}{9} 這類加權平均的大小：每一個都是某兩點之間的分點，畫在數線上看位置。
  - 根號版：√5、√7 之間的分點排順序。

### R3 天秤市集（重點三：次序不等式）

**玩法**：x、y 的範圍是數線上一段亮起的柵欄。做運算時，兩段柵欄合成一段新的，端點從哪裡來會連線標出來。答錯時合出來的那段會閃紅，露出多出來或少掉的部分。

設計稿：`docs/num_r3_design.md`（2026/11/15 草案）。講義只有 3 題，第一章把五選題拆開，一種運算練一題。

- **第一章 範圍的加減乘除**（6 題）：距離寫成範圍、加和減（−y 翻過 0）、四個角（xy、\frac{x}{y}）、跨過 0 的平方、哪些一定成立（講義五選題）、速算。
- **第二章 複合的式子**（4 題）：平方相減、配方再看範圍（兩個平方各自看範圍）、拆成兩個括號（講義的 (E)）、速算。

**圖上作答**（1.8）：範圍用拖的，不用選項。在數線上拖兩個端點圈出 x − y、xy 的範圍（新元件：拖端點的柵欄），xy 的四個角點出最大、最小的那一個。

### R4 圍籬牧場（重點四：算幾不等式）

**玩法**：先動手：拖動長方形圍籬的角，周長固定，面積的讀數跟著變，正方形時面積最大，牧場的草長滿。

只收兩項的算幾不等式（三項的不收）。設計稿：`docs/num_r4_design.md`（2026/11/15 草案），講義 13 題收 12 題。

- **第一章 算幾不等式與等號**（9 題）：半圓裡的兩個平均、周長固定的圍籬（給和求積）、面積固定的圍籬（給積求和）、平方和固定、先湊出定值、步道最省、斜邊固定的直角三角形、三角形裡的水池、速算。
- **第二章 湊出能用的形式**（6 題）：倒數型、分式型、根號型、正數才能用、兩個等號一起成立、速算。

**圖上作答**（1.8）：拖長方形的角找面積最大（滑桿），等號成立的地方在圖上點出來。步道、水池的題目也先拖再算。

### R5 篩種倉庫（重點五：有理數與無理數）

**玩法**：倉庫裡把種子篩成兩堆，有理數一堆、無理數一堆（引擎已有 `filter`）。審判卡判對了，種子落進正確的籃子。判錯時種子彈回來，旁邊出現反例。

設計稿：`docs/num_r5_design.md`（2026/11/15 草案），講義 9 題收 7 題（反證法進階、a^{3} + b^{3} 放塔）。

- **第一章 分辨與封閉性**（5 題）：篩種子、算一算再篩（＋封閉性審判）、審判台（三種題型）、一定是有理數嗎、速算。
- **第二章 比較係數、反證法與有理化**（6 題）：兩個秤盤、秤盤的條件、反證法（排句子＋找矛盾）、分母有理化、三項的分母、速算。

**圖上作答**（1.8）：種子拖進「有理數」「無理數」兩個籃子（拖曳），比較係數時把項拖到兩個秤盤上，反證法的句子用排序。

### R6 剝殼磨坊（重點六：雙重根號）

**玩法**：雙重根號像麥殼，一層一層剝。答對一層，殼裂開掉落，露出裡面化簡好的式子。整數部分：數在數線柵欄上落在哪兩根柱子之間，放大到看得出來。

設計稿：`docs/num_r6_design.md`（2026/11/15 草案），講義 6 題全收。

- **第一章 雙重根號化簡**（6 題）：找兩個數（點面積 b 的長方形）、減號的那一個、先湊出 2√b、兩層的、化簡後比較係數、速算。
- **第二章 整數部分與小數部分**（5 題）：由內往外夾（數線上一層一層點）、先化簡再夾、代入求值、反過來求（a^{2} + b^{2}）、速算。

**圖上作答**（1.8）：剝殼是點那一層的殼，整數部分是在數線上點出它落在哪兩根柱子之間（`ltap`）。

### R7 方田拼圖（重點七：乘法公式）

**玩法**：方格麥田就是面積模型。展開 = 把大正方形切成小塊，因式分解 = 把小塊拼回長方形（沿用多項式 P3、P4 的拼積木）。立方公式用 3D 的方塊堆（拼成大立方體）。

- **第一章 展開與因式分解**（約 11 題）
  - 等式審判卡：「a^{3} + b^{3} = (a + b)^{3} − 3ab(a + b)」○ 之類，錯的卡要真的錯（程式代數字驗）。
  - 「看成一整塊」：(x + 2y − 1)(x − 2y + 1) 先看成 [x + (2y − 1)][x − (2y − 1)]。
  - 配方型的分解。範例：x^{4} − 7x^{2}y^{2} + y^{4} = (x^{2} + y^{2})^{2} − 9x^{2}y^{2} = (x^{2} + 3xy + y^{2})(x^{2} − 3xy + y^{2})（已驗算）。
  - (a + 1)(a − 1)(a^{2} + a + 1)(a^{2} − a + 1) 這類「兩兩配對」的題目。四次方的平方差。
  - 有理化的分母是立方根：用立方和、立方差公式。
- **第二章 代入與對稱式互求**（約 10 題）
  - 整數、小數部分代進式子：先把式子分解成 (3b − 2a)^{3} 這種形式再代。
  - 梯子：x + \frac{1}{x} = 3 → x^{2} + \frac{1}{x^{2}} = 7 → x^{3} + \frac{1}{x^{3}} = 18 → x^{4} + \frac{1}{x^{4}} = 47（已驗算）。每一階踩著上一階，答對就往上爬一格。
  - a + b = 4、ab = 2 → a^{2} + b^{2} = 12、a^{3} + b^{3} = 40（已驗算）。
  - 配方求值：一堆平方加起來 ≤ 0 ⇒ 每一個都是 0。

**圖上作答**（1.8）：展開、因式分解用拖積木拼長方形，梯子題每答對一階就點下一階，等式審判卡用代數字的天秤看兩邊重量。

### R8 谷底水渠（重點八：數線上的幾何）

**玩法**：|x − a| 就是到柵欄柱 a 的距離，|x − 3| ≤ 5 就是以 3 為中心、半徑 5 的柵欄亮起來。分段討論時畫 y = |x − a| + |x − b|，它像一條有平底的水渠。轉折點把數線分成幾段（像 P8 的閘門），一段一段畫出來。水平線 y = k 的滑桿往上推，數交點個數（沿用 C6 的漣漪）。

- **第一章 絕對值就是距離**（中心思想 1、2，約 11 題）
  - |x − a| ≤ b、≥ b 在數線上畫出來（點選區域，答對稻子長出來）。
  - 反寫：−1 ≤ x ≤ 7 ⇒ 中點 3、半長 4 ⇒ |x − 3| ≤ 4。應用：「標準值上下 10％」寫成絕對值。
  - 相同解的判斷：|5 − x| 和 |x − 5| 一樣，√((x − 5)^{2}) = |x − 5|。
  - 聯立：兩段柵欄的交集。整數解的個數。
  - 平方法：|2x + 1| ≤ |x + 5| 兩邊平方。
- **第二章 分段討論與三角不等式**（中心思想 3、4，約 12 題）
  - 解 |x − 3| = 2x − 9：x ≥ 3 時 x = 6（保留），x < 3 時 x = 4（不在這段，畫成空心的點、拿掉）。答案 x = 6（已驗算）。
  - 兩個絕對值：三段各自解。應用：水廠、電廠的基本費（新的情境）。
  - 中位數法則：先動手拖動點 P，看到三根柱子的距離和在中間那根最小。|x − 1| + |x − 4| + |x − 6| 的最小值 5，在 x = 4（已驗算）。有係數的：|3x − 2| 看成 3 個 |x − \frac{2}{3}|。
  - 解的個數：|x − 1| + |x + 3| = k，k < 4 無解、k = 4 有無限多解、k > 4 兩個解（滑桿看交點）。f(x) < k 有解 ⇔ k 大於最小值。
  - 三角不等式 |a| + |b| ≥ |a + b|，等號在 ab ≥ 0。

**圖上作答**（1.8）：|x − a| ≤ b 在數線上點出或拖出區間，分段討論點出轉折點，水渠圖上點出最低點，解的個數用滑桿數交點。

## 3. 終焉之塔與延後的題型

塔照 `design_rules.md` 第 7.5 節的做法：程式產生、每題 3 組數字、30 層、試煉大題 12 題。下面這些講義有、但主線不放的題型放塔（之後記到 `docs/num_tower_backlog.md`）：

- a、b 無理，a + b、ab 有理 ⇒ a^{3} + b^{3} 有理（R5 移過來，使用者 2026/11/13）
- 反證法進階版：證明 ∛2 + √5 是無理數（要展開 (P − √5)^{3}）
- 三層以上的雙重根號、√(a + 2√(b + √c)) 這種要剝三次的
- 雙重根號相加後再代入高次式：a = √(7 + √33) + √(7 − √33) 這一型
- a^{5} + b^{5}（用 a^{2} + b^{2} 和 a^{3} + b^{3} 組出來）
- (a − b)^{3} + (b − c)^{3} + (c − a)^{3} 的分解
- 等號成立反推 (x, y)：4x + y + \frac{9}{x} + \frac{4}{y} = 16 這一型
- 有理數的圖形問題（半圓裡哪些線段長是有理數）
- 根號化簡後的絕對值：√(25x^{2} − 10x + 1) = |5x − 1| 要看 x 的範圍
- 整數分散性：7|a − 3| + 3|b + 5| + \frac{1}{3}|c − 7| = 2
- 三角不等式的根號版：√(4x^{2} − 12x + 9) + … ≤ …
- ||x + 1| − |x − 2|| ≤ x 這種套兩層的分段
- 分段討論畫圖：三個以上絕對值加一次式的函數圖形
- 次序不等式的複合式：xy − 3x − 2y 的範圍

**不收**：三項的算幾不等式（a^{2}b 型），主線和塔都不放（使用者 2026/11/13）。

## 4. 觀念卡、速算、段考範圍

- **觀念卡**（`concepts_num.gd`）：每關 3～5 張。例如「循環小數化分數：乘 10 的 [ ] 次方，讓循環的部分對齊再相減」、「算幾不等式要 [ ] 才能用，等號在 [ ] 時成立」。每張至少一塊干擾積木。
- **速算**：每關一種，數字小、一兩步算完。例如 R1 分數化小數、R2 內分點坐標、R6 √(a + 2√b) 的 m、n。
- **段考範圍**：整個單元一段，exam 欄位之後填。

## 5. 製作順序

1. 地圖 `num_map.gd`、單元設定（`units.gd` 的 h1num）、R1。R1 做完先給使用者試玩。
2. 依序做 R2～R8，每做完一關照 `design_rules.md` 第 8 節的清單檢查，延後的題型更新 backlog。
3. 觀念卡、速算跟著每一關一起做。
4. 八關做完再做終焉之塔。
