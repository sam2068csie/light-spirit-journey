# 高一「數與式」（數之原野）單元規劃（草案，2026/11/13）

依據：高偉數學「高一上一段加強輔導班練習試題・數與式」（44 頁，重點一～八）＋ `docs/design_rules.md`。
這是**等使用者確認**的草案，確認之後才開始做關卡。範例都是重新設計的數字，標「已驗算」的都用程式算過。

## 0. 總覽

8 大關（R1～R8）＋終焉之塔。地區是高一地圖的「數之原野」：方格麥田、數線柵欄、風車。
講義 8 個重點全部都有收，但順序改成課本 1-1 實數、1-2 絕對值的順序，讓後面用到的工具前面先教過。

| 關 | 名稱（暫定） | 主題 | 對應講義 |
|---|---|---|---|
| R1 | 風車小數 | 數線、循環小數、有限小數 | 重點一前半 |
| R2 | 篩種倉庫 | 有理數與無理數 | 重點五 |
| R3 | 方田拼圖 | 乘法公式與因式分解 | 重點七 |
| R4 | 剝殼磨坊 | 根式、雙重根號、整數與小數部分 | 重點六、重點五的有理化 |
| R5 | 天秤市集 | 比大小、不等式的性質、範圍的運算 | 重點一後半、重點三 |
| R6 | 圍籬牧場 | 算幾不等式 | 重點四、重點一的尺規作圖（根號） |
| R7 | 柵欄距離 | 絕對值、數線距離、分點公式 | 重點二、重點八的中心思想 1、2 |
| R8 | 谷底水渠 | 分段討論、中位數、三角不等式 | 重點八的中心思想 3、4 |

和講義順序不同的地方：
- **乘法公式提前到 R3**：講義放在重點七，但雙重根號（重點六）、有理數判斷（重點五）都要先會 (a ± b)^{2} 和立方公式。
- **分點公式移到 R7，和絕對值放一起**：2|x − a| = 3|x − b| 本來就是「距離的比」。
- **比大小（重點一後半）和次序不等式（重點三）合成 R5**：兩者都是「不等式能怎麼操作」。
- **尺規作圖分兩邊**：比例（平行線截線段）放 R7 的分點，根號（半圓作 √ab）放 R6 當算幾的幾何意義。

單元代號 `h1num`，大關 id 用 **R1～R8**、觀念 tag 用 **`num_`** 開頭（R 還沒有單元用過）。

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題都一步一步帶。講義的「下列哪些正確」五選題，拆成一張一張審判卡（○／✕），✕ 的卡再追問「舉一個反例」。
- **學生自己列式**（1.4）：算式用填空模板挖空，例如 √(9 + 2√14) = √[ ] + √[ ]（兩格可互換，用 `groups`）。
- **看得到的後果**（1.2）：每關有自己的「世界反應」，寫在各關的「玩法」。圖上不寫中文（4）。
- **錯的選項絕對錯**（2）：每一個選項都想「有沒有哪個情況它會對」。比大小、不等式性質這種題目，用程式掃一大堆數字確認錯的選項真的會錯。
- **判分寬鬆**（2.5）：分數、小數、沒化簡的根號都算對，√80 = 4√5 引擎已經會比。兩根、因式的順序用 `groups`，比例式用 `prop`。
- **證明題**：遊戲沒辦法收文字證明。反證法改成「把證明的句子排順序」（引擎已有 `order`），加上「矛盾出在哪一句」的選擇題。
- **計算太重的放塔**（2）：三層以上的根號、五次方、三項的算幾放終焉之塔（第 3 節）。
- **是非題位置固定**：「有理數／無理數」的二選一要加進 `choice_order.gd` 的 PAIRS，有理數固定在左。

## 2. 各關規劃

### R1 風車小數（數線、循環小數、有限小數）

**玩法**：原野上的風車，每片扇葉寫一個數字，循環節就是扇葉。答對時風車轉起來，數字一圈一圈接成小數。數線柵欄上，點對位置會亮起一根燈柱。

- **第一章 循環小數與分數**
  - 循環小數化分數：把「乘 10 的幾次方、相減」的式子挖空讓學生列。
    範例：1.2\ol{36} → 1000x − 10x = 1236.\ol{36} − 12.\ol{36} → x = \frac{1224}{990} = \frac{68}{55}（已驗算）。
  - 分數化循環小數：用長除法，餘數重複的那一刻風車開始轉。
  - 循環小數夾範圍：一個帶未知數字 a 的循環小數夾在兩個分數之間，求 a（數字之後用程式找唯一解）。
- **第二章 有限還是循環**
  - 先約分，再看分母的質因數。畫面上分母拆成質因數積木，和分子約掉的那幾塊消失，只剩 2、5 時燈亮（有限）；剩其他質數時風車一直轉（循環）。
    範例：\frac{21}{56} = \frac{3}{8}（有限），\frac{9}{42} = \frac{3}{14}（循環）。重點是「看起來有 7，約分後就沒了」。
  - 有限小數進階：分子有未知數字 a，讓約分後只剩 2、5（數字之後用程式掃 a = 1～9 確認答案唯一）。
  - 第 n 位數字：先找循環節長度，再算餘數。範例：\frac{1}{7} 的第 100 位：100 = 6 × 16 + 4，第 4 個數字是 8（已驗算）。
  - 有理數的稠密性：兩個數之間「有無窮多個有理數」的判斷卡。

### R2 篩種倉庫（有理數與無理數）

**玩法**：倉庫裡把種子篩成兩堆，有理數一堆、無理數一堆（引擎已有 `filter`）。審判卡判對了，種子落進正確的籃子。判錯時種子彈回來，旁邊出現反例。

- **第一章 分辨與封閉性**
  - 分類：√16、\frac{22}{7}、0.\ol{3}、π、√8、√2 × √8……
  - 封閉性審判卡＋舉反例：「a、b 都是無理數，a + b 一定是無理數」✕，反例 √2 + (−√2) = 0。「有理數 + 無理數 = 無理數」○。
  - a + b、ab 有理 ⇒ a^{2} + b^{2}、a^{3} + b^{3} 有理，a − b 不一定（接 R3 的乘法公式，所以 R2 只放「判斷」，用公式的部分在 R3 回頭再考）。
- **第二章 比較係數**
  - 天秤的兩個秤盤：有理數盤、√3 盤，兩邊各自要相等。
    範例：(2 + √3)a + (1 − √3)b = 7 − √3，a、b 有理 → 2a + b = 7、a − b = −1 → (a, b) = (2, 3)（已驗算）。
  - 審判卡：「a + c√2 = b + d√2 ⇒ a = b 且 c = d」要有「a、b、c、d 都是有理數」才成立。
- **第三章 反證法**
  - 證明 √5 − √2 是無理數：把證明的句子排順序（假設它是有理數 r → 兩邊平方 → 移項得 √10 = 有理數 → 矛盾）。
  - 矛盾出在哪一句：選擇題。

### R3 方田拼圖（乘法公式與因式分解）

**玩法**：方格麥田就是面積模型。展開 = 把大正方形切成小塊，因式分解 = 把小塊拼回長方形（沿用多項式 P3、P4 的拼積木）。立方公式用 3D 的方塊堆（拼成大立方體）。

- **第一章 展開**
  - (a + b)^{2}、(a + b + c)^{2}、(a ± b)^{3}、a^{3} ± b^{3} 的展開，每一項是一塊田。
  - 「看成一整塊」：(x + 2y − 1)(x − 2y + 1) 先看成 [x + (2y − 1)][x − (2y − 1)]。
  - 等式審判卡：「a^{3} + b^{3} = (a + b)^{3} − 3ab(a + b)」○ 之類，錯的卡要真的錯（程式代數字驗）。
- **第二章 因式分解**
  - 平方差、立方和差。範例：x^{4} − 7x^{2}y^{2} + y^{4} = (x^{2} + y^{2})^{2} − 9x^{2}y^{2} = (x^{2} + 3xy + y^{2})(x^{2} − 3xy + y^{2})（已驗算）。
  - (a + 1)(a − 1)(a^{2} + a + 1)(a^{2} − a + 1) 這類「兩兩配對」的題目。
- **第三章 對稱式互求（梯子）**
  - x + \frac{1}{x} = 3 → x^{2} + \frac{1}{x^{2}} = 7 → x^{3} + \frac{1}{x^{3}} = 18 → x^{4} + \frac{1}{x^{4}} = 47（已驗算）。每一階踩著上一階，答對就往上爬一格。
  - a + b = 4、ab = 2 → a^{2} + b^{2} = 12、a^{3} + b^{3} = 40（已驗算）。
  - 配方求值：a^{2} + b^{2} + … ≤ … ⇒ 每個平方都是 0。

### R4 剝殼磨坊（根式、雙重根號、整數與小數部分）

**玩法**：雙重根號像麥殼，一層一層剝。答對一層，殼裂開掉落，露出裡面化簡好的式子。整數部分：數在數線柵欄上落在哪兩根柱子之間，放大到看得出來。

- **第一章 根式與有理化**
  - 化最簡根式、分母有理化（單項、兩項）。三項的有理化分兩次做。
- **第二章 雙重根號**
  - √(a + 2√b) = √m + √n，m + n = a、mn = b，兩格可互換（`groups`）。
    範例：√(9 + 2√14) = √7 + √2，√(8 − 2√15) = √5 − √3（已驗算）。
  - 減號的那一個，**大的在前**：提示「開根號出來要是正的」。
  - 不是 2√b 的要先湊：√(11 − 4√6) = √(11 − 2√24) = √8 − √3（已驗算）。
- **第三章 整數部分與小數部分**
  - 先化簡再夾：√(11 − 4√6) = 2√2 − √3 ≈ 1.10，整數部分 1，小數部分 2√2 − √3 − 1（已驗算）。
  - 接著代入式子求值（例如 \frac{1}{b} 有理化）。

### R5 天秤市集（比大小、不等式的性質、範圍的運算）

**玩法**：市集的天秤。兩邊放上數，答對時天秤往重的那邊傾斜、燈亮。範圍題用數線上的區間（一段亮起的柵欄），相加、相減時兩段合成一段。

- **第一章 比大小**
  - 分數比大小：通分子、或比 1 − 分數。
  - 根號相加：平方比較。範例：√11 + √3 和 2 + √10，平方後 14 + 2√33 和 14 + 2√40，後者大（已驗算）。
  - 根號相減：有理化成 \frac{2}{√15 + √13} 和 \frac{2}{√11 + √9}，分母大的小（已驗算）。
  - 分點的比大小（加權平均落在兩數之間）。
- **第二章 不等式的性質**
  - 審判卡＋反例：「a > b、c > d ⇒ ac > bd」✕（反例用負數），「a > b ⇒ \frac{1}{a} < \frac{1}{b}」✕（a、b 異號）。
  - 由 abc < 0、a + b + c < 0 等條件判斷正負（一步一步：先判斷幾個負的）。
- **第三章 範圍的運算**
  - −1 ≤ x ≤ 3、2 ≤ y ≤ 4：x − y 先把 −y 的範圍寫出來再相加，得 −5 ≤ x − y ≤ 1。xy 看四個角的乘積，得 −4 ≤ xy ≤ 12（已驗算）。
  - 常見錯誤當錯的選項：x − y 寫成 (−1 − 2) 到 (3 − 4)（直接相減端點）。
  - x^{2} + y^{2} + 2x + 4y 在方框裡的最大最小：先配方，看離中心最近、最遠。

### R6 圍籬牧場（算幾不等式）

**玩法**：先動手（1.3）：拖動長方形圍籬的角，周長固定，面積的讀數跟著變，正方形時面積最大，牧場的草長滿。再用半圓作圖：拖動直徑上的點 C，垂線 \ol{CD} = √ab 永遠不超過半徑 \frac{a + b}{2}，兩者相等時 C 在圓心。

- **第一章 算幾不等式與等號**
  - 半圓作圖看出 \frac{a + b}{2} ≥ √ab，等號在 a = b。
  - 給和求積：a + 4b = 8 ⇒ a · 4b ≤ 16 ⇒ ab ≤ 4，此時 a = 4、b = 1（已驗算）。
  - 給積求和：x + \frac{9}{x} ≥ 6（x > 0），x = 3 時。
- **第二章 湊出能用的形式**
  - 拆項：x + \frac{4}{x − 2} = (x − 2) + \frac{4}{x − 2} + 2。
  - **正數才能用**：x < 2 時 x − 2 < 0，要先提負號。最大值 −2，在 x = 0（已驗算）。這一題專門教「沒有檢查正負就用」的錯。
  - 分式型：\frac{x^{2} + 4x + 13}{x + 2} 先令 t = x + 2。
- **第三章 應用**
  - 步道面積：草地面積 150，上下步道寬 2、左右步道寬 3。步道面積 = 4x + 6y + 24 ≥ 2√(24 × 150) + 24 = 144，此時草地長 15、寬 10（已驗算）。
  - 直角三角形斜邊固定，面積最大。等腰直角三角形裡的長方形水池。

### R7 柵欄距離（絕對值、數線距離、分點公式）

**玩法**：|x − a| 就是到柵欄柱 a 的距離。|x − 3| ≤ 5：以 3 為中心、半徑 5 的柵欄亮起來。分點：兩根柱子之間拉一條繩子，拖動上面的珠子 P，讀數顯示 \ol{PA} : \ol{PB}。

- **第一章 絕對值就是距離**
  - |x − a| ≤ b、≥ b 在數線上畫出來（點選區域，答對稻子長出來）。
  - 反寫：−1 ≤ x ≤ 7 ⇒ 中點 3、半長 4 ⇒ |x − 3| ≤ 4。
  - 相同解的判斷：|5 − x| 和 |x − 5| 一樣，√((x − 5)^{2}) = |x − 5|。
  - 聯立：兩段柵欄的交集。整數解的個數。
  - 平方法：|2x + 1| ≤ |x + 5| 兩邊平方。
- **第二章 分點公式**
  - A(−2)、B(8)，\ol{AC} : \ol{BC} = 3 : 2：內分 C = 4，外分 C = 28（已驗算）。兩個都要找到（題目說「所有」）。
  - 2|x − a| = 3|x − b| 的判斷卡。
  - 應用：追趕問題、地圖縮小比例。
  - 尺規作圖（比例）：平行線截出等比例的線段。

### R8 谷底水渠（分段討論、中位數、三角不等式）

**玩法**：畫 y = |x − a| + |x − b| 的圖像，它像一條有平底的水渠。轉折點把數線分成幾段（像 P8 的閘門），一段一段畫出來。水平線 y = k 滑桿往上推，數交點個數（沿用 C6 的漣漪）。

- **第一章 分段討論**
  - 解 |x − 3| = 2x − 9：x ≥ 3 時 x = 6（保留），x < 3 時 x = 4（不在這段，畫成空心的點、拿掉）。答案 x = 6（已驗算）。
  - 兩個絕對值：三段各自解。
  - 應用：水廠、電廠的基本費（新的情境）。
- **第二章 最小值與中位數**
  - 先動手：拖動點 P，看到三根柱子的距離和在中間那根最小。|x − 1| + |x − 4| + |x − 6| 的最小值 5，在 x = 4（已驗算）。
  - 有係數的：|3x − 2| 看成 3 個 |x − \frac{2}{3}|。
- **第三章 三角不等式與解的個數**
  - |x − 1| + |x + 3| = k：k < 4 無解、k = 4 有無限多解、k > 4 兩個解（滑桿看交點）。
  - f(x) < k 有解 ⇔ k 大於最小值。
  - 三角不等式 |a| + |b| ≥ |a + b|，等號在 ab ≥ 0。

## 3. 終焉之塔與延後的題型

塔照第 7.5 節的做法：程式產生、每題 3 組數字、30 層、試煉大題 12 題。下面這些講義有、但主線不放的題型放塔（之後記到 `docs/num_tower_backlog.md`）：

- 三層以上的雙重根號、√(a + 2√(b + √c)) 這種要剝三次的
- 雙重根號相加後再代入高次式：a = √(7 + √33) + √(7 − √33) 這一型
- a^{5} + b^{5}（用 a^{2} + b^{2} 和 a^{3} + b^{3} 組出來）
- (a − b)^{3} + (b − c)^{3} + (c − a)^{3} 的分解
- 三項的算幾（a^{2}b 的最大值，要把 a 拆成兩半）。**這個要你決定是不是課綱內**，見第 5 節
- 等號成立反推 (x, y)：4x + y + \frac{9}{x} + \frac{4}{y} = 16 這一型
- 有理數的圖形問題（半圓裡哪些線段長是有理數）
- 根號化簡後的絕對值：√(25x^{2} − 10x + 1) = |5x − 1| 要看 x 的範圍
- 整數分散性：7|a − 3| + 3|b + 5| + \frac{1}{3}|c − 7| = 2
- 三角不等式的根號版：√(4x^{2} − 12x + 9) + … ≤ …
- ||x + 1| − |x − 2|| ≤ x 這種套兩層的分段
- 次序不等式的複合式：xy − 3x − 2y 的範圍

## 4. 觀念卡、速算、段考範圍

- **觀念卡**（`concepts_num.gd`）：每關 3～5 張。例如「循環小數化分數：乘 10 的 [ ] 次方，讓循環的部分對齊再相減」、「算幾不等式要 [ ] 才能用，等號在 [ ] 時成立」。每張至少一塊干擾積木。
- **速算**：每關一種，數字小、一兩步算完。例如 R1 分數化小數、R4 √(a + 2√b) 的 m、n、R7 內分點坐標。
- **段考範圍**：整個單元一段，exam 欄位之後填。

2. **三項的算幾不等式**（a^{2}b 型）：108 課綱高一只教兩項，講義有收。要放主線第二章、放塔，還是不收？

4. **難題放塔**：第 3 節的清單有沒有要拉回主線、或乾脆不收的？
5. **每關的名稱和主題**（風車、篩種、方田、剝殼磨坊……）：喜歡就照這個方向，想換風格也可以。
