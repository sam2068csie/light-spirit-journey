## 場景

箭羽高原的**雙線織坊**：用兩個方向的線（經線、緯線）織布的工坊。

- **布**：\vec{a}、\vec{b} 張開成一塊平行四邊形的布，行列式 = 布的面積。\vec{b} 在 \vec{a} 的逆時針那邊，布是正面（金色、行列式是正的）；在順時針那邊，布翻過來（紫色、行列式是負的）；兩支平行，布壓成一條線（行列式 0）。
- **拉長、推斜**：布的一邊拉長 k 倍，面積變 k 倍；把一邊沿著另一邊推斜（加上另一邊的倍數），面積不變。
- **兩條線**：第二章，織布機上兩條線交叉的地方就是聯立方程式的解。Δ ≠ 0：交在一點；Δ = 0：兩條線平行（無解）或疊在一起（無限多組解）。
- 第一章在織布機，第二章在掛線的架子。

## 錯的選項怎麼確保「絕對錯」

- 第 7 題 ✕ 卡都有反例：第 1 組 ③（任何 Δ ≠ 0：左邊 2Δ、右邊 4Δ）、④（左邊 −Δ）；第 2 組 ② a = b = 1、c = −1、d = 2；④ X(1, 0)、Y(0, −3) 是 −3。

## 觀念卡（5 張）

1. 二階行列式：\det{a}{b}{c}{d} = [ad − bc]。（干擾：ac − bd）
2. 行列式和面積：\vec{a}、\vec{b} 張成的平行四邊形面積 = [\|行列式\|]，行列式是負的表示 \vec{b} 在 \vec{a} 的順時針那邊。（干擾：行列式）
3. 行列式的性質：一列乘 k 倍，行列式[乘 k 倍]；一列加上另一列的倍數，行列式不變。（干擾：不變）
4. 克拉瑪法則：Δ ≠ 0 時恰有一組解，x = \frac{Δ_{x}}{[Δ]}、y = \frac{Δ_{y}}{Δ}。（干擾：Δ_{y}）
5. Δ = 0：兩條直線[平行或疊在一起]，無解或無限多組解，要代回去看。（干擾：垂直）

觀念 tag：`vec_det`（1、2、3、8）、`vec_detprop`（4、5、6、7）、`vec_cramer`（9～13）、`vec_solcount`（14～18）。
