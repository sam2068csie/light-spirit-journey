## 場景與新元件

舞台是峽谷壁上的石階：**每往上一階，高度乘 10**。log x 就是「x 站在第幾階」：1 在第 0 階、10 在第 1 階、100 在第 2 階，2 大約在第 0.3 階。真數乘 10 = 往上一階，log 的加減 = 在石階上上下走。

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **十倍石階**（新：數線 `nline` 加 `"stair": true`） | 第 1、3、7、8、11 題 | 數線畫成往右上爬的石階，每一階的邊緣寫 10 的幾次方（0.01、0.1、1、10、100…）。點石階、點出來的點都照現有的 `ltap`、`pts` 做，只是換一個畫法。 |
| **對數尺**（新：數線 `nline` 加 `"logticks": true`） | 第 4 題 | 0 到 1 之間的刻度標 1、2、3…10，位置在 log 1、log 2…log 10。學生估出 log 2、log 3 之後，那一格亮起來。 |
| **計算尺**（新：`rule`） | 第 6 題 | 兩把對數刻度的尺，上尺可以左右拖（滑桿，上尺的 1 對齊下尺的 m）。把上尺的 1 對到 2，上尺的 3 底下就是 6：乘法變成長度相加，就是 log ab = log a + log b。 |
| **分貝計**（新：`meter`） | 第 13、14 題 | 左邊是參考的聲音（或地震），右邊是可以拖的那一個。兩個聲波圈的大小照 log 的值畫，中間寫「強度是幾倍」= 10^{…}。 |
| 審判卡、填空、選擇、籃子（`lsort`） | 其他步驟 | 現有的 |

**答對時**：那一階石階亮起來；計算尺對齊時刻度發光；分貝計的聲波一圈一圈擴散。
**答錯時**：點錯的石階晃一下、寫出那一階是幾到幾。

## 每一步為什麼必要（1.7）

- 第 1 題：①② 是「log = 第幾階」的意義，③ 把圖上看到的寫成整數部分（E3 位數問題要用）。
- 第 2、10、12 題：審判卡就是觀念本身。
- 第 3 題：① 先排除不是實數的，② 算出一樣的點，③ 是題目問的。
- 第 4 題：①③ 找到「差不多是 10 的次方」的數，②④ 換成 log。
- 第 5 題：A ① 是關鍵（10^{log a} = a），②③④ 用它化簡；B ①② 算出 a、b、c，③ 看出完全平方，④ 是答案。
- 第 6 題：①② 用計算尺看到 log ab = log a + log b，③④ 用它合併。
- 第 7、8 題：① 是「乘 10 的次方 = log 加整數」，② 是答案。
- 第 11 題：A ① 在石階上看出範圍，② 換成很小的數；B ① 把 0.6 寫成 log 4，② 是答案。
- 第 13 題：① 拖出來看強度變化，② 寫成 10 的次方，③ 檢查其他敘述。
- 第 14 題：① 從公式看出 log 的變化，② 換成真數的倍數。

## 錯的答案怎麼確保「絕對錯」

- 第 2 題：「10^{n log 2} = 2n」寫成「對所有 n」，因為 n = 1、2 時剛好相等；n = 3 時 8 ≠ 6，所以 ✕。
- 第 5 題 B ③、第 8 題 B ②、第 11 題 B ②、第 14 題 A ② 的錯誤選項：程式代數字確認不相等（`verify_e2.py`）。
- 第 10、12、13 題的錯卡：都用程式算過（log 20 = 1 + log 2、log √{√{√10}} = \frac{1}{8}、log 0.0035 ≈ −2.46、10^{1.5} ≈ 31.6）。
- 講義 H30 的 (C) ⁶√{−2} = (−2)^{\frac{1}{6}} 不收（負數的分數次方不出題，E1 決定的）；H40 的 (A)(B) 換成自己設計的卡（講義原題看不清楚）。

## 觀念卡（5 張）

1. 對數的意義：10^{y} = x ⇔ y = log x，log x 就是 x 站在第 [幾階]；10^{log a} = [a]。（干擾：10a、log a）
2. 對數律：log ab = log a [+] log b、log \frac{a}{b} = log a [−] log b、log a^{r} = [r]log a。（干擾：×、÷）
3. 首數平移：x 乘 10^{n}，log x 就 [加 n]。（干擾：乘 n、加 10^{n}）
4. 對數的範圍：10^{n} ≤ x < 10^{n + 1} ⇔ [n] ≤ log x < n + 1。（干擾：n + 1）
5. 分貝與地震：分貝加 10，強度變 [10] 倍；規模加 1，能量變 10^{[1.5]} 倍。（干擾：2、1）
