## 場景與新元件

舞台是峽谷的谷底：從崖頂往深谷放**測繩**，繩子上**每一個結是一位數**。很大的數往下放（幾位數）、很小的數量的是「小數點後第幾位」。

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **數字條**（新：`digits`） | 第 1 題 | 一排數字方塊，中間有一顆會發光的小數點。拖滑桿 k，小數點往左跳 k 格（k 是負的就往右），右邊跟著寫 × 10^{k}。小數點停在第一個不是 0 的數字後面時，方塊發光。之後的步驟把前幾位（有效數字）圈起來，後面的變暗、四捨五入的那一位跳一下。 |
| **測繩**（新：`rope`） | 第 5、11 題 | 從崖頂垂下的繩子，每一個結是一位數，每 5 個結標一次數字。**先猜**：拖滑桿決定放多長（不扣能量）；算完之後旁邊垂下一條金色的真的繩子，底下寫差幾個結（+6、−4）。 |
| **多條測繩**（`rope` 的 `ropes`） | 第 9 題 | 幾條繩子並排，長度是 log 的值。前面一樣長的部分折起來（畫一個斷開的記號，寫 140），只畫最後十幾個結，長短一眼看出來。每算完一個，那條繩子垂下來。 |
| **尾數尺**（E2 的對數尺 `logticks`＋`ltap`） | 第 5、8、11 題 | 0 到 1 之間標 1、2、3…10（位置是 log 1、log 2…）。尾數是一根指針，學生點指針落在哪兩格之間，左邊那一格就是最高位數字。不用新寫，E2 已經有了。 |
| **拉範圍**（R3 的 `lrange`） | 第 10 題 | 數線上拖兩個把手，拉出 n 的範圍。 |
| **地震計**（E2 的 `meter`） | 第 12 題 B | 拖地震規模，中間寫能量是幾倍（10^{…}）。 |
| 審判卡、填空、選擇 | 其他步驟 | 現有的 |

**答對時**：數字條的小數點落定、發光；測繩的真繩子垂下來，猜得越準，結發的光越亮；尾數尺那一格亮起來。
**答錯時**：點錯的尾數尺格子晃一下，寫出那一格是 log 幾到 log 幾。

## 錯的答案怎麼確保「絕對錯」

- 第 2、6 題的錯卡：程式用真的整數算過（`verify_e3.py`）：4.06 × 10^{17} 是 18 位數、8.1 × 10^{−6} 從第 6 位開始、2.50 × 10^{9} × 6 × 10^{−3} 是 8 位數、10^{5.3} 是 6 位數、10^{−2.9} 從第 3 位開始、2^{50} 是 16 位數。

## 觀念卡（5 張）

1. 科學記號：a × 10^{n}，1 ≤ a < [10]；小數點往左移 n 位就是 × 10^{[n]}。（干擾：100、−n）
2. 有效數字：中間和最後的 0 [也算]；加減看 [最後一位]、乘除看 [個數]。（干擾：不算、第一位）
3. 幾位數：log x = n + 尾數（0 ≤ 尾數 < 1）⇒ x 是 [n + 1] 位數。（干擾：n、n − 1）
4. 小數點後第幾位：log x = −n + 尾數 ⇒ 小數點後第 [n] 位開始不是 0。（干擾：n + 1）
5. 最高位數字：尾數在 log d 和 log (d + 1) 之間 ⇒ 最高位是 [d]。（干擾：d + 1）
