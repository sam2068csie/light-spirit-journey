# 光靈的親密度（養成系統）

完整提案在 Claude Docs「光靈養成系統提案」（2026/11/18）。這裡記實作的重點和進度。

## 原則（使用者 2026/11/18 決定）

- 親密度主要靠「一起學數學」累積；小屋互動是每天 1～2 分鐘的小甜頭，有每日上限。
- 只增不減：沒有飢餓、生病、倒退。3 天以上沒來，歡迎回來 +5（不管幾天都一樣）。
- 唯一的遊戲好處：Lv 7 以上簽到守護上限 +1。不給提示、不給終焉之塔免扣心。
- 只顯示等級和進度條，數字收在說明視窗裡。
- 光靈的口味喜好：每個人不一樣，每週變化（第二期做點心時實作）。
- 等級名稱、回憶故事屬於世界觀，之後再一起討論；現在的名稱是暫定的。

## 怎麼增加（game_bond.gd 的 BOND_PTS、BOND_CAP）

| 行為 | 親密度 | 每天上限 |
| --- | --- | --- |
| 答對（過關）一題，改對也算 | +1 | 30 題 |
| 第一次通過一段旅程 | +5 | 不限 |
| 第一次完成一張觀念卡片 | +3 | 不限 |
| 做完今日修煉 | +5 | 1 次 |
| 每日任務全部完成 | +5 | 1 次 |
| 小屋：摸摸頭（點光靈選，或按住來回摸） | +1 | 3 次 |
| 小屋：聊天（說你今天真的做過的事） | +2 | 1 次 |
| 3 天以上沒來 | +5 | 換日時 |

10 級：0／40／120／250／450／700／1000／1400／1900／2500。

## 進度

- [x] 第一期：存檔 `bond`、接在答題／旅程／卡片／修煉／每日任務上、小屋的摸頭和聊天、表情（開心、害羞）、升級視窗（小屋、主畫面、大地圖，first_run.gd 的 bond 步驟）、說明視窗、Lv 2 主畫面小愛心、Lv 3 害羞、Lv 4 友誼之星＋光靈的小床、Lv 7 守護 +1、歡迎回來。測試：tests/test_bond.gd。
- [ ] 第二期：點心（每人每週不同的喜好）、回憶相簿、Lv 5 暱稱、buddy 台詞分等級、回憶故事（等世界觀）。
- [ ] 第三期：教光靈（從做過的觀念卡片小測抽題、間隔複習）、Lv 6、8、9、10 的解鎖。

## 程式在哪裡

- `data/core/game_bond.gd`：管家的一層（economy 和 game 之間），規則、等級、聊天內容。
- `data/ui/bond_panel.gd`：升級視窗、說明視窗、粉紅進度條。
- `data/house/house.gd`：小屋裡的光靈互動、左下角的親密度。
- `data/ui/spirit_look.gd`：`draw_mood`（開心、害羞、驚訝）、友誼之星頭飾。
