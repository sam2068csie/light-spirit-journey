# V5 四心營火：關卡設計（2026/11/21，已實作：data/levels/vec2/vec5_bank.gd）

對應上冊 3-2 重點四（三角形的四心，A64～A74）、重點五（面積比，A75～A76）。單元規劃見 `docs/vec2_plan.md`。這份是**每一題、每一步**的設計，確認之後才開始寫程式。

- 2 章：第一章 10 題（9 題＋速算），第二章 8 題（7 題＋速算）。講義的面積比只有 2 題，第二章其他是新題。
- 每一題有 2 組數字（或兩種以上的變化），每次玩隨機抽一組。數字都和講義不同，全部用程式驗算過（`tools/vec2/verify_v5.py`）。
- 每一步都照 design_rules 1.7 檢查過：拿掉它就答不出題目問的問題。
- 沿用 V1～V4 的箭頭畫布、V2 的橡皮筋（加權拉力）、V3 的影子和展開田、V4 的根號鍵。**這一關的主角是「點在三角形裡的位置」**：四心各有一個找法，係數和面積比是同一件事。

## 場景

箭羽高原的**四心營火**：三角形的營地裡要點四座營火，各有各的規矩。

- **重心營火**：三個人從頂點各拉一條繩子，三條力剛好抵消（\vec{GA} + \vec{GB} + \vec{GC} = \vec{0}）。
- **外心營火**：到三個帳篷（頂點）一樣遠，三條繩子一樣長。
- **內心營火**：到三面圍籬（三邊）一樣遠，三條垂直的竿子一樣長。
- **垂心營火**：三條從頂點垂直照到對邊的陽光交會的地方。
- 第二章：營地旁邊的**三角形花圃**，從 P 拉三條線到頂點，把花圃分成三塊，三塊的面積比就是 P 的「權重」。

## 每一步為什麼必要（1.7）

- 第 1、6、8、17 題：每張審判卡都是講義五選題的一個選項（或新卡）。第 1 題的沙盒是重心那張卡的證據。
- 第 2 題：兩支都要換成基底才能展開，① ② 各一支、③ 是答案。
- 第 3 題：① 選對要內積的向量是這一題的關鍵（選錯會多出不知道的內積），② ③ 是平方和長度。
- 第 4 題：重心是三點的平均，三個點都要先寫出來。
- 第 5 題：① 看出 Q 的位置跟著 P 變，② ③ 用「係數和 = 1」求 Q，④ 是題目問的面積比。
- 第 7 題：題目問四座營火，四步各找一座。
- 第 9 題 A：題目問三組係數（外心、D、垂心），② ③ ④ 各一組，① 是 ② 要用的內積。B：題目問 (x, y) 和比，三步缺一不可。
- 第 11 題：① 是重心（最簡單的情形），② 是題目的比，③ 是規律。
- 第 12、13 題：面積比 = 係數，每一塊一步。
- 第 14～16 題：權重 ⇔ 面積比 ⇔ 係數，每一題走其中一段。

## 錯的選項怎麼確保「絕對錯」

- 第 1 題：✕ 卡都有寫死的反例（中垂線上的 D、一般的凸四邊形）。
- 第 6 題：每張卡用 \vec{AI} = \frac{b}{a + b + c}\vec{AB} + \frac{c}{a + b + c}\vec{AC} 算過，第 2 組再用坐標驗一次面積比。
- 第 8 題第 2 組：○ 的卡用 300 個隨機三角形驗過；✕ 的卡有寫死的反例（不等腰的三角形）。
- 第 9 題 C：垂心 (5, 4) 是外心的位置，垂心是直角頂點 A(1, 1)。
- 第 17 題 ③：內心的面積比是對邊的比，換一個順序就不對（三邊不一樣長）。
- 速算：題目的關係式寫法都是四心的定義或定理，四個按鈕各對應一種。

## 判分

- 第 11 題 ③、第 15、16 題 ①：權重成比例就對（`prop`，\frac{2A + 4B + 6C}{12} 也對）。
- 第 5 題 ④、第 14 題 ②：比成比例就對（`prop`）。

## 觀念卡（5 張）

1. 重心：\vec{GA} + \vec{GB} + \vec{GC} = [\vec{0}]，\vec{AG} = \frac{1}{3}(\vec{AB} + \vec{AC})。（干擾：\vec{AG}）
2. 外心：到三頂點一樣遠，\vec{AO} · \vec{AB} = \frac{1}{2}[\|\vec{AB}\|^{2}]（影子落在中點）。（干擾：\|\vec{AB}\|）
3. 內心：\vec{AI} = \frac{b}{a + b + c}\vec{AB} + \frac{c}{a + b + c}\vec{AC}，權重是[對邊長]。（干擾：鄰邊長）
4. 垂心：\vec{AH} · \vec{BC} = [0]，\vec{OH} = \vec{OA} + \vec{OB} + \vec{OC}（O 是外心）。（干擾：1）
5. 面積比：w_{A}\vec{PA} + w_{B}\vec{PB} + w_{C}\vec{PC} = \vec{0} ⇒ △PBC : △PCA : △PAB = [w_{A} : w_{B} : w_{C}]。（干擾：w_{C} : w_{B} : w_{A}）
