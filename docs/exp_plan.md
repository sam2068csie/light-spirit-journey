# 高一「指數與常用對數」（倍增峽谷）單元規劃（2026/11/17 草案 v3）

依據：高偉數學「高一上一段加強輔導班練習試題・指數與常用對數」（28 頁，重點一～三，共 60 題）＋ `docs/design_rules.md`。
範例都是重新設計的數字，標「已驗算」的都用程式算過。講義題號用 H1～H60（照講義出現的順序）。

## 0. 總覽

**使用者的決定（2026/11/17）**
- 這是小單元：每關 2 章，一章最多 12 題（含速算）。講義 60 題不用全收，可以取捨。
- 原本三個重點做三關；重點一題目太多，**拆成兩關**（指數律／乘法公式與應用），共 **四關**。
- 需要小數的答案用高二指對數的小數鍵盤（step 引擎的 `"dec": true`：「/」換成「.」；`"dot": true`：分數鍵之外多一個「.」；近似值用 `mode: "approx"` ＋ `tol`）。
- 「增加 a 倍」就是「變成 1 + a 倍」，照講義的說法出題。

地區是高一地圖「曦光大陸」上已經留好的 **倍增峽谷**（`g10_world.gd`：每往下一層、落差加倍的岩層）。四關順著峽谷往下走：岩壁 → 岩洞 → 石階 → 谷底。

單元代號 `h1exp`（units.gd 已經留了位置），大關 id 用 **E1～E4**、觀念 tag 用 **`elog_`** 開頭（E 還沒有單元用過；高二的指數與對數用的是 L1～L8 和 exp_／log_／digits_）。地圖腳本叫 `h1exp_map.gd`（`exp_map.gd` 是高二的）。

**和高二「指數與對數」的分工**：高二 L4（對數運算）、L8（位數望遠鏡）有一部分重疊。高一只用常用對數（底數 10），不碰換底公式、對數函數圖形、指數／對數方程式與不等式。題目和玩法重新設計，不搬高二的題庫；高二 L8 的「尾數尺」可以搬到 step 引擎共用。

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題都一步一步帶。「下列哪些正確」五選題拆成一張一張審判卡（○／✕），✕ 的卡再追問正確的值。
- **學生自己列式**（1.4）：算式用填空模板挖空。
- **答案在圖上、少讀字**（1.8）：每關的「看圖作答」寫在各關的「玩法」。圖上不寫中文（4）。
- **錯的選項絕對錯**（2）：比大小、位數題用程式掃過確認。
- **小數**：log 的值、科學記號的係數、近似值用小數鍵盤；log 2、log 3、log 7 的近似值在題目裡另起一行給（照高二 L8 的寫法）。
- **題數**：每章 12 題以內（含一題速算）。

## 2. 各關規劃

### E1 倍增岩壁（重點一：指數律）

**玩法**：峽谷的岩壁一層一層往下，每往下一層落差加倍。指數是「往下幾層」：乘法 = 再往下走、除法 = 往上爬；負指數是岩壁上方，分數指數是兩層之間。答對時光從那一層亮起來。
**看圖作答**：拖光點停在第幾層（次方可以是分數）；偵錯題點出錯的等號。

- **第一章 指數的意義與運算**（6 題）
  1. 有意義嗎（H3）：審判卡 0^{0}、(−3)^{0}、(−\frac{1}{3})^{−2}、(−5)^{√2}、0^{−\frac{1}{2}}，最後數一數有幾個有意義。
  2. 偵錯題（H4）：點出第一個錯的等號。2 = 4^{\frac{1}{2}} = [(−2)^{2}]^{\frac{1}{2}} = (−2)^{2 × \frac{1}{2}} = −2（錯在第三個等號：底數是負的不能用指數律）。
  3. 分配律（H1）：(7 + 2√6)^{\frac{3}{2}}(7 − 2√6)^{\frac{3}{2}} = 25^{\frac{3}{2}} = 125（已驗算）。
  4. 根式連乘（H8）：25^{−\frac{4}{3}} × ∜{1024} × √{\frac{5∛5}{8}} 這一型，全部化成 2、5 的幾次方。
  5. 無理數次方（H9）：64^{−\frac{2}{3}} × 16^{0.25} × 3^{1 − √5} × 6^{1 + √5} ÷ 2^{√5} = \frac{9}{4}（已驗算）。
  6. 速算：同底數的乘除、根式化指數。
- **第二章 解方程與代換**（7 題）
  1. 解方程（H5）：x > 0，\frac{∜{x^{8}}}{3x^{−1}} · \frac{6}{x^{6}} = 16 ⇒ 2x^{−3} = 16 ⇒ x = \frac{1}{2}（已驗算）。
  2. 提公因式（H2）：3^{x} + 3^{x + 1} + 3^{x + 2} = 2^{x} + 2^{x + 1} + 2^{x + 2} + 2^{x + 3} ⇒ (\frac{3}{2})^{x} = \frac{15}{13}（已驗算）。
  3. 換成同一個底數（H6）：9^{x} = 7 ⇒ 27^{x + 1} × 81^{−x} = 27 × 3^{−x} = \frac{27}{√7}（已驗算）。
  4. 用 a、b 表示（H10）：5^{0.4} = a、5^{0.15} = b ⇒ 5^{−0.1} = \frac{b^{2}}{a}。
  5. 找關係式（H17）：45^{x} = 27、5^{y} = 3 ⇒ \frac{3}{x} − \frac{1}{y} = 2（已驗算）。
  6. 連等式（H18、H19）：設 3^{x} = 5^{y} = A^{z} = k，3 = k^{\frac{1}{x}}…，\frac{1}{x} + \frac{1}{y} = \frac{2}{z} ⇒ A = √15。第二組換成 3^{x} = 4^{y} = 6^{z} 選對的關係式。
  7. 速算：換成同一個底數（4^{x} = 3 ⇒ 8^{x} = ？）。
- **不收**：H7（大雜燴計算，和第一章 4、5 重複）。

### E2 回音岩洞（重點一：乘法公式與指數的應用）

**玩法**：洞裡的回音一聲接一聲：喊出 a^{\frac{1}{2}} + a^{−\frac{1}{2}}，平方一次變成 a + a^{−1}，再立方變成 a^{\frac{3}{2}} + a^{−\frac{3}{2}}。洞底的溫泉長著菌絲，每天倍增；旁邊的礦石發光，每隔一段時間減半。
**看圖作答**：乘法公式沿用 R7 的「階梯」（gtap）：點出下一步要平方、還是立方；成長與衰退拖時間軸，畫面上的菌絲／光跟著變；比大小在數線上排順序（lsort）。

- **第一章 乘法公式**（6 題）
  1. 立方差（H11）：a^{2x} = 3 + 2√2 ⇒ \frac{a^{3x} + a^{−3x}}{a^{x} + a^{−x}} = a^{2x} − 1 + a^{−2x} = 5（已驗算）。
  2. 一路爬上去（H12）：a^{2x} = 5 − 2√6 的五張審判卡（a^{x} = √3 − √2、a^{x} + a^{−x}、…、a^{4x} + a^{−4x} = 98）。
  3. 開根號（H14）：a + a^{−1} = 14 ⇒ a^{\frac{1}{2}} + a^{−\frac{1}{2}} = 4、a^{\frac{1}{2}} − a^{−\frac{1}{2}} = ±2√3（正負都要，已驗算）。
  4. 開立方（H15）：z + z^{−1} = 18，t = z^{\frac{1}{3}} + z^{−\frac{1}{3}} ⇒ t^{3} − 3t = 18 ⇒ t = 3（已驗算）。
  5. 決定正負（H16）：0 < a < 1，a + a^{−1} = √10 ⇒ a − a^{−1} = −√6（已驗算）。
  6. 速算：已知 a + a^{−1}，求 a^{2} + a^{−2}。
- **第二章 指數的應用**（7 題）
  1. 反求倍率（H20）：每天增加 a 倍，2 日後 30 萬、3.5 日後 240 萬、b 日後 1920 萬 ⇒ (1 + a)^{1.5} = 8 ⇒ a = 3、b = 5（已驗算）。
  2. 布袋蓮（H21）：x k^{3} = 120、x k^{5} = 480 ⇒ 第 8 個月 (x, k, y) = (15, 2, 3840)（已驗算）。
  3. 半衰期（H23）：a 半衰期 10 年、b 15 年，現在 a : b = 4 : 1。拖時間軸：30 年後 a = 2b、60 年後相等（已驗算），審判卡。
  4. 選模型（H24）：「每 3 天加倍」⇒ f = a × 2^{\frac{t}{3}}。
  5. 藥量（H26）：M(t) = 1000 × 0.64^{t} ⇒ M(1.5) = 512（已驗算），t 到 t + 1 吸收的量和殘存量的比 = 0.36（小數鍵盤）。
  6. 比大小（H29）：每 2 天 2 倍、每 3 天 3 倍、每 4 天 4 倍、每 6 天 6 倍 ⇒ 都化成 12 次方：64、81、64、36（已驗算）。
  7. 速算：每 n 天變 k 倍，t 天後變幾倍。
- **不收**：H13（和第一章 3 同型）、H22（優酪乳，移到 E4 用 log 做）、H25（克里夫蘭比例）、H27（學習曲線）、H28（同底比大小，併進第二章 6 的觀念卡）。

### E3 十倍石階（重點二：常用對數）

**玩法**：峽谷壁上的石階，每往上一階高度乘 10。log x 就是「x 站在第幾階」：1 在第 0 階、10 在第 1 階，2 大約在第 0.3 階。真數乘 10 倍 = 往上一階，log 的加減 = 上下走。
**看圖作答**：在對數刻度的石階上點出數的位置（ltap）；判斷範圍用「夾在哪兩階之間」；分貝、地震用滑桿。

- **第一章 對數的意義與運算**（11 題）
  1. 觀念審判卡（H30）：(−2)^{−√3} = \frac{1}{(−2)^{√3}}、a^{\frac{1}{2}} + a^{−\frac{1}{2}} = 2 ⇒ a^{2025} + a^{−2025} = 2、10^{n log 2} = 2n、log(−2)^{2} + log 3^{2} = log(−6)^{2}。
  2. 數線上幾個相異點（H31）：每個數先算出值、點在石階上，疊在一起的是同一點。
  3. 10^{log a} = a（H32）：100^{log 3} = 9、(√10)^{log 16} = 4、(10√10)^{log 9} = 27、(∛100)^{log \frac{27}{8}} = \frac{9}{4}（已驗算）。
  4. 先化簡再代（H33）：a = log \frac{√10}{1000} = −\frac{5}{2}、b = (\frac{1}{10})^{log 3} = \frac{1}{3}、c = 100^{log 2} = 4 ⇒ √{(a + b − c)^{2}} = \frac{37}{6}（已驗算）。
  5. 合併（H34）：2log 3 + 3log 2 − \frac{1}{2}log 36 = log k ⇒ k = 12（已驗算）。
  6. 平方差、代數值（H35）：log(√13 + √3) + log(√13 − √3) = 1（已驗算）；已知 log p、log q、log r 求 \frac{p^{3}q}{r}。
  7. 用 a 表示（H36）：log a = 2.03 ⇒ 0.001^{0.01} = \frac{100}{a}。
  8. 幾倍（H37）：log a = −2.5、log b = 0.5 ⇒ a 是 b 的 \frac{1}{1000} 倍。
  9. 首數平移（H38）：甲數的 log 是 2.71，乘 1000 ⇒ 5.71、乘 \frac{1}{10} ⇒ 1.71（小數鍵盤）。
  10. 同一串數字（H39）：log 169 = k ⇒ log 0.0169 = k − 4。
  11. 速算：log 10^{n}、log 的加減。
- **第二章 對數的範圍與應用**（9 題）
  1. log 2、log 3、log 7 組合（H40）：審判卡。
  2. 夾在哪兩階（H42）：log 3870 介於 n、n + 1 之間 ⇒ n = 3。
  3. 最接近哪一個（H50，從 E4 移來）：log a = 2.6 ⇒ a 最接近 400（10^{0.6} ≈ 3.98，已驗算）。
  4. 範圍審判卡（H43）：10^{log a} = log 10^{a}、10^{5log 3} 和 10^{3log 5} 比大小、log 0.0035 在 −3 和 −2 之間。
  5. 真數的倍數（H41）：T = 2 + 4log E，T 增加 2 ⇒ E 變成 √10 倍。
  6. 地震（H44）：log E = 1.5r + 11.8，規模差 0.9 ⇒ 10^{1.35} ≈ 22 倍（題目給 10^{0.35} 的近似值）。
  7. 分貝（H45）：d = 10 log \frac{I}{I_{0}}，滑桿調分貝，五張審判卡（110 分貝、30 分貝、20 和 10 分貝…）。
  8. 速算：log 的整數部分。
- **不收**：無（H50 移進來）。

### E4 深谷測繩（重點三：科學記號與位數問題）

**玩法**：往深谷放測繩，繩子上每一節是一位數。很大的數往下放（幾位數）、很小的數往上量（小數點後第幾位）。旁邊有一把「尾數尺」：0 到 1 之間標著 log 2、log 3…log 9，尾數落在哪兩格之間，最高位數字就是左邊那一格（高二 L8 的尺搬過來）。
**看圖作答**：拖小數點（科學記號）、點尾數尺、拖測繩長度、反求 n 用拉範圍（lrange）。

- **第一章 科學記號**（8 題）
  1. 取有效數字（H46）：23412976 取 2 位、3 位 ⇒ 2.3 × 10^{7}、2.34 × 10^{7}（拖小數點＋小數鍵盤）。
  2. 科學記號判斷（H47）：a = 7.53 × 10^{23}、b = 2.3 × 10^{−9} 的審判卡（幾位數、有效數字、第幾位不是 0）。
  3. 有效數字的四則運算（H48）：加減看位數、乘除看有效數字個數。
  4. 天文距離（H49）：1 天文單位 1.5 × 10^{11} 公尺、相距 4.2 天文單位、速度 3 × 10^{8} ⇒ 來回 4.2 × 10^{3} 秒（已驗算）。
  5. 幾位數、最高位數字（H54 第一題）：3^{50}：log = 23.856 ⇒ 24 位數，尾數 0.856 > log 7 ⇒ 最高位 7（已驗算）。
  6. 小數點後第幾位（H54 第二題）：(\frac{3}{5})^{40}：log = −8.874 = −9 + 0.126 ⇒ 第 9 位開始不是 0，那個數字是 1（已驗算）。
  7. 位數判斷審判卡（H53）：log 0 = 1、log 5 ≈ 0.6990、10^{7.93} 的整數部分幾位、10^{−6.12}、2^{100} 幾位。
  8. 速算：已知 log，說出幾位數。
- **第二章 位數的應用**（10 題）
  1. 已知位數反推（H51）：43^{100} 是 164 位數 ⇒ 43^{20} 是 33 位數（log 43 夾在 1.63 和 1.64 之間，已驗算）。
  2. 反求科學記號（H52）：log √p = 8.4 ⇒ log p = 16.8 ⇒ p ≈ 6.3 × 10^{16}，17 位數、最高位 6（已驗算）。
  3. 兩數相加（H55）：3^{60} + 2^{95}：4.2 × 10^{28} + 4.0 × 10^{28} ⇒ 29 位數、最高位 8、個位數 9（已驗算；做的時候再挑一組會進位的）。
  4. 比大小（H56）：2^{500}、10^{150}、15^{120} ⇒ 150.5、150、141.1（已驗算）。
  5. 反求 n 最大（H57）：1.25^{n} 的整數部分是 8 位數 ⇒ n 最大 82（已驗算）。
  6. 反求 n 的範圍（H58）：(\frac{3}{2})^{n} 是 5 位數 ⇒ 23 ≤ n ≤ 28（已驗算）。
  7. 至少幾天（H22，從 E2 移來）：差距每天變 2 倍，2^{n} ≥ 2000 ⇒ n ≥ 10.97 ⇒ 第 11 天。
  8. 位元（H59）：10^{100} 寫成二進位要 333 個位元（已驗算）。
  9. 芮氏規模（H60）：log E = 5.24 + 1.44M，規模 6.5 ⇒ log E = 14.6（已驗算），反求規模四捨五入到小數點後一位。
  10. 速算：最高位數字（尾數尺）。
- **不收**：無（H50 移到 E3）。

## 3. 終焉之塔與延後的題型

塔照 `design_rules.md` 第 7.5 節的做法：程式產生、每題 3 組數字、30 層、試煉大題 12 題。E1、E2 不收的 H7、H13、H25、H27、H28 記到 `docs/exp_tower_backlog.md`，做塔的時候從裡面挑。四關做完再做塔。

## 4. 觀念卡、速算、段考範圍

- **觀念卡**（`concepts_h1exp.gd`）：每關 3～5 張。例如「a^{r} 的底數要 [ ] 才能用指數律」、「log x 的整數部分 + 1 = x 的 [ ]」。每張至少一塊干擾積木。
- **速算**：每章一題（上面各章最後一題）。
- **段考範圍**：高一第一次段考（和數與式同一段），exam 欄位之後填。

---

## 5. 製作順序

1. 地圖 `h1exp_map.gd`、單元設定（`units.gd` 的 h1exp）、E1。E1 做完先給你試玩。
2. 做 E2～E4，每關照 `design_rules.md` 第 8 節的清單檢查，延後的題型記到 backlog。
3. 觀念卡、速算跟著每一關一起做。
4. 四關做完再做終焉之塔。
