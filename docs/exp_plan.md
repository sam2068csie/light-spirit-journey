## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題都一步一步帶。講義的「下列哪些正確」五選題，拆成一張一張審判卡（○／✕），✕ 的卡再追問反例或正確的值。
- **學生自己列式**（1.4）：算式用填空模板挖空，例如 7^{\frac{1}{2}} = [ ]^{\frac{1}{2}}、log 12 = 2log[ ] + log[ ]。
- **答案在圖上、少讀字**（1.8）：每關有自己的「看圖作答」，寫在各關的「玩法」。圖上不寫中文（4）。
- **錯的選項絕對錯**（2）：比大小、位數題用程式掃過確認。
- **鍵盤沒有小數點**：答案設計成整數、分數或「10 的幾次方的次方數」。有效數字、科學記號這種本來就是小數的，改成填「係數的數字」和「次方」兩格（例如 2.3 × 10^{[7]}、[23] × 10^{6} 這種挖法再討論，見第 4 節問題 3）。
- **log 2、log 3、log 7 的近似值**：題目裡另起一行給（照高二 L8 的寫法）。
- **題數**：每章 12 題以內，每關 2 章。

## 2. 各關規劃

### E1 倍增岩壁（重點一：指數律）

**玩法**：峽谷的岩壁一層一層，每層標著一個質數（2、3、5、7）。每一個數拆成「質數的幾次方」，岩層就長出那麼高的光柱（負的往下）。乘起來 = 光柱疊加、除 = 扣掉；最後光柱的高度就是答案的指數。
**新的看圖作答**：拖光柱的高度（每個質數一根，次方可以是分數）。

- **第一章 指數的意義**（約 6 題）
  - 有意義嗎：一張一張審判卡。範例：0^{0}、(−3)^{0}、(−\frac{1}{3})^{−2}、(−5)^{√2}、0^{−\frac{1}{2}}。
  - 偵錯題：點出推論裡第一個錯的等號。範例：2 = 4^{\frac{1}{2}} = [(−2)^{2}]^{\frac{1}{2}} = (−2)^{2 × \frac{1}{2}} = −2（錯在第三個等號：底數是負的不能用指數律）。
  - 根式和指數互換：∛{x^{2}} = x^{[ ]}。
  - 分配律：(7 + 2√6)^{\frac{3}{2}}(7 − 2√6)^{\frac{3}{2}} = (49 − 24)^{\frac{3}{2}} = 125（已驗算）。
- **第二章 指數的運算**（約 6 題）
  - 基本運算（拖光柱）：64^{−\frac{2}{3}} × 16^{0.25} × 3^{1 − √5} × 6^{1 + √5} ÷ 2^{√5} = \frac{9}{4}（已驗算）。
  - 根式連乘：25^{−\frac{4}{3}} × ∜{1024} × √{\frac{5∛5}{8}} 這一型（數字換過）。
  - 提公因式：3^{x} + 3^{x + 1} + 3^{x + 2} = 2^{x} + 2^{x + 1} + 2^{x + 2} + 2^{x + 3} ⇒ (\frac{3}{2})^{x} = \frac{15}{13}（已驗算）。
  - 解方程：x > 0，\frac{∜{x^{8}}}{3x^{−1}} · \frac{6}{x^{6}} = 16 ⇒ 2x^{−3} = 16 ⇒ x = \frac{1}{2}（已驗算）。
  - 速算：同底數的乘除（2^{\frac{1}{3}} × 2^{\frac{1}{6}} = ？）。

### E2 回音岩洞（重點一：代換與乘法公式）

**玩法**：洞裡的回音一聲接一聲：喊出 a^{\frac{1}{2}} + a^{−\frac{1}{2}}，平方一次回音變成 a + a^{−1}，再立方變成 a^{\frac{3}{2}} + a^{−\frac{3}{2}}。沿用 R7 的「階梯」（gtap）：點出下一步要踩哪一階。
**看圖作答**：踩階梯；代換題把式子拆成同一個底數的積木。

- **第一章 代換與找關係式**（約 6 題）
  - 換成同一個底數：9^{x} = 7 ⇒ 27^{x + 1} × 81^{−x} = 27 × 3^{−x} = \frac{27}{√7}（已驗算）。
  - 用 a、b 表示：5^{0.4} = a、5^{0.15} = b ⇒ 5^{−0.1} = \frac{b^{2}}{a}（拆成卡片組合）。
  - 找關係式：45^{x} = 27、5^{y} = 3 ⇒ \frac{3}{x} − \frac{1}{y} = 2（已驗算）。
  - 連等式：2^{x} = 7^{y} = A^{z}，\frac{1}{x} + \frac{1}{y} = \frac{2}{z} ⇒ A = √14。3^{x} = 4^{y} = 6^{z} 選對的關係式（審判卡）。
- **第二章 乘法公式**（約 7 題）
  - a^{2x} = 3 + 2√2 ⇒ \frac{a^{3x} + a^{−3x}}{a^{x} + a^{−x}} = a^{2x} − 1 + a^{−2x} = 5（已驗算）。
  - a^{2x} = 5 − 2√6 的五張審判卡（a^{x}、a^{x} + a^{−x}、一路到 a^{4x} + a^{−4x}）。
  - a + a^{−1} = 14 ⇒ a^{\frac{1}{2}} + a^{−\frac{1}{2}} = 4、a^{\frac{1}{2}} − a^{−\frac{1}{2}} = ±2√3（正負都要，已驗算）。
  - 反過來開立方：z + z^{−1} = 18，t = z^{\frac{1}{3}} + z^{−\frac{1}{3}} ⇒ t^{3} − 3t = 18 ⇒ t = 3（已驗算）。
  - 0 < a < 1 決定正負：a + a^{−1} = √10 ⇒ a − a^{−1} = −√6（已驗算）。
  - 速算：已知 a + a^{−1}，求 a^{2} + a^{−2}。

### E3 菌絲溫泉（重點一：指數的應用與比大小）

**玩法**：溫泉邊的菌絲每天倍增、放射礦石的光每隔一段時間減半。拖時間軸，畫面上的菌絲／光跟著長或暗。
**看圖作答**：拖滑桿找「第一次超過」的那一天；比大小把幾個數點到數線上排順序（lsort）。

- **第一章 成長與衰退**（約 6 題）
  - 由兩個時間點反求倍率：2 日後 30 萬、3.5 日後 240 萬 ⇒ r^{1.5} = 8 ⇒ 每天 4 倍（題目寫「變成原來的 r 倍」，避免「增加 a 倍」的歧義）。
  - 布袋蓮：x k^{3} = 120、x k^{5} = 480 ⇒ (x, k, y) 第 8 個月 = (15, 2, 3840)（已驗算）。
  - 半衰期：a 半衰期 10 年、b 15 年，現在 a : b = 4 : 1。拖時間：30 年後 a = 2b、60 年後相等（已驗算）。
  - 選模型：「每 3 天加倍」⇒ f = a × 2^{\frac{t}{3}}（看圖選曲線）。
  - 不用 log 的「至少幾天」：每天差距變 2 倍，2^{n} ≥ 2000 ⇒ n = 11。
- **第二章 指數比大小與模型**（約 6 題）
  - 化成同次方比：每 2 天 2 倍、每 3 天 3 倍、每 4 天 4 倍、每 6 天 6 倍 ⇒ 12 次方是 64、81、64、36（已驗算），「3 倍」那位最快、2 倍和 4 倍永遠一樣。
  - 化成同底數比：\frac{4}{∛2}、2^{\frac{5}{4}} 這一型。
  - 比例模型：A = kR^{0.7}，看起來 8√2 倍 ⇒ 實際 32 倍（數字之後換）。
  - 藥量：M(t) = 1000 × 0.64^{t} ⇒ M(1.5) = 512（已驗算），t 到 t + 1 吸收的比例 = 0.36。
  - 學習曲線：F(t) = a(1 − 10^{−bt})，F(1) = 80、F(2) = 120 ⇒ F(3) = 140（已驗算）。

### E4 十倍石階（重點二：常用對數）

**玩法**：峽谷壁上的石階，每往上一階高度乘 10。log x 就是「x 在第幾階」：1 在第 0 階、10 在第 1 階、100 在第 2 階，2 大約在第 0.3 階。
**看圖作答**：在對數刻度的數線上點出數的位置（ltap）；log 的加減 = 在石階上往上往下走。

- **第一章 對數的意義**（約 6 題）
  - 定義：log 1000 = [3]、log \frac{1}{√10} = [−\frac{1}{2}]。
  - 數線上幾個相異點：√{11 − 2√10}、\frac{1}{√10}、log √10、10^{−\frac{1}{2}} 這一型（每個先算出值、點在數線上，疊在一起的就是同一點）。
  - 10^{log a} = a：100^{log 3} = 9、(√10)^{log 16} = 4、(10√10)^{log 9} = 27、(∛100)^{log \frac{27}{8}} = \frac{9}{4}（已驗算）。
  - 觀念審判卡：(−2)^{−√3}、10^{n log 2} = 2n、log(−2)^{2} + log 3^{2} = log(−6)^{2} 這一型。
- **第二章 對數的運算與表達**（約 6 題）
  - 合併：2log 3 + 3log 2 − \frac{1}{2}log 36 = log 12（已驗算）。
  - 平方差：log(√13 + √3) + log(√13 − √3) = 1（已驗算）。
  - 已知 log p、log q、log r 求 log \frac{p^{3}q}{r}。
  - 真數的倍數：log a = −2.5、log b = 0.5 ⇒ a 是 b 的 \frac{1}{1000} 倍。甲數的 log 是 2.71，乘 1000 ⇒ 5.71。log 169 = k ⇒ log 0.0169 = k − 4。
  - log 2、log 3、log 7 的組合：審判卡（a + b = log 6、log 20 = 1 + a…）。
  - 速算：log 的整數部分（log 3870 在哪兩個整數之間）。

### E5 轟鳴瀑布（重點二、三：數量級）

**玩法**：瀑布的轟鳴聲用分貝計顯示；遠方的地震讓岩層晃動。用滑桿調「分貝」或「規模」，畫面上的能量方塊跟著乘 10。
**看圖作答**：拖滑桿；科學記號拖小數點（新玩法：把小數點拖到第一個非零數字後面，數一數移了幾位就是次方）。

- **第一章 科學記號與有效數字**（約 6 題）
  - 取有效數字：23412976 取 2 位、3 位（拖小數點＋四捨五入）。
  - 科學記號判斷：a = 7.53 × 10^{23} 有幾位數、有效數字幾位；b = 2.3 × 10^{−9} 從小數點後第幾位開始不是 0。
  - 有效數字的四則運算（加減看位數、乘除看有效數字個數）。
  - 天文距離：1 天文單位 1.5 × 10^{11} 公尺、相距 4.2 天文單位、速度 3 × 10^{8} ⇒ 來回 4.2 × 10^{3} 秒（已驗算）。
  - log a = 2.6 ⇒ a 最接近 400（10^{0.6} ≈ 3.98，已驗算）。
- **第二章 對數的應用**（約 6 題）
  - 分貝：d = 10 log \frac{I}{I_{0}}，80 分貝是 50 分貝的 1000 倍；五張審判卡（飛機、睡眠、20 和 10 分貝…）。
  - 地震：log E = 1.5r + 11.8，規模差 2 ⇒ 能量 1000 倍；差 0.9 ⇒ 10^{1.35}（題目給 10^{0.35} 的近似值）。
  - T = 2 + 4log E，T 增加 2 ⇒ E 變成 √10 倍（數字之後換）。
  - 對數範圍審判卡：10^{log a} = log 10^{a}、10^{5log 3} 和 10^{3log 5} 比大小、log 0.0035 在哪兩個整數之間。
  - 速算：真數變 10 倍、100 倍，log 加多少。

### E6 深谷測繩（重點三：位數問題）

**玩法**：往深谷放測繩，繩子上每一節是一位數。很大的數往下放（幾位數）、很小的數往上量（小數點後第幾位）。旁邊有一把「尾數尺」：0 到 1 之間標著 log 2、log 3…log 9，尾數落在哪兩格之間，最高位數字就是左邊那一格。
**看圖作答**：點尾數尺；拖測繩的長度；反求 n 用拉範圍（lrange）。

- **第一章 幾位數、最高位數字**（約 6 題）
  - 2^{100}：log = 30.10 ⇒ 31 位數，最高位 1（已驗算）。
  - 3^{50}：log = 23.856 ⇒ 24 位數，尾數 0.856 > log 7 ⇒ 最高位 7（已驗算）。
  - 很小的數：(\frac{3}{5})^{40}，log = −8.874 = −9 + 0.126 ⇒ 小數點後第 9 位開始不是 0，那個數字是 1（已驗算）。
  - 已知位數反推：43^{100} 是 164 位數 ⇒ 43^{20} 是 33 位數（log 43 夾在 1.63 和 1.64 之間，已驗算）。
  - 位數判斷審判卡：log 0 = 1、log 5 ≈ 0.6990、10^{7.93} 的整數部分幾位…
- **第二章 位數的應用**（約 6 題）
  - 比大小：2^{500}、10^{150}、15^{120} ⇒ 150.5、150、141.1（已驗算）。
  - 反求 n：1.25^{n} 的整數部分是 8 位數 ⇒ 73 ≤ n ≤ 82（已驗算）。(\frac{3}{2})^{n} 是 6 位數，n 最大、最小。
  - 兩數相加的位數和個位數：3^{100} + 2^{159} 這一型（最高位要看兩個數加起來會不會進位）。
  - 位元：10^{100} 寫成二進位要 333 個位元（已驗算）。
  - 芮氏規模：log E = 5.24 + 1.44M，反求規模（四捨五入到小數點後一位）。
  - 速算：已知 log，說出幾位數。

## 4. 要你決定的事

1. **關數**：做 6 關（建議，一關約 10 題講義題）還是照其他單元做滿 8 關（一關只有 7～8 題講義題，要自己補比較多題）？
2. **關卡名稱和分組**：E1～E6 的名稱、哪些題放哪一關，可以嗎？特別是 E5 把「科學記號」和「分貝、地震」放在一起（都在講數量級）。
3. **有效數字、科學記號的作答方式**：鍵盤沒有小數點。建議「拖小數點」當主要玩法，答案就是小數點的位置和次方；需要打字的地方只填整數（次方、位數、最高位數字）。這樣可以嗎？
4. **E1 的「拖光柱」**（每個質數一根光柱，高度是次方）是新玩法，可以嗎？還是用比較單純的填空就好？

## 5. 製作順序

1. 地圖 `h1exp_map.gd`、單元設定（`units.gd` 的 h1exp）、E1。E1 做完先給你試玩。
2. 依序做 E2～E6，每關照 `design_rules.md` 第 8 節的清單檢查，延後的題型記到 backlog。
3. 觀念卡、速算跟著每一關一起做。
4. 六關做完再做終焉之塔。
