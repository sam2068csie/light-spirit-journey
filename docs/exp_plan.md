依據：高偉數學「高一上一段加強輔導班練習試題・指數與常用對數」（28 頁，重點一～三，共 60 題）＋ `docs/design_rules.md`。
範例都是重新設計的數字，標「已驗算」的都用程式算過。講義題號用 H1～H60（照講義出現的順序）。

## 0. 總覽

**使用者的決定（2026/11/17）**
- 這是小單元：每關 2 章，一章最多 12 題（含速算）。講義 60 題不用全收，可以取捨。
- **三個重點做三關**（重點一曾經拆成兩關，同題型合併之後題數變少，2026/11/17 合回一關）。
- 需要小數的答案用高二指對數的小數鍵盤（step 引擎的 `"dec": true`：「/」換成「.」；`"dot": true`：分數鍵之外多一個「.」；近似值用 `mode: "approx"` ＋ `tol`）。
- 「增加 a 倍」就是「變成 1 + a 倍」，照講義的說法出題。
- **講義裡同一個題型的題目，合成遊戲裡的一題**（各自變成那一題的變化），不要拆成獨立的兩題。這樣講義 60 題全部收得進來。
- **不用完全照講義**：使用者採用了「先猜再算、計算交給畫面、判斷留給學生」的改法（光柱積木、回音階梯、折紙、賽跑、發光礦石、數量級階梯、計算尺、分貝計、拖小數點、尾數尺），新玩法變多是好事，開發時間多一點沒關係。段考核心技巧（化同底數、a + a^{−1} 的乘法公式、首數尾數判斷位數和最高位、反求 n）全部保留，大雜燴計算、個位數、有效數字規則減量。

## 1. 共通做法（套用 design_rules）

- **不直接挑戰**（1.1）：每一題都一步一步帶。「下列哪些正確」五選題拆成一張一張審判卡（○／✕），✕ 的卡再追問正確的值。
- **學生自己列式**（1.4）：算式用填空模板挖空。
- **答案在圖上、少讀字**（1.8）：每關的「看圖作答」寫在各關的「玩法」。圖上不寫中文（4）。
- **錯的選項絕對錯**（2）：比大小、位數題用程式掃過確認。
- **小數**：log 的值、科學記號的係數、近似值用小數鍵盤；log 2、log 3、log 7 的近似值在題目裡另起一行給（照高二 L8 的寫法）。
- **題數**：每章 12 題以內（含一題速算）。同題型的講義題合成一題的變化。

## 2. 各關規劃

講義裡**同一個題型的題目合成遊戲裡的一題**，各自變成那一題的一種變化（變化 A、B、C：每次玩隨機抽一種）。每一題後面括號是合進來的講義題號；標「新」的是講義沒有、為了好玩和好懂加的題目。

### E1 倍增岩壁（重點一：指數律）

**場景**：峽谷的岩壁一層一層往下，每往下一層落差加倍。指數是「往下幾層」：乘法 = 再往下走、除法 = 往上爬；負指數是岩壁上方，分數指數是兩層之間。岩壁底下有回音岩洞、溫泉的菌絲、會發光的礦石。

**新玩法**
- **光柱積木**（`pillar`）：岩壁上每個質數一根光柱（2、3、5、7）。題目裡的每一張數字卡，學生判斷「它是哪個質數的幾次方」後拖到那根柱子，柱子自己疊高（負的往下）。最後讀柱子的高度就是答案的指數。學生做判斷，加總交給畫面。
- **回音階梯**：沿用 R7 的「階梯」（gtap）。階梯上是 a^{\frac{1}{2}} + a^{−\frac{1}{2}}、a + a^{−1}、a^{2} + a^{−2}、a^{\frac{3}{2}} + a^{−\frac{3}{2}}…，學生點下一步踩哪一階（平方還是立方），只填關鍵的那個值，展開交給畫面。
- **折紙**（`fold`）：拖對折的次數，紙的厚度一路超過台北 101、玉山、聖母峰、月球。先猜再拖。
- **賽跑**（`race`）：幾個角色的光條照各自的倍率一起長，拖天數看誰領先。
- **發光礦石**（`glow`）：兩塊礦石照各自的半衰期變暗，拖時間軸，亮度一樣時停下來。

- **第一章 指數律**（9 題）
  1. 有意義嗎（H3）：審判卡 0^{0}、(−3)^{0}、(−\frac{1}{3})^{−2}、(−5)^{√2}、0^{−\frac{1}{2}}，最後數一數有幾個有意義。
  2. 偵錯題（H4）：點出第一個錯的等號。2 = 4^{\frac{1}{2}} = [(−2)^{2}]^{\frac{1}{2}} = (−2)^{2 × \frac{1}{2}} = −2（錯在第三個等號：底數是負的不能用指數律）。
  3. 共軛相乘（H1）：(7 + 2√6)^{\frac{3}{2}}(7 − 2√6)^{\frac{3}{2}} = 25^{\frac{3}{2}} = 125（已驗算）。
  4. 光柱積木：化成質數的次方（H7、H8、H9，減量：每題 4～5 張卡）：
     - 變化 A 根式連乘（H8）：25^{−\frac{4}{3}} × ∜{1024} × √{\frac{5∛5}{8}} 這一型。
     - 變化 B 無理數次方（H9）：64^{−\frac{2}{3}} × 16^{0.25} × 3^{1 − √5} × 6^{1 + √5} ÷ 2^{√5} = \frac{9}{4}（已驗算）。6 要拆成 2 和 3 兩根柱子。
     - 變化 C 分數連乘（H7）：[(\frac{1}{3})^{\frac{1}{6}}]^{4} · (\frac{16}{81})^{−\frac{1}{4}} ÷ 27^{\frac{1}{9}} 這一型。
  5. 解方程（H5）：x > 0，\frac{∜{x^{8}}}{3x^{−1}} · \frac{6}{x^{6}} = 16 ⇒ 2x^{−3} = 16 ⇒ x = \frac{1}{2}（已驗算）。
  6. 提公因式（H2）：3^{x} + 3^{x + 1} + 3^{x + 2} = 2^{x} + 2^{x + 1} + 2^{x + 2} + 2^{x + 3} ⇒ (\frac{3}{2})^{x} = \frac{15}{13}（已驗算）。
  7. 代換（H6、H10）：
     - 變化 A 代入值（H6）：9^{x} = 7 ⇒ 27^{x + 1} × 81^{−x} = 27 × 3^{−x} = \frac{27}{√7}（已驗算）。
     - 變化 B 用 a、b 表示（H10）：5^{0.4} = a、5^{0.15} = b ⇒ 5^{−0.1} = \frac{b^{2}}{a}（光柱：0.4 和 0.15 各是一塊，要湊出 −0.1）。
  8. 找關係式（H17、H18、H19）：
     - 變化 A 兩個式子（H17）：45^{x} = 27、5^{y} = 3 ⇒ \frac{3}{x} − \frac{1}{y} = 2（已驗算）。
     - 變化 B 連等式求底數（H18）：3^{x} = 5^{y} = A^{z}，\frac{1}{x} + \frac{1}{y} = \frac{2}{z} ⇒ A = √15。
     - 變化 C 連等式選關係（H19）：3^{x} = 4^{y} = 6^{z}，選出對的關係式。
  9. 速算：換成同一個底數（4^{x} = 3 ⇒ 8^{x} = ？）。
- **第二章 乘法公式與指數的應用**（11 題）
  1. 已知 a^{2x}（H11、H12）：
     - 變化 A（H11）：a^{2x} = 3 + 2√2 ⇒ \frac{a^{3x} + a^{−3x}}{a^{x} + a^{−x}} = a^{2x} − 1 + a^{−2x} = 5（已驗算）。
     - 變化 B（H12，減量成三張審判卡）：a^{2x} = 5 − 2√6，回音階梯一路往上：a^{x} = √3 − √2、a^{x} + a^{−x} = 2√3、a^{3x} + a^{−3x} = 18√3。
  2. 回音階梯往上爬（H13、H14 第 2 小題）：
     - 變化 A（H13）：a^{\frac{1}{2}} − a^{−\frac{1}{2}} = 3 ⇒ a + a^{−1} = 11、a^{\frac{3}{2}} − a^{−\frac{3}{2}} = 36 ⇒ 相除 = \frac{36}{11}（已驗算）。
     - 變化 B（H14）：a + a^{−1} = 14 ⇒ a^{\frac{1}{2}} + a^{−\frac{1}{2}} = 4，再求 \frac{a^{\frac{3}{2}} + a^{−\frac{3}{2}}}{a^{2} + a^{−2}}。
  3. 往下開根號、決定正負（H14 第 1 小題、H16）：
     - 變化 A（H14）：a + a^{−1} = 14 ⇒ a^{\frac{1}{2}} − a^{−\frac{1}{2}} = ±2√3（不知道 a 比 1 大還小，正負都要，已驗算）。
     - 變化 B（H16）：0 < a < 1，a + a^{−1} = √10 ⇒ a − a^{−1} = −√6（已驗算）。
  4. 開立方（H15）：z + z^{−1} = 18，t = z^{\frac{1}{3}} + z^{−\frac{1}{3}} ⇒ t^{3} − 3t = 18 ⇒ t = 3（已驗算）。
  5. 折紙到月球（新，先猜再算）：0.1 mm 的紙對折 n 次。先用滑桿猜幾次會超過月球，再拖對折次數：23 次超過台北 101、26 次超過玉山、27 次超過聖母峰、42 次超過月球（38.4 萬公里，已驗算）。最後問：再多折 1 次，厚度變幾倍？
  6. 兩筆資料反求（H20、H21、H27）：
     - 變化 A 細菌（H20）：每天增加 a 倍，2 日後 30 萬、3.5 日後 240 萬、b 日後 1920 萬 ⇒ (1 + a)^{1.5} = 8 ⇒ a = 3、b = 5（已驗算）。
     - 變化 B 布袋蓮（H21）：x k^{3} = 120、x k^{5} = 480 ⇒ 第 8 個月 (x, k, y) = (15, 2, 3840)（已驗算）。
     - 變化 C 學習曲線（H27）：F(t) = a(1 − 10^{−bt})，F(1) = 80、F(2) = 120 ⇒ F(3) = 140（已驗算）。
  7. 發光礦石（H23）：a 半衰期 10 年、b 15 年，現在 a : b = 4 : 1。先拖時間軸讓兩塊一樣亮（60 年），再用式子確認；審判卡：30 年後 a = 2b（已驗算）。
  8. 選模型（H24）：「每 3 天加倍」⇒ f = a × 2^{\frac{t}{3}}（看圖選曲線）。
  9. 代公式（H25、H26）：
     - 變化 A 比例模型（H25）：A = kR^{0.6}，看起來 27 倍 ⇒ 實際 R 是 27^{\frac{5}{3}} = 243 倍（已驗算）。
     - 變化 B 藥量（H26）：M(t) = 1000 × 0.64^{t} ⇒ M(1.5) = 512（已驗算），t 到 t + 1 吸收的量和殘存量的比 = 0.36（小數鍵盤）。
  10. 賽跑：指數比大小（H28、H29）：
     - 變化 A 四人賽跑（H29）：每 2 天 2 倍、每 3 天 3 倍、每 4 天 4 倍、每 6 天 6 倍。先預測誰贏，拖天數看光條；2 倍和 4 倍永遠並排。最後化成 12 次方：64、81、64、36（已驗算）。
     - 變化 B 化成同底數（H28）：\frac{9}{∛3} = 3^{\frac{5}{3}}、3^{\frac{5}{4}}、2^{\frac{5}{2}}、1 ⇒ 最大的是 \frac{9}{∛3}（6.24、3.95、5.66，已驗算）。
  11. 速算：每 n 天變 k 倍，t 天後變幾倍。

### E2 十倍石階（重點二：常用對數）

每一題、每一步的設計見 `docs/exp_e2_design.md`（2026/11/17 草案；以設計稿為準）。

**場景**：峽谷壁上的石階，每往上一階高度乘 10。log x 就是「x 站在第幾階」：1 在第 0 階、10 在第 1 階，2 大約在第 0.3 階。

**新玩法**
- **數量級階梯**（`stair`）：對數刻度的石階。把東西（病毒、螞蟻、人、台北 101、地球直徑）點到它站的那一階；log 的加減 = 上下走。
- **計算尺**（`slide_rule`）：兩把對數刻度的尺，上面那把可以左右拖。把上尺的 1 對齊下尺的 2，上尺的 3 對到下尺的 6：乘法變成長度相加，就是 log ab = log a + log b。
- **分貝計**（`meter`）：拖滑桿調分貝，畫面上的聲波和「強度是幾倍」跟著變，每加 10 分貝乘 10。

- **第一章 對數的意義與運算**（9 題）
  1. 數量級階梯（新）：把病毒（10^{−7} 公尺）、人（1.7 公尺）、台北 101（508 公尺）、地球直徑（1.27 × 10^{7} 公尺）點到石階上：log 就是在數第幾個數量級。人在第 0 和 1 階之間（log 1.7 ≈ 0.23）。
  2. 觀念審判卡（H30）：(−2)^{−√3} = \frac{1}{(−2)^{√3}}、a^{\frac{1}{2}} + a^{−\frac{1}{2}} = 2 ⇒ a^{2025} + a^{−2025} = 2、10^{n log 2} = 2n、log(−2)^{2} + log 3^{2} = log(−6)^{2}。
  3. 數線上幾個相異點（H31）：每個數先算出值、點在石階上，疊在一起的是同一點。
  4. 自己發現 log 2 和 log 3（新）：2^{10} = 1024 ≈ 10^{3} ⇒ 2 爬 10 次 ≈ 10 爬 3 次 ⇒ log 2 ≈ 0.3。3^{4} = 81 ≈ 80 = 2^{3} × 10 ⇒ 4log 3 ≈ 3log 2 + 1 ⇒ log 3 ≈ 0.48（實際 0.4771，已驗算）。
  5. 10^{log a} = a（H32、H33）：
     - 變化 A（H32）：100^{log 3} = 9、(√10)^{log 16} = 4、(10√10)^{log 9} = 27、(∛100)^{log \frac{27}{8}} = \frac{9}{4}（已驗算）。
     - 變化 B（H33）：a = log \frac{√10}{1000} = −\frac{5}{2}、b = (\frac{1}{10})^{log 3} = \frac{1}{3}、c = 100^{log 2} = 4 ⇒ √{(a + b − c)^{2}} = \frac{37}{6}（已驗算）。
  6. 計算尺：對數的運算（H34、H35）：先用計算尺做一次乘法（2 × 3、2 × 4），看到「長度相加 = 真數相乘」，再合併：
     - 變化 A 合併（H34）：2log 3 + 3log 2 − \frac{1}{2}log 36 = log k ⇒ k = 12（已驗算）。
     - 變化 B 平方差（H35 第 1 小題）：log(√13 + √3) + log(√13 − √3) = 1（已驗算）。
     - 變化 C 代數值（H35 第 2 小題）：已知 log p、log q、log r 求 \frac{p^{3}q}{r}。
  7. 首數平移（H38、H39）：在石階上整串往上、往下搬：
     - 變化 A（H38）：甲數的 log 是 2.71，乘 1000 ⇒ 5.71、乘 \frac{1}{10} ⇒ 1.71（小數鍵盤）。
     - 變化 B（H39）：log 169 = k ⇒ log 0.0169 = k − 4。
  8. 用 log 比倍數（H36、H37）：
     - 變化 A（H37）：log a = −2.5、log b = 0.5 ⇒ a 是 b 的 \frac{1}{1000} 倍（差 3 階）。
     - 變化 B（H36）：log a = 2.03 ⇒ 0.001^{0.01} = 10^{−0.03} = \frac{100}{a}。
  9. 速算：log 10^{n}、log 的加減。
- **第二章 對數的範圍與應用**（6 題）
  1. log 2、log 3、log 7 組合（H40）：審判卡，可以拿計算尺驗證（log 6 = log 2 + log 3）。
  2. 夾在哪兩階（H42、H50）：
     - 變化 A（H42）：log 3870 介於 n、n + 1 之間 ⇒ n = 3。
     - 變化 B（H50，從重點三移來）：log a = 2.6 ⇒ a 最接近 400（10^{0.6} ≈ 3.98，已驗算）。
  3. 範圍審判卡（H43）：10^{log a} = log 10^{a}、10^{5log 3} 和 10^{3log 5} 比大小、log 0.0035 在 −3 和 −2 之間。
  4. 分貝計（H45）：d = 10 log \frac{I}{I_{0}}。拖滑桿把圖書館的聲音（30 分貝）調成吹風機（80 分貝），強度變 10^{5} 倍；再做審判卡（110 分貝、20 和 10 分貝…）。
  5. 對數公式的應用（H41、H44）：
     - 變化 A 真數的倍數（H41）：T = 2 + 4log E，T 增加 2 ⇒ E 變成 √10 倍。
     - 變化 B 地震（H44）：log E = 1.5r + 11.8，規模差 0.9 ⇒ 10^{1.35} ≈ 22 倍（題目給 10^{0.35} 的近似值）。岩層搖晃的幅度跟著規模變。
  6. 速算：log 的整數部分。

### E3 深谷測繩（重點三：科學記號與位數問題）

每一題、每一步的設計見 `docs/exp_e3_design.md`（2026/11/18）。和下面的差別：3^{50} 換成 3^{60}（尾數離 log 7 太近）、3^{60} + 2^{95} 換成 3^{41} + 2^{66}（一定進位）、尾數尺直接用 E2 的對數尺。

**場景**：往深谷放測繩，繩子上每一節是一位數。很大的數往下放（幾位數）、很小的數往上量（小數點後第幾位）。

**新玩法**
- **拖小數點**（`dot`）：一串數字上拖小數點，停在第一個非零數字後面，旁邊自動數出移了幾位（就是 10 的次方）。
- **先猜再算**：位數題第一步先拖測繩猜長度（不扣能量），算完再看猜的和真的差多少。
- **尾數尺**（`ruler`）：0 到 1 之間標著 log 2、log 3…log 9，尾數是一根指針，學生點指針落在哪兩格之間，左邊那一格就是最高位數字（高二 L8 的尺搬到 step 引擎）。

- **第一章 科學記號**（7 題）
  1. 拖小數點：科學記號與有效數字（H46＋新）：
     - 變化 A 人口（H46）：23412976 取 2 位、3 位 ⇒ 2.3 × 10^{7}、2.34 × 10^{7}。
     - 變化 B 真實尺度（新）：地球質量、紅血球直徑、光從太陽到地球的秒數，寫成科學記號（數字做設計稿時查資料確認）。
  2. 科學記號判斷（H47）：a = 7.53 × 10^{23}、b = 2.3 × 10^{−9} 的審判卡（幾位數、有效數字、第幾位不是 0）。
  3. 有效數字的運算（H48，減量）：乘除看有效數字個數、加減看最後一位，各一小題。
  4. 天文距離（H49）：1 天文單位 1.5 × 10^{11} 公尺、相距 4.2 天文單位、速度 3 × 10^{8} ⇒ 來回 4.2 × 10^{3} 秒（已驗算）。
  5. 先猜再算：用 log 判斷位數（H54＋新）：
     - 變化 A 2^{100}（新）：先拖測繩猜幾位（多數人會猜很長），log 2^{100} = 30.10 ⇒ 31 位數，尾數尺點出最高位 1（已驗算）。
     - 變化 B 3^{50}（H54 第 1 小題）：log = 23.856 ⇒ 24 位數，尾數 0.856 > log 7 ⇒ 最高位 7（已驗算）。
     - 變化 C 很小的數（H54 第 2 小題）：(\frac{3}{5})^{40}：log = −8.874 = −9 + 0.126 ⇒ 小數點後第 9 位開始不是 0，那個數字是 1（已驗算）。
  6. 位數判斷審判卡（H53）：log 0 = 1、log 5 ≈ 0.6990、10^{7.93} 的整數部分幾位、10^{−6.12}、2^{100} 幾位。
  7. 速算：已知 log，說出幾位數。
- **第二章 位數的應用**（6 題）
  1. 已知位數反推（H51、H52）：
     - 變化 A（H51）：43^{100} 是 164 位數 ⇒ 43^{20} 是 33 位數（log 43 夾在 1.63 和 1.64 之間，已驗算）。
     - 變化 B（H52）：log √p = 8.4 ⇒ p ≈ 6.3 × 10^{16}，17 位數、最高位 6（已驗算）。
  2. 比大小（H56）：2^{500}、10^{150}、15^{120} ⇒ 150.5、150、141.1（已驗算），在測繩上比長短。
  3. 反求 n（H57、H58、H22）：拉範圍（lrange）：
     - 變化 A n 最大（H57）：1.25^{n} 的整數部分是 8 位數 ⇒ n 最大 82（已驗算）。
     - 變化 B n 的範圍（H58）：(\frac{3}{2})^{n} 是 5 位數 ⇒ 23 ≤ n ≤ 28（已驗算）。
     - 變化 C 至少幾天（H22，從重點一移來）：差距每天變 2 倍，2^{n} ≥ 2000 ⇒ 第 11 天。
  4. 加起來有幾位數（H55＋新，拿掉個位數）：
     - 變化 A 棋盤麥粒（新）：第 1 格 1 粒、每格加倍，64 格共 2^{64} − 1 粒 ⇒ 20 位數、最高位 1（1.8 × 10^{19}，已驗算）。先猜再算。
     - 變化 B 兩數相加（H55）：3^{60} + 2^{95} ⇒ 29 位數、最高位 8（已驗算；做的時候再挑一組會進位的）。
  5. 位數的應用題（H59、H60）：
     - 變化 A 位元（H59）：10^{100} 寫成二進位要 333 個位元（已驗算）。
     - 變化 B 芮氏規模（H60）：log E = 5.24 + 1.44M，規模 6.5 ⇒ log E = 14.6（已驗算），反求規模四捨五入到小數點後一位。
  6. 速算：最高位數字（尾數尺）。
