## 場景與新元件

舞台是山谷裡的水渠：數線是渠道旁的柵欄，|x − a| 就是到柵欄柱 a 的距離。y = |x − a| + |x − b| 的圖形像一條有平底的水渠。

**這一關不用新的元件**，全部用現有的：

| 元件 | 用在哪裡 | 怎麼動 |
|---|---|---|
| **點數線**（`ltap`） | 第 1、3、7、8、9、12、13、16、18、19 題 | 點出解的那幾段、轉折點、整數解、中心、最低的地方。點錯的地方標出理由（例如「|0 − 2| = 2 < 3」） |
| **拉範圍**（`lrange`） | 第 1、3、5、7、16、21 題 | 拖兩個把手拉出解的範圍 |
| **滑桿**（`slide`，坐標方格） | 第 14、17 題 | 拖住戶 P 沿著路走，讀數寫出費用、距離和，找最少的地方 |
| **在坐標方格點一點**（`grid`） | 第 20 題 | 分段畫好函數圖形，點出最低點 |
| 篩選（`filter`）、填空、選擇、審判卡 | 其他步驟 | 現有的 |

**答對時**：
- 數線題：那一段柵欄亮起來，稻子長出來。
- 分段題：數線先被轉折點切成幾段（像 P8 的閘門），每一段答完那一段亮起來；不在那一段的候選解畫成空心點、被水沖走。
- 水渠題：水從高處流到渠底，停在最低的地方。

## 每一步為什麼必要（1.7）

- 第 1 題：= 是兩個點、≤ 是中間、> 是外面，三種一起看才知道「距離」的意思。
- 第 3 題：① 是關鍵（左邊一定成立，或者要拆成兩段），③ 是題目問的。
- 第 4～6、9 題：中點、半長就是方法，最後一步是題目問的。
- 第 7 題：兩段柵欄各自畫，交集才看得出來（第 2 組交在一個點）。
- 第 8 題：① 估出上界，② 一個一個點整數（要排除 |2x − 1| 太小的 0、1），③ 是題目問的。
- 第 12、13、15 題：每一段解完，最後一步檢查在不在那一段（這是分段討論最常錯的地方）。
- 第 14 題：① 先看出費用最少在哪裡（決定中間那段有沒有解），② ③ ④ 三段。
- 第 17、18 題：① 是中位數的方法，② 是答案，第 17 題 ③ 是推廣。
- 第 19 題：平底就是解的個數的關鍵，③ ④ 是題目問的。
- 第 20 題：分段寫出來，最低點才畫得出來。
- 第 21 題：① 化成絕對值，② 是三角不等式等號成立的條件，③ 是答案。
- 第 22 題：① 是整數的關鍵（係數太大的只能是 0），② ③ 是答案。

## 錯的答案怎麼確保「絕對錯」

- 篩選、審判：程式在細格子上確認解集合不一樣（同解的完全一樣）。
- 點數線：點錯的地方標出代進去的值，看得出不滿足。
- 第 15 題 x = 1：B(2) 和 C(2) 重合，不是相異四點。
- 第 19 題：k 比最小值小一定無解，k 等於最小值時平底上每一點都是解。

## 判分

- 第 7 題第 2 組「−8 ≤ x ≤ 2 或 x = 6」分三格填。
- 第 13 題 ⑤、第 12 題 ③ 點數線，點到哪一個解都可以，兩個都要點到（第 12 題只有一個）。
- 第 22 題 ③ 的兩個答案可以對調（`set`）。
- 分數答案可以填小數。

## 觀念卡（4 張）

1. 絕對值是距離：|x − a| ≤ b ⇔ [a − b] ≤ x ≤ [a + b]，|x − a| ≥ b ⇔ x ≤ a − b 或 x ≥ a + b。（干擾：b − a、相乘）
2. 反寫：m ≤ x ≤ n ⇔ |x − [中點]| ≤ [半長]。（干擾：兩端相加、全長）
3. 分段討論：轉折點把數線切成幾段，每一段的解要 [在這一段裡] 才算。（干擾：都保留）
4. 中位數、三角不等式：|x − a_{1}| + … + |x − a_{n}| 在 [中位數] 最小；|a| + |b| ≥ |a + b|，等號在 [ab ≥ 0]。（干擾：平均數、ab ≤ 0）

## 速算

- 第 11 題：|x − a| ≤ b 的範圍（按鈕：a − b ≤ x ≤ a + b、−b ≤ x ≤ b、a − b ≤ x ≤ b），或 m ≤ x ≤ n 寫成絕對值（按鈕：|x − 中點| ≤ 半長、|x − 中點| ≤ 全長、|x + 中點| ≤ 半長）。產生時確認三個不一樣。
- 第 23 題：|x − a| + |x − b| 的最小值（按鈕：|a − b|、|a + b|、0），三根柱子的最小值（按鈕：最大 − 最小、兩兩距離相加、中間那根的值）。
